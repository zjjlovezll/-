# S1-f：缺的是轨枕-道床这一层，不是钢轨梁

日期 2026-10-20。目标：把 S1-e 遗留的 "30-60 Hz 带低 27%" 补上。
结论先行：**钢轨梁在这套扣件刚度下根本不可能提供 30-60 Hz 的内容**，缺的是轨枕质量 + 道床刚度这一层；
而单自由度集总（无论怎么调 kz）在数学上无法同时对上峰值与频带——两自由度"钢轨-轨枕"链是必需的。

## 1. 文献侧的口径

- 对 track 模型保真度的评述指出：beam-on-elastic-foundation（Winkler）模型在较高频段不能充分描述
  轨道动力响应，而**离散支承**的钢轨模型才能反映周期性支承带来的高阶内容
  （[Vehicle System Dynamics 综述节选](https://www.tandfonline.com/doi/pdf/10.1080/23248378.2024.2394195#4#2)、
  [离散支承钢轨模型](https://www.hse.ru/pubs/share/folder/ndburmpl90/50867823.pdf#83#38)）。
- 因此第一步按文献做了"离散支承钢轨梁"（模态法），但见第 2 节的硬结论：它在这一算例里没有
  30-60 Hz 的模态可用。

## 2. 离散支承钢轨梁：第一阶模态就在 132 Hz（决定性）

`validation/crh380a_m/build_rail_modes.py`（Euler-Bernoulli Hermite 梁，251 节点、502 DOF、
每 0.6 m 一个 25e6 N/m 扣件、自由-自由端、质量归一化、广义特征值用 `scipy.linalg.eigh`）：

```
EI = 6.884e6 N·m^2 (E=214 GPa, I=3.217e-5 m^4)   mu = 60.64 kg/m
输出：60 阶模态，f = 131.93 .. 156.00 Hz
```

**为什么第一阶就是 132 Hz**：整根钢轨在扣件上做均匀浮沉时，`k_total/m_total = k_pad/m_bay`，
与扣件数量无关：

```
omega = sqrt(25e6 / (60.64 * 0.6)) = 828 rad/s -> 131.9 Hz
```

所以"钢轨 + 刚性扣件"这个组合的**全部**模态都 ≥132 Hz，30-60 Hz 带里一个模态都没有。
`track_modes_turnout.json` 已生成并记录，但**不予接入**——结构上不可能贡献目标频带。

## 3. 目标频带的物理来源：轨枕在道床上的浮沉

SDITT `Par_TrackSystem.m`（Flexible Track 路径）给了缺失的两层：

| 层 | 参数（每米轨长，0.6 m 枕距折算每枕） |
|---|---|
| 扣件/胶垫 kz | 120e6 N/m per m → 每枕 25e6 N/m（与 FT-Modal 一致） |
| 道床 kz | 20e6 N/m per m → 每枕 **12e6 N/m** |
| 道床 cz | 200e3 N·s/m per m |
| 轨枕质量 | 2400 kg/m³ × 0.054824 m² = 131.6 kg/m → 每枕 **79 kg** |
| 钢轨参与质量 | 2 m × 60.64 = **121 kg** |

两质量（钢轨 + 轨枕）串联的基频：

```
k_series = 1/(1/25e6 + 1/12e6) = 8.11e6 N/m
f        = sqrt(8.11e6 / (121 + 79)) / 2pi = 32.0 Hz
```

Simpack 的力主频是 **31.65 Hz**。差 1.1%——这就是缺失的机制。

## 4. 单自由度集总的实测上限（关键否证）

把上面这条链**等效成一个自由度**（质量 199 kg、弹簧 8.11e6），跑满 1.2 s：

| 变体 | 峰值 | 最小力 | 脱空 | 轮对行程 | 主频 | 150-250 Hz | 30-60 Hz |
|---|---|---|---|---|---|---|---|
| kz50 cz20（两扣件） | 123.77 kN | 13.41 | 0 | 0.6012 mm | 36.65 Hz | 0.577 | **3.545** |
| **kz8.11e6 / m199（串联等效）** | **131.64 kN** | 10.63 | 0 | 0.4962 | 490.6 Hz | **1.048** | **0.466** |
| Simpack | 134.97 | 27.67 | 0 | 0.5944 | 31.65 | 1.088 | 4.839 |

- 峰值：131.64 vs 134.97（**−2.5%，全项目最好**）；
- 但 30-60 Hz 带从 3.545 掉到 **0.466**，主频被一个 490 Hz 的窄峰占住。

**这就是单自由度集总的上限**：把 kz 调软能把"准静态等效刚度"对上（峰值对），但那个自由度
只有一个特征频率，它落在 32 Hz 时反而不被辙叉的几何激励激发，于是 30-60 Hz 的宽带能量消失。
要同时得到峰值与频带，必须让**两个特征频率同时存在**——即真正的两自由度（钢轨 + 轨枕），
上有扣件、下有道床。

## 5. 因此下一刀要改的是 `TrackKernel`

现在 `local_compliant` 是"每根钢轨 2 个自由度（y, z）+ 一组支撑"。需要扩成每根钢轨 4 个自由度：

```
钢轨 z_r:  m_r = 121 kg  --(k_pad=25e6, c_pad=20e3)--  轨枕 z_s: m_s = 79 kg  --(k_ball=12e6, c_ball=120e3)-- 地面
```

模态频率：约 32 Hz（同相）与 190 Hz（反相，`sqrt(k_pad(1/m_r+1/m_s))`），正好覆盖
30-60 Hz 与 150-250 Hz 两个带。这是 S1-f 的唯一实现路径，也是 S2 之前最后一个物理缺口。

## 7. 教训

- `np.linalg.eigh` 在 numpy 2.2.6 里签名是 `(a, UPLO='L')`，**没有广义特征值**；广义问题要用
  `scipy.linalg.eigh(a, b)`。我按 numpy 文档写 `eigh(K, M)` 直接拿到 `AttributeError`。
- "给轨道加自由度" 之前先算它的模态落在哪个频段：扣件刚度除以每枕质量就决定了地板频率，
  算一下 30 秒就能避免生成一整族用不上的模态。

## 8. 两层轨道已落地并跑通（本节为实测，覆盖第 5 节的"待落地"）

`TrackKernel` 新增 `two_layer` 类型（每根钢轨 4 个自由度：`y_rail, z_rail, y_sleeper, z_sleeper`），
`LinearSupport` 新增 6 个带默认值字段（`sleeper_mass_[yz]_kg`、`ballast_k_[yz]_n_m`、
`ballast_c_[yz]_n_s_m`），旧算例不受影响。**56 项测试全过。**

算例（`validation/crh380a_m/make_two_layer_case.py`，0.6 m 枕距）：
`m_rail=121 kg`、`k_pad=25e6 / c_pad=20e3`、`m_sleeper=79 kg`、`k_ballast=12e6 / c_ballast=120e3`。

满 1.2 s（2401 采样，7/7 门过，`numerically_checked`，67 自由度，nfev 482 525）：

| 轨道模型 | 峰值 | 最小力 | 脱空 | 轮对行程 | 主频 | 30-60 Hz | 150-250 Hz |
|---|---|---|---|---|---|---|---|
| 刚体 | 158.04 kN | 3.02 | 0 | 0.5933 mm | 175.76 Hz | 1.183 | 6.402 |
| 单自由度 kz50/cz20 | 123.77 | 13.41 | 0 | 0.6012 | 36.65 | 2.507 | 0.408 |
| **两层（本次）** | **125.35** | **23.50** | **0** | 0.4741 | **545.61** | **0.380** | 0.480 |
| Simpack | 134.97 | **27.67** | 0 | 0.5944 | **31.65** | **4.839** | 1.088 |

**读法**：第一个目标达成——峰值 −7.1%、最小力 23.50 kN 与参考的 27.67 kN 最接近
（此前单自由度是 13.41）、且完全不脱空。**但频带没有达成**：主频 545.61 Hz 是轮对压在接触
弹簧上的振铃（`sqrt(1.5*C*sqrt(delta)/m_wheelset)/2pi`，C≈1.2e11、delta≈0.1 mm → 约 600 Hz），
它压过了 32 Hz 的轨道模态；30-60 Hz 反而从 1.183（刚体）降到 0.380。

## 9. 结论：缺的不是层数，是模态参与质量

32 Hz 模态确实存在，但它在接触点的参与质量只有 79 kg 的轨枕，而 121 kg 的钢轨坐在 25e6 N/m
的扣件上——轮对感受到的仍是"硬轨 + 小质量轨枕"，所以 32 Hz 那条振型的挠度小、接触力里看不
出来。参考解里 31.65 Hz 能主导，说明它的轨道在接触点有**大得多的低频参与质量**。

下一步（按可检验性排序）：

1. 给轨枕质量补上道床参与质量（道床锥体质量，通常 200-400 kg/枕），使 32 Hz 模态的接触点
   参与质量从 79 kg 提到 300 kg 量级——这是唯一能在不改判据的前提下把 30-60 Hz 抬起来的改动。
2. 抑制 545 Hz 振铃：接触阻尼目前在 `hunt_crossley` 口径下由恢复系数给定（e=0.5），可对照
   Simpack 的 `fn.dref=1e5` 做一次定标，而不是继续调 e。
3. 若 1 与 2 之后 30-60 Hz 仍不足，则说明参考解的低频内容来自我们尚未建模的轨下结构
   （轨道板/道床板），那属于 S1-g，不是轨道层能补的。
