# 随机不平顺（随机相位带限谱）逐带反演：3/8 带达标，而且这次不是非线性的错

日期 2026-10-28 · 脚本 `scripts/s37_random_spectrum_bands.py` · 数据 `../scratch/s37/bands.json`

第 6 门的"随机不平顺"一半。与 `s35` 的确定性混合不同，这里每个带是一条**随机相位**带限记录
（带内 24 个谐波、频率均匀、相位随机、归一化到指定 rms），而且**标定与测试用不同种子**，
所以结果不是"用同一条波形标定自己"。

## 1 预注册协议

| 项 | 值 |
|---|---|
| 路线 / 速度 | 直线、刚性轨、70.32 km/h（第 4 轮抽到的同一档，未换） |
| 补片 | 42.5–45.5 m，2.5 mm 步长，50 mm 升余弦端坡，**只加在左轨** |
| 带 | 0.10–0.30 m 等对数四分：**0.1000–0.1316 / 0.1316–0.1732 / 0.1732–0.2280 / 0.2280–0.3000 m**（148.4–195.3 / 112.8–148.4 / 85.7–112.8 / 65.1–85.7 Hz） |
| 幅值 | 每带 **8 µm rms**（峰值 ≈24 µm，整条记录 ≈48 µm 峰峰，落在第 192 轮判定的线性区） |
| 标定 | 种子 **20261029**，一次只开一个带，量 `g_k = rms(a_k)/rms(记录_k)` |
| 测试 | 种子 **20261030 / 20261031**，四带同时开 |
| 判据 | 每带 `|误差| ≤ 2 dB`，报**带命中率**，不报单一总误差 |

## 3 这次**不是**非线性

四个标定运行与两个测试运行的**平均侵入量**：

| 运行 | 平均侵入 |
|---|---|
| 带 0 标定 | 64.08 µm |
| 带 1 标定 | 65.18 µm |
| 带 2 标定 | 65.47 µm |
| 带 3 标定 | 65.45 µm |
| 种子 20261030 | 63.02 µm |
| 种子 20261031 | 64.48 µm |

静止值是 65.47 µm，第 192 轮判定"平均侵入离开 65 µm 就不许定量"。**六次运行全部在 63.0–65.5 µm**，
即全部落在允许定量的区间里，而 8 次预测仍只过 3 次。所以限制因素换了：
不再是 `δ^1.5` 的压缩，而是**一个标量增益描述不了一条带**。

## 4 机理：带内传递在变，标量增益不足以反演宽带记录

第 192 轮的逐音标定给了带内斜率：

| 单音频率 | 波长 | 增益 (m/s²)/µm |
|---|---|---|
| 85.19 Hz | 0.2293 m | 0.1768 |
| 94.23 Hz | 0.2073 m | 0.2282 |
| 141.65 Hz | 0.1379 m | 1.1426 |
| 194.56 Hz | 0.1004 m | 1.1671 |

**85.2 → 94.2 Hz 之间增益就升了 29 %**（+10.5 % 的频率）。一个三分之一倍频程带内的传递因此可以
变化几十个百分点，而"带 rms ÷ 单一 g_k"只在测试记录的谱形与标定记录的谱形完全一致时才无偏；
两条随机实现的谱形不同，比值就带上了这个带内变化，表现为**同向偏置**（0.2280–0.3000 m 两个种子
都是 +2.3…+2.4 dB）与**散布**（0.1000–0.1316 m 两个种子 −3.03 / +1.88 dB）。

这条与第 192 轮的结论互补而非冲突：192 轮证明**高频带本身不能定量**（非线性），本轮证明
**即使在线性带里，随机记录也不能用单个标量反演到 ±2 dB**（带内传递变化）。

## 5 由此确定的下一步协议（判据先写）

**频率分辨反演**：把带内分成 K 个频点，每点单独标定 `H(f_i)`（或由一次带限随机标定做 H1 估计），
反演按频点做 `r(f) = a(f)/H(f)` 再取带 rms。

- 判据不变（每带 ≤2 dB），但比较对象变成"同一批 8 次预测"；
- 若频率分辨后仍不到 6/8，则剩下的限制才是数据（记录只有 3 m、窗内只有一个行程）；
- **不允许**用"换一个更有利的带"来达标——带的划分在本轮已经预注册。

## 6 本轮自己修掉的一个度量缺陷

`band_rms` 的归一化原先少了 `1/n` 因子（正弦应读成 `A/√2`，实测读成 17.5 倍）。因为**标定与复原
用的是同一个估算子，比例里抵消**，所以第 2 节的数字不受影响；但脚本打印的 rms 与增益都会错。
已改为 Hann 加窗 PSD 口径并用两个正弦验证（3.0 幅值 → 2.121 / 2.120，理论 2.1213）。宽带内容上
该估算子仍低约 2 倍，这一点写在 docstring 里；凡引用都只用**比值**，不用绝对值。

## 7 边界

- 只测 70.32 km/h、单轴单侧、刚性轨、单一车型；
- 8 µm rms 一档幅值，没有测幅值依赖性（本轮的目的是"随机谱能不能反演"，不是"多大的幅值能反演"）；
- 没有实测真值参与；
- "带内传递变化"是**由四个单音增益的斜率推出来的**，没有在带内做密集扫频——那是下一步。
