# Velch 0.4.17 发布说明

发布日：2026-10-23　｜　和 0.4.16 的差别：**环境体检有了按钮**。

## 这一版改了什么

- ① 算例屏新增「环境体检」，打开即跑 `velch selfcheck`，结果按 `[PASS]/[WARN]/[FAIL]` 着色；
  底部结论分「全部通过 / 可用，有 N 项提示 / N 项需要处理」三档。
- 导航区从一行三键改为 **2×2**，四个键都完整可见（布局闸门在 1.0 与 1.3 两档各量一次）。
- 自检仍走 `velch-cli.exe`（`launcher_argv`），界面不 import 自检模块。

## 为什么值得发

第一次打开打包版、算例表是空的时候，用户需要的不是文档，而是一句话：**缺什么、去哪里填**。
现在这句话就在屏幕上，附带可以复制的修法。

## 仍然没有的四项

1. Simpack 横向布置的双侧导入（需要两条轨都有断面表的模型）。
2. Simpack 侧轴重/刚度/阻尼只作对照。
3. 没有代码签名。
4. `physics_validation_status` 仍未标定。

## 验证

- `pytest` **572 passed, 1 skipped**
- `packaging/smoke_test.py --readonly-acl` → ACCEPT（8 步）
- 体检实跑：`exit 0`、6 项、`WARN` 1 项（未设 Simpack 环境变量）
