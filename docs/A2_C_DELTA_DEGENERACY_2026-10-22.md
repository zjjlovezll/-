# A2 C–δ 简并排查（2026-10-22）

问题：法向力是 `N = C · δ^1.5`，`C` 由接触刚度假定、`δ` 由几何算出。若几何存在未知偏移 `ε`，
那么 `(C 大, ε 小)` 与 `(C 小, ε 大)` 可能给出同一力——反演里这就是简并。

## 1. 结论先说

**刚性偏移与 C 不构成简并，是规范（gauge）等价。** 竖直刚体平移会同时抬升车辆姿态，
求解器的静平衡把偏移完全吸收，力、波形、频谱逐位不变（下表 0.000 %）。
真正的简并发生在 **C 与可变形支撑（`k_z`）之间**，因为那一条会反馈进动力学，
而它已被观测量区分开（§3）。

## 2. 实测：刚性偏移不可观测

算例 `case_frog_N_strip05.json`（辙叉窗 0.05 s），把两侧轮型面 `z_offset_m` 各下沉 **0.1 mm**
（即等价于轨面抬高 0.1 mm），其余不动：

| 变体 | 静态 kN | 均值 kN | 峰值 kN | rms kN | 主频 Hz | 最大侵入 µm | nfev |
|---|---|---|---|---|---|---|---|
| base | 66.285 | 59.528 | 203.990 | 37.514 | 178.22 | 447.525 | 10 505 |
| eps（下沉 0.1 mm） | 66.285 | 59.528 | 203.989 | 37.515 | 178.22 | 447.523 | 10 649 |
| **相对变化** | **0.000 %** | 0.000 % | **−0.000 %** | +0.002 % | 0.00 | −0.002 | +1.4 % |

机制：`equilibrate_vertical` 求的是姿态，偏移被整车竖向位移吸收；`δ` 由平衡后的相对几何决定，
与偏移无关。因此“几何有 0.1 mm 偏差所以 C 标定错了”这个担心**不成立**——若偏差是刚性的，
它既不影响力也不影响频谱（只改变绝对高程）。

脚本：`validation/crh380a_m/probe_contact_degeneracy.py`，输出 `a2_degeneracy.json`。

## 3. 真正的简并在 C 与支撑刚度之间（用既有实测）

当偏移由**可变形支撑**承载（`local_compliant`/`two_layer`/`layered`），它就进入动力学：

| 观测量 | 灵敏度 | 反演分辨率（1 kN / 0.01 mm 噪声） | 来源 |
|---|---|---|---|
| 峰值力 | 1.347 kN / 单位 ln | σ(ln k_z) ≈ **±110 %** | 早期 `inverse` 实测 |
| 力波形 | 158.6 kN / 单位 ln | σ ≈ **±0.63 %** | 同上（118× 差） |
| 沉降波形 | 0.2846 mm / 单位 ln | σ ≈ **5.28 %**（k_z）、c_z −7.4 % | `settlement_observable` 实测 |

即：单看峰值时 C 与 k_z 确实几乎不可分（±110 %）；一旦改用波形（力或轨位移），
两者都被压到 <10 %。**简并的解法不是更好的力律，而是换观测量。**

## 4. 由此固定的两条使用规则

1. **不要用"额定侵入"去标定 C**：额定侵入若来自刚性几何，它对 C 的约束是零（§2 已证）；
   有效做法是用材料/曲率定 C（`local_circular` 现状），再用波形观测量去标定 `k_z`/`c_z`。
2. **报告 C 时必须同时报告它是怎么定的**（材料曲率 / 拟合 / 沿用），否则读者无法判断
   350 % 级的力差是刚度还是几何。

## 5. 与既有结论的关系

- 这条与 `case_H_stiff`（把 `effective_radius_m` 调到 0.5407 使 C = 1.117e11）的 1.24 MN 峰值一致：
  **单改 C 会更差**，因为静平衡侵入被压小、动态增量不变，力就更尖。
- 与 `docs\CONTACT_MODELS_MATLAB_VELCH_SIMPACK.md` 的结论对齐：C 的取值应来自 Simpack 反算的
  `C = 1.117e11 N/m^1.5`（`R* = 0.5407 m`）或材料曲率，而不是任何拟合出的"等效半径"。
