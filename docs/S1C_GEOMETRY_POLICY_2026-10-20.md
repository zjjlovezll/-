# S1-c：接触点几何策略（`geometry_policy`）——实现、A/B、以及为什么它是空结果

日期：2026-10-20 　代码：`Velch/src/velch/contact.py` 　算例：`validation/crh380a_m/case_frog_T_*`

## 1. 这一步想解决什么

S1 的目标是把接触几何从"在采样网格上取最深节点"换成**解析求极值**。
动机来自与 Simpack 的残余差分解（见 `CONTACT_ALGORITHM_FINAL_2026-10-20.md` §4）：

- 我们的接触点是**点接触**，法向力在 150–250 Hz 频带内占 74% 能量；
- Simpack 是**斑接触**（`rw.cont.meth=2` → 离散弹性），同段没有这个振铃；
- 当时留下的两个候选原因：①接触点在网格节点之间跳动（数值）②单点接触本身
  就是硬弹簧（物理）。

S1-c 就是把①彻底排除或证实的实验。

## 2. 实现（可回退）

| 位置 | 内容 |
|---|---|
| `contact.py`：`GEOMETRY_POLICIES = ("grid", "patch")` | `grid` = 历史路径，逐位不变 |
| `ContactParameters.geometry_policy`（默认 `"grid"`）、`.patch_window_m`（默认 1 mm） | 由算例 `contact` 段选择；旧算例不改即跑 |
| `find_patch_contact()` | 只做**亚节点**细化：用跨过最深节点的三个节点拟合抛物线，取极值点 |
| 刚度口径不变 | `R*` 仍用 ±1 mm 窗口最小二乘（平直段已验：侵入 0.0655 vs Simpack 0.0662 mm） |
| 兜底 | 抛物线说"无接触"而采样点说"有接触"时，信采样点（尖 V 不是抛物线） |
| 测试 `tests/test_contact_patch_geometry.py` | 4 项：策略校验、解析极值还原、不吸附到节点、节点重合时与 grid 一致 |
| 全套测试 | **51 passed** |

**一个被自己抓住的坑**：第一版把窗口设成固定 1 mm 的**最小二乘滑窗**，
在 5 mm 重采样的轨体上窗口内不足 5 点 → 返回 `None` → 静平衡直接失败
（`no seed converged`）。自适应成 `max(1 mm, 2.5×节点间距)` 后能跑，
但随即暴露更严重的问题：12.5 mm 的窗口把 20 mm 宽的辙叉凹坑**抹平**了，
整程 1.2 s 算出 59.68 kN 恒定力（等于静载，辙叉激励完全消失）。
这正是"过度平滑"的可检测指纹，因此改为**只用三个节点**的亚节点细化——
它不可能平滑超过一个节点间距。

## 4. 频谱判据（决定性）

`cmp_spectrum.py`（新建）对两条力曲线做同一里程轴的 FFT：

| 频带 | `grid` | `patch` |
|---|---|---|
| 0–150 Hz | 12.6% | 12.9% |
| **150–250 Hz** | **73.9%** | **72.5%** |
| 250–400 Hz | 11.6% | 12.8% |
| 400–700 Hz | 1.4% | 1.3% |
| 主频 | 158.4 Hz | 158.4 Hz |

**结论：振铃与节点跳变无关。** 把接触点从"节点"换成"解析极值"，158–194 Hz
频带的能量份额只从 73.9% 变到 72.5%，主频一点没动。所以这 194 Hz 是
**物理的**：1780 kg 轮对压在 ~1.1e9 N/m 的单点赫兹弹簧上，被辙叉几何激起的
接触共振。它只能靠"分布接触 + 阻尼过渡"压下去，靠几何取点精度压不下去。

## 5. 保留价值

- `geometry_policy` 是干净的策略开关，默认 `grid`，逐位可回退；
- 亚节点细化本身是对的（接触点不再随节点跳变，`y*(s)` 连续），只是**不解决**
  峰值与振铃；
- `cmp_spectrum.py` 成为新的验收工具：以后任何"接触是否被抹平"的改动，
  先看 150–250 Hz 份额和主频是否变化，比看峰值更灵敏。

## 6. 下一步（唯一有机制的杠杆）

按 `ROADMAP_BEYOND_SIMPACK.md` S1-d：**分布接触 + 阻尼过渡**

1. 在潜在接触区（±a，`a` 取当前 `half_width_m`）做条带积分
   `N = C Σ max(δ(y),0)^1.5 Δy`，`δ_eq = (N/C)^(2/3)` 回灌切向律；
2. 阻尼按 `fn.dref = 1e5 m` 的过渡形式，而不是 `c·√δ`；
3. 验收：150–250 Hz 份额 < 20%（现 74%）、峰值 ≤ 140 kN（现 158）、
   平直段静载仍 59.68 kN、脱空 0。
