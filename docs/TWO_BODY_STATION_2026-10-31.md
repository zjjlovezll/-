# 逐站两体 Hertz（无拟合常数）也不行：病根在“尖轨尖当成点接触”（2026-10-31，第 281 轮）

> 第 280 轮把半宽排除后，唯一剩下的候选是"逐站独立假设本身"。最直接的实现就是**逐站真解两体 Hertz**：
> 每个站位用两根轨自己的冠高与曲率半径算各自的接触刚度，再解"两体力之和 = 半载"。这一轮把它的
> **无拟合常数**版本写完并跑掉——结论是**它也不成立**，而且失败的方式指出了一个具体机理。

## 一、模型（无自由参数）

```
每体 i（stock, blade），每站 s：
    z_i(s)   = 该体断面冠高（max z）
    R_i(s)   = 冠附近 ±3 mm 抛物线拟合的横向半径，R = 1/|2a|
    R*_i     = (1/1.27365 m + 1/R_i)^-1        （轮横向半径 1.27365 m，第 259 轮实测）
    C_i      = (4/3) E* sqrt(R*_i)             （E* = 1.154e11 Pa）
    F_i      = C_i · max(0, p − z_i)^1.5
每站：解 F_stock + F_blade = 60 153 N 得公共轮心高 p，share = F_blade / N
```

**没有任何拟合量**：断面、`E*`、轮半径都是声明的。所以这是**预测**而不是标定。

## 二、读数

```
stations 300/300 finite; R_stock 299..300 mm   R_blade 1..300 mm

run                         usable    floor      bias
straight_one_set               469   0.3132   -0.2220
one_set_twopeak                479   0.3216   -0.2608

one_set_random                 383   0.5069   -0.4501
all bumped runs under 0.02: NO
VERDICT: a per-station two-body Hertz model with no fitted stiffness still misses the floor, so the
         residual is not the two-body split either
```

**它连无凸起那趟都过不了**（0.3132，偏 **−0.2220**）——所以问题不是"叠加时失效"，而是**绝对值就错了**：模型系统性少给尖轨约 0.22 的份额。

## 三、失败的方式指出了一个具体机理

`R_blade` 从 **300 mm 一路降到 1 mm**（尖轨在窄断面上是一条锐边），而 `C ∝ sqrt(R*)`：
1 mm 的边给出 `sqrt(0.001)`，是 300 mm 冠 `sqrt(0.3)` 的 **1/17**。于是模型认为"尖轨是一把刀，压下去几乎不承力"。

真实情况正相反：**尖轨窄断面上的接触沿滚动方向是线状/共形的**，同样压深下承载更高，不是更低。
与其说"两体分配模型错"，不如说**在这里用点接触 Hertz 的尺寸律是错的**——而这正是 `s85` 建库时把
尖轨断面接进条带积分、而不是点接触的原因。

## 四、能说 / 不能说

**能说**：一个**无拟合常数**的逐站两体点接触 Hertz 模型（曲率来自断面、`E*` 与轮半径声明）在四条已归档
运行上 floor 为 **0.3132 / 0.3216 / 0.4089 / 0.5069**，偏置 **−0.2220 / −0.2608 / −0.3537 / −0.4501**；
它比标定过的实测律（0.0133 / 0.0427 / 0.1314）差一个数量级，**连无凸起那趟都不达标**。

**不能说**：① 不能说"两体分配不可能"——只能说**点接触尺寸律**在这套几何里不成立；
② 不能说"必须用求解器逐站重算"——本轮没做；
③ 不给任何随机剖面幅值；④ 只测直向、单速度、单侧。

## 五、下一步（由本轮的失败直接指定）

把接触从"点 Hermite"换成**沿滚动方向的线/共形接触**：每体用**条带积分**（`strip_integral`，求解器已在用）
在真实断面上积分，得到该站的等效刚度 `C_i(s)`（而不是 `sqrt(R*)`），再解两体和力平衡。
判据不变：floor ≤ 0.02，且**无凸起那趟必须先过**（本轮它就没过——这是新的前置门）。
