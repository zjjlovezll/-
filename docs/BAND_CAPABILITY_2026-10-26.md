# 分带反演能力表：修掉三处测量错误之后

日期：2026-10-26
脚本：`scripts/s9l_differential_bands.py`（短波，4 次运行 ≈ 1000 s）、`scripts/s9_inversion.py`（长波，8 次运行 ≈ 90 min）
前置：`docs/AXLEBOX_RESTRAINT_2026-10-26.md`（B027，13.094 Hz 无阻尼轴箱模态）

## 1. 为什么之前的表不能用

代码审查（D1–D13）指出，`docs/RANDOM_SPECTRUM_INVERSION_2026-10-25.md` 与 CHANGELOG 第 93 轮那张"2/8 带达标、串扰底线 10–16 µm"的表建立在四类错误上：

| 编号 | 错误 | 后果 |
|---|---|---|
| **D3/B027** | 轴箱缺转动约束 → 13.094 Hz、ζ = 0 的四重模态 | 轴箱通道里常驻 9.18 m/s² 的假信号，比要测的不平顺大 1–2 个数量级；13.33 Hz 在 80 km/h = **1.667 m**，正好压在 (1.6, 3.2) m 带内 |
| **D8** | `build_case` 用 `vehicle_ref` 覆盖了内联车辆，算例实际以 **350 km/h** 跑，而谱分析按 80 km/h 折算 | 带↔波长映射差 4.375 倍 |
| **D1** | 站位表只到 150 m，2 s × 97.2 m/s 从 13.5 m 起要走到 217.9 m | 长波记录最后 1.3 s 是自由落体（`axle1_z_m = −2.474 m`，分析窗 31 % 无效） |
| **D5/D6** | 探针给的是**峰值** A，回归却用响应**带内 rms**（低 1/√2 = 3.01 dB）；`s9m` 又按转置方向求逆 | 8/8 带"偏大"，其中 3 dB 是量纲；负的复原幅值来自转置 |
| D2/D9 | 零激励底线测了但没减；`s9l` 的对照由 ±0 组成因而结构恒等于 0 | 轻带"复原"成标定量 |

修法：B027 见专文；`s9k.build_case` 改为保留内联车辆并写入正确速度、加"是否跑出站位表"的硬报错（`ValueError: run would leave the rail station table`）；`s9_inversion.flexible_base()` 把末站克隆到 400 m 并在仍不够时退出；`s9m` 的归一化改成除以输入 **rms**（`A/√2`）。

没过的两带是 (0.4, 0.8) 与 (1.6, 3.2)，两带的共同点是**真值最小**（2.75 与 3.00 µm），复原值都停在 4.4 / 4.9 µm——即存在一个约 **3–4 µm 等效深度的残余底线**。它不再来自 13 Hz 模态（那条已经消失），而来自单边 Hertz 接触与蠕滑饱和在相邻带之间的泄漏；这一条与"不存在常数 H"（双带同时激励使 2 m 对角增益降 14 %）是同一个物理。

## 3. 长波：修后复测

见表底注与 CHANGELOG 第 95 轮；协议三处改动（站位表克隆到 400 m、列缓存记录协议指纹、闭环比模长）。

## 4. 这张表能说明什么

- **短波（0.05–0.2 m）可以定量反演**：0.05–0.1 m 与 0.1–0.2 m 两带误差 −6.3 % / +10.7 %，与单频探针结果（25 mm、50 mm 在 80 km/h 为 +9.7 %）互相独立地一致。
- **0.2–0.8 m 与 0.8–1.6 m 处于同一量级**，其中 0.8–1.6 m 达标、0.4–0.8 m 因真值太小而超标。
- **底线约 3–4 µm**：任何低于这个量级的带都无法定量，只能报告"低于底线"。
- 把 13 Hz 模态去掉之后，短波那一路**从"测不出"变成"六带达标"**——问题确实出在模型装配上，不是出在算法上。

## 5. 这张表不能说明什么

- 真值仍然来自**自建仿真**，没有任何实测标定；`physics_validation_status` 仍是 `unvalidated_against_measurement_or_Simpack`。
- 只测了一条直线、一个速度（80 km/h）、一个车（`CRH380A_M_axlebox`）、单侧单轴、刚性轨道。速度依赖已知存在（50 mm 在 80 km/h 与 350 km/h 差 13.6 %）。
- 3–4 µm 底线的**来源**只有间接证据（与"无常数 H"同源），没有逐项分解。
