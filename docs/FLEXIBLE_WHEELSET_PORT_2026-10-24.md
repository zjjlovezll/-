## 3. 数学形式（移植时要实现的部分）

模态坐标的质量是**单位阵**：`Mlc(1:DOF_FW,1:DOF_FW) = diag(ones(...))`
（`Matrix_Vehicle_FW_230409.m:89`），刚体运动仍由 5 自由度 + `Mw/Jwx/Jwy/Jwz` 承担
（`:95-99`），6 阶刚体模态在 `Load_ModeShape_FW.m` 里被删掉（`NM_del = 6`）。所以：

```
q̈ + (2ζω) q̇ + ω² q + 2Ω G q̇ + Ω² C q = Φᵀ f
```

- `ω²` 来自 `ModeFreq`，`ζ` 按节径给（`DR_FW` 默认 1e-2，节径 0 用 1e-3，节径 ≥2 用 1e-4，驱动 `:329-333`）；
- `Ω = V/R0`（`Matrix_Vehicle_FW_230409.m:80`），`Klc += Ω²C`（`:133`）、`Clc += -2ΩG`（`:418`）；
- 接触点位置 = 刚体位姿 + Φ·q，在**变形并旋转**后的踏面节点上搜索
  （`Multi_Con_250812.m:138-155`：`Pos_FW = [0 Yw Zw] + (pos_ori + Defor')·A_WS`，侧滚/摇头角由 `WOut/WBack` 重建）。

### 9.1 方程（论文式 2-30 ~ 2-32）

```
q̈_w + 2Ω G q̇_w + (K_w + Ω² C) q_w = Q_w(v, t)          (2-30)
C = G G + G J − J G − J J − E                            (2-31)
K_w = diag(ω_w1², ω_w2², …, ω_wNM²)                      (2-32)
```

与 `Load_Rotation_FW.m:54-55` 的 `C = G*G + G*J - J*G - J*J - E` **逐字一致**——两条线索互证，
说明我们把 SDITT 的读法理解对了。四个矩阵都是单元积分（`N_e(v)` 为形函数，`Φ_w` 为正则振型）：

```
J = Σ_e ∫ Φᵀ Nᵀ J̃ N Φ dV        （陀螺，与转速相关，反对称）
G = Σ_e ∫ Φᵀ Nᵀ (∂N/∂v_i) J̃ v_i Φ dV
E = Σ_e ∫ Φᵀ Nᵀ Ẽ N Φ dV        （离心，对称）
L = Σ_e ∫ Φᵀ Nᵀ Ẽ v dV          （离心力向量，只对节径 n=1 的轴对称径向模态非零）
J̃ = B_θ Bᵀ,  Ẽ = −B_θθ Bᵀ,  B = 绕车轴的旋转矩阵           (2-33 ~ 2-39)
```

`G` 与 `J` 反对称、`E` 与 `C` 对称；`G` 只在**同一特征频率处有多个特征向量**的模态之间耦合
（轮对弯曲 ND=1、多节径 ND≥2），这些模态正是旋转后发生**频率分叉**的那些。

### 9.3 频率分叉可以直接算，不需要 ANSYS

论文式 (2-42)：`f_m^B = f_m − ND·n`，`f_m^F = f_m + ND·n`（`n` 为每秒转数，`Ω = 2πn`）。
这与 (2-30) 一致：对一对同频模态取 `G = [[0, −ND], [ND, 0]]`，特征根为 `λ ≈ ω ± ND·Ω`
（因为 `ω² − λ² ± 2λΩ·ND = 0` ⇒ `λ = ±Ω·ND + √(ω² + Ω²ND²)`），换到 Hz 正好是 `±ND·n`。

用论文自己的数验算：`R0 = 0.43 m`、`200 km/h` ⇒ `n = 20.56 r/s`，
2 节径 `459.7 ± 2×20.56 = 418.6 / 500.8 Hz`，论文实测 `420.2 / 499.1 Hz`（差 1.6 Hz，
来自被截断的 `C` 项与 `Ω²` 二阶小量）；3 节径 `1204.3 ± 3×20.56 = 1142.6 / 1266.0`，
论文 `1145.4 / 1263.0 Hz`。**所以只要拿到"哪些模态同频、节径几"这两件事，
`K` 与 `G` 就可以按 9.2 的表直接构造**，这是本轮最实质的收获。

### 9.4 他们的"轴箱加速度"定义与我们不同（会影响反演结论）

论文 §2.2.1 明说：*"车辆结构动力学模型中为简化分析，未建立轴箱作为分析对象"*——他们用
ANSYS `SOLID45` 建轮对（**Nw = 39613 自由度**），在"沿轮轴中心线、距轮对中心横向 1 m 处"用
`MASS21` 建一个**无质量节点**当轴箱质心，再用 `MPC184` 耦合附近轮轴内表面节点。
也就是说他们的"轴箱加速度"是**轮对有限元上那个位置的加速度**，不是轴箱体的加速度。

这解释了两边的数为什么差一个量级：

| 来源 | "轴箱加速度"主频 | 峰值 |
|---|---|---|
| 论文（轮对 FEM 节点） | 刚轮 50 与 115–145 Hz；柔轮另加 **345 与 378 Hz** | 65.3 → 120.4 m/s²、125.1 → 157.6 m/s² |
| 我们（86 坐标、8 个 48.2 kg 轴箱体 + 1e8 轴承 + 转臂节点） | **13.7 Hz**（轮对对照 193.6 Hz） | rms 1.95 g |

`13.7 Hz` 是"轴箱体坐在 1e8 N/m 轴承上"的刚体模态——它是**我们建模选择的产物**，不是现场加速度计的
主频。真实加速度计螺栓固定在轴箱上，而轴箱由轴承预紧近乎夹紧在轴上，所以高频成分确实会传上来。
**这条要进 O010 之外的账：将来做实测反演时，轴箱通道的物理定义必须先钉死**（轮对节点值 or 轴箱体值）。

### 10.3 一个顺带得到的更正：1.6 Hz 残差不是 `Ω²` 二阶项

§9.3 原来写"差 1.6 Hz 来自被截断的 `C` 项与 `Ω²` 二阶小量"。S8-1 把 `C` 取成 `G·G` 后发现：
对一对简并模态，`ω² − Ω²ND²` 与 `2ΩG` 一起给出的特征根**正好**是 `ω ∓ Ω·ND`
（`s² + (2ω²+2μ²)s + (ω²−μ²)² = 0 ⇒ s = −(ω∓μ)²`，`μ = Ω·ND`），二阶项精确抵消 ——
测试 `test_the_eigenvalue_solve_agrees_with_the_closed_form` 在无阻尼时验证到 `1e-6`。

所以剩下的 1.6 / 2.8–3.0 Hz 残差**全部属于 `J` 与 `E`**（式 2-33~2-36 的体积积分，要振型），
不是 `Ω²` 展开误差。这个更正改变了下一步的优先级：`C` 的 `J/E` 部分属于"有振型才谈得上"的
精修，而不是必须先补的缺口。

### 10.4 原计划（已被 §11 取代，其中两条要更正）

`wheel_modes.py` 现在只回答"模态集是什么、它应该以什么频率振动"。当时的计划是：

1. **把模态坐标接进 `Topology`**：每个轮对 31 个坐标、质量 1.0（单位模态质量），
   `ω²` 与 `2ζω` 作为"对地弹簧-阻尼"（`LinkSpec` 的单坐标项正好就是它），
   这样 `mass_array`/`offset`/`static_equilibrium`/`history` 列名全部沿用现成机制；
2. **陀螺项要新的元件类型**：`−2ΩG q̇` 正比于**速度**而不是位移，现有 `axial`/`torsional`
   都表达不了，需要一条"速度耦合"元件（同时给出 `∂f/∂v` 的常数块）；
3. **零模态必须逐位等价**：模态数 0 时 `history.csv` 的 sha256 必须与今天的冻结基线一致，
   这是"没破坏已有物理"的唯一可执行证明。

判据先定好：零模态逐位等价；31 阶时自由轮对分叉复现 418.57/500.83 与 1142.61/1265.99；
解析雅可比对中心差分 `< 1e-6`。

**实施时被两条现实改正**（理由见 §11.2、§11.6）：模态坐标**不能**进 `Topology`（单位模态质量会被
`total_weight` 当成 124 kg 真实重量，直接压垮作用-反力门）；"零模态逐位等价"在**轨迹层**做不到，
只能做到"零模态时状态向量的前 `body+track` 行逐位不变"。

## 11. S8-1 接进求解器：模态块落在轨道块之后（2026-10-24）

### 11.1 状态布局

```
[ 刚体 q | 轨道 q | 模态 q ]      模态块永远在最后，n_modes = 31 × 柔性轴数
```

- 通道名 `axle{axle+1}_mode{index}_q`，速度孪生 `…_q_per_s`（写入器给每个状态都写速度）；
  单位是 `-`，因为单位模态坐标是无量纲的广义位移 —— 不能写成 `_m`，否则会被当成长度参与几何。
- 本仓库示例算例：`35 + 8 + 4×31 = 183` 坐标（刚性版 59）。
- 算例写法：

```json
"flexible_wheelset": { "source": "table-2-3", "axles": [1, 2, 3, 4],
                       "radius_m": 0.43, "cutoff_hz": 2000.0 }
```

  或 `{"source": "file", "file": "<modes.json>"}`（`velch-wheel-modes/1` 格式，文件 sha256 进 `asset_hashes`）。
  未知 source 直接拒绝：`unknown flexible_wheelset source …: use 'table-2-3' or 'file'`。

### 11.2 为什么模态坐标不是"刚体"

单位模态质量 `1.0` 是**归一化**，不是 124 kg 真实质量。若把模态坐标做成 `Body`，
`total_weight = Σ m·g` 会多算 `31×4 = 124 kg`，而重力并没有对应项，
`translational_action_reaction` 门必挂 —— 那会是一个"看起来在算物理、其实在给幻影质量记账"的错。
所以模态块由 `VehicleDynamics._build_modal_block()` 拥有，`mass` 在构造函数里
`np.concatenate` 追加，`Topology` 一行未改。

### 11.3 力律与雅可比

```
f = −( K q + C v ),   K = diag(ω²) + Ω²·(G·G),   C = diag(2ζω) + 2Ω·G,   V = ½ qᵀKq
```

`G` 的每个简并对是 `[[0,−ND],[ND,0]]`，所以 `C` 的陀螺部分是**反对称**的：
这正是 `np.outer(jac, jac)` 这类对称元件永远表达不了、必须新增 `speed_jacobian` 的原因
（`Connector.speed_row` / `LinkSpec.speed_entries`，默认回落到 `jacobian`，因此既有元件行为不变）。

雅可比里两个块都是常数：`∂f/∂q = −K`、`∂f/∂v = −C`，直接加在模态偏移处。
稀疏骨架把整块标成实心 —— 静止时反对称陀螺行在有限差分探测里**看不见**，
不标实心就会在第一步丢耦合。

### 11.4 四处"向量尾部就是轨道块"的假设

接入时炸出 `ValueError: could not broadcast input array from shape (24,) into shape (55,)`，
逐一查明是四处把"尾部"当成轨道块的地方（`jacobian.py`）：`_track_blocks` 的循环与赋值、
`_rail_rows` 的模态分支、法向与切向行（`:180`、`:186`）、接触点 `turn` 行（`:492`）。
统一改为 `[self.dof:self.track_stop]`，`self.track_stop = dynamics.dof + dynamics.track.dimension`。
`vehicle_solver.py` 的能量门里 `velocity[topology.body_dimension:]` 是同一类，一并切片。

### 12.7 装进求解器后用起来是什么样

`load_modes()` 读得进来，200 km/h 下：ND1 88.25 → 70.05 / 106.45 Hz；ND2 347.10 → 310.69 / 383.50；ND3 957.32 → 902.71 / 1011.93。即**分裂量 = ND × 转数/秒**，与 §9 的解析推导一致。

算例里写：

```json
"flexible_wheelset": {"source": "file", "file": "vehicles/modes/CRH3C_wheelset_fe.json"}
```

轮对座标从 5 个变成 5 + 33 个；四轴都挂上时状态维度 35 + 8 + 4×33 = 175。

### 12.8 还没做的（下一节的入口）

- §11 的模态块现在**还没有力和它耦合**：`force[start:]` 只由模态块自己的弹簧阻尼产生，车体、一系、**接触力都没有经过 Φᵀ 映射**，所以振型装上了也激不起来。这是 S8-2。
- 接触点仍在**未变形的**踏面上找（`contact_search.py`），S8-3 才用振型算变形踏面。
- 阻尼比仍是论文的按节径取值（ND0 1e-3 / ND1 1e-2 / ND≥2 1e-4），没有做模态阻尼实测。

## 13. S8-2：让接触力真的推得动振型（2026-10-24 深夜）

§12 交出了振型，但 §11 的模态块仍然只和自己耦合：`force[模态]` 只由 `K q + C v` 产生，**车体、一系、接触力一项都没经过 Φᵀ**。所以第一版柔性算例跑出来 `max |q| = 0.000e+00`——不是数值稳，是根本没有输入。

这一节补上这条通路。

### 13.1 新模块 `src/velch/modal_coupling.py`

```python
TreadRing(side, nodes, shapes, radius_m, sigma_m=0.04)
    .from_modes(modes, side)      # 按 y 的符号取一片车轮，形状不足直接拒绝
    .centre                       # 胎面环中心（量出来的，不是假设）
    .plane_y_m                    # 车轮横向位置（中位数）
    .bottom_point(penetration_m)  # 轮心正下方的胎面点
    .weights(point)               # 高斯核，归一化到和为 1
    .generalised_force(point, f)  # Q_i = Σ_a w_a φ_i(a)·f
    .displacement(point, q)       # d = Σ_a w_a Σ_i φ_i(a) q_i（同一套权重）
ModalContact(rings={side: ring}, offsets={axle: offset})
    .generalised(axle, side, point, f) / .block(axle) -> slice
```

三条性质是**当成判据写的**，不是当注释写的：

1. **权重和为 1**：整体平移的振型必须把力原样传回去（力不能被投影无中生有或吃掉）；
2. **同一个权重既算力也算位移**：所以虚功恒等式 `Q·q == f·d(x)` 对任意 `q` 成立 —— 用两套权重会悄悄破坏能量守恒，而**峰值力看不出来**；
3. **投影对力线性**：`Q(f₁+f₂) = Q(f1)+Q(f2)`，零力给零。

### 13.2 接线点

在 `vehicle_solver.evaluate()` 的每个接触斑里，紧跟刚体那几行之后：

```python
side = -1 if "left" in str(rail.template_id) else 1
ring = coupling.rings[side]
force[coupling.block(rail.axle_index)] += coupling.generalised(
    rail.axle_index, side, ring.bottom_point(geometry.penetration_m),
    (0.0, response.wheel_force_y_n, response.wheel_force_z_n))
```

侧向符号用的是本仓库既有约定（`wheels[].lateral_offset_m` 里 L = −0.75，CAD 轮平面在 y = ±0.7359 m），不是猜。

### 13.3 抓到一个会让结果错 1000 倍的单位错

`TreadRing.centre` 之所以存在，是因为**振型存在 CAD 装配坐标系里，原点不是轮对中心**：这辆车的轮环中心在 x ≈ −1.2476 m。第一版把接触点放在 `x = 0`，核函数就落到 1.25 m 之外——`weights` 仍然归一化、`generalised_force` 仍然返回非零，一切"看起来正常"。测试里钉住"接触点必须跟着环中心走"，才把这个洞堵上。

更要紧的一条：**Abaqus 用 mm 和 t，求解器用 m 和 kg**。odb 的位移是 mm，Abaqus 的质量归一化是 `Σ m_t·u_mm² = 1`；同一批数字换到 SI 只剩 `Σ m_kg·u² = 1e-3`。所以出货时必须乘 `1/√1000`（mm→m 除 1000、恢复单位模态质量乘 √1000）。修之前实测 **max|φ| = 3.561**、5 ms 内胎面模态位移 **0.17 m**（！），而因为接触仍在未变形踏面上找（S8-3），**力、门、状态全都正常**——这正是最难发现的一类错。修正后 **max|φ| = 0.1126**（≈ 1/√(318 kg) 的量级），同一算例：

| 量 | 修前 | 修后 |
|---|---|---|
| max \|φ\| | 3.561 | **0.1126** |
| max \|q_模态\| | 1.124e-01 | **3.555e-03** |
| 5 ms 内胎面模态位移 | 1.7e-01 m | **2.49e-04 m**（0.25 mm，静侵入 65 µm 的量级） |
| 状态 | `numerically_checked` | `numerically_checked`，7 门全过 |

ratio 31.5 ≈ √1000，与推导一致；这说明修的是**归一化**，不是"把数调小"。

### 13.4 测试（`tests/test_modal_coupling.py`，11 项）

| 测试 | 钉住什么 |
|---|---|
| 每侧拿到自己那片车轮 | `plane_y_m` 符号、每环 300–450 节点、33 阶 |
| 接触点在轮心正下方 | `bottom_point` 跟随 `centre`，z = centre_z − R + δ |

### 13.5 还没做的（S8-3 与之后）

- **接触仍在未变形踏面上搜索**：`contact_search.py` 不知道 Φ q，所以模态位移再大也不改侵入量、不改接触点、不改力。这是下一步，也是"柔性轮对能改多少力"这个问题真正的答案所在（论文：Ip1 87.92 → 84.74 kN、轴箱加速度 65.3 → 120.4 m/s²）。
- **只投影了法向与横向力**：纵向力（`longitudinal_force_n`）还没进模态；它走的是 yaw 那一行。
- **一系/重力没有经过 Φᵀ**：悬挂力仍施加在轮对的 5 个刚体坐标上。严格做法是把轴座上的力也按振型投影，需要轴座处的振型（现在只出了胎面环）。
- **阻尼比仍是论文的按节径取值**，不是实测模态阻尼。

## 14. S8-3：让踏面变形进入侵入量

§13 结束时接触仍在**未变形**踏面上搜索，所以模态位移再大也不改力。这一节是把它接上。

### 14.1 一行接口

`_deform_geometry(geometry, rail, q)`：取该轴模态块、该侧胎面环，用与力投影**同一组权重**读出接触点处的 z 位移，然后

```
penetration_m -= move_z          # z 向上为正：钢抬起 → 侵入变浅
wheel_z_m     += move_z          # 搜索报出的高度跟着走，两处不许各说一套
```

放在 `_evaluate_patch` 里、`evaluate_contact` **之前**。顺序是内容而不是风格：力律是 `C·δ^1.5`，若在力上打补丁而 δ 不变，`sqrt(δ)` 的刚度就永远看不到变形，1.3 mm 深侵入下的非对称性也会被抹平。

### 14.2 先把"1.13 而不是 1.49"这件事查清

第一次量到的比值是 +20 µm → 0.8707、−20 µm → 1.1351，而我按冻结基线的 δ = 65.5 µm 预期 1.49 / 0.579。追下去发现**是我的预期错了**：这个算例（`examples/vehicle_v2` 的派生）本来的侵入是 **226.9 µm**、法向力 64.4 kN，不是 65.5 µm。代入 δ = 226.9 µm：

| 方向 | 实测比 | `((δ∓20)/δ)^1.5`（δ = 226.9 µm） |
|---|---|---|
| 胎面抬高 20 µm | 0.8707 | 0.8707 |
| 胎面下沉 20 µm | 1.1351 | 1.1351 |

**逐位吻合到 1e-6**（`test_the_force_follows_the_new_depth` 就是这条）。所以这不是"接近"，是恒等式；先前那个越看越可疑的 1.13 是拿别的算例的侵入量当分母算出来的。

### 14.3 镜像：一套振型服务两个车轮

同一组 q 在右环给出 `d_z = −0.030362 m`，在左环给出 `+0.031220 m` —— 符号相反，幅值差 2.8%（网格不对称，与 33 阶频率散布同源）。所以对称算例上"全局峰值"的比值会把两侧混在一起：+20 µm 时右轨 0.8707、左轨 1.1259，看上去像"机理只做了一半"，实际是两侧在往相反方向动。

### 14.4 测试（`tests/test_modal_deformation.py`，5 项）

| 测试 | 钉住什么 |
|---|---|
| 模态 q 全零时几何原样返回 | `is geometry`（同对象，不是相等） |
| 侵入按位移本身平移 | ±20 µm → `penetration_m` 差 1e-15 内精确 |
| 两侧互为镜像 | 同一 q → 一正一负，幅值 8% 内 |
| **力跟着新深度走** | `F'/F == ((δ−d)/δ)^1.5`，1e-6；且 `geometry.penetration_m` 同步 |
| 刚性算例永不形变 | `contact_coupling is None`，连尾部的假 q 也进不去 |

### 14.5 仍缺的一半（下一个增量）

- **接触点不随振型横向移动**：论文（陈嘉胤 §2.2）与 VSD 2017 都是在**变形后的踏面**上重新搜索接触点，`x = x_rigid + Φq`，横移会改变接触点的型面斜率，进而改变法向方向与力臂。本增量只补了深度这一个标量，法向方向仍是刚体的。
- **一系与重力的 Φᵀ 投影**未做（需要轴座处的振型，目前只出了胎面环）。
- **解析雅可比不知道 ∂δ/∂q**：`jacobian.py` 里模态块只有 `−K`、`−C`，没有这条耦合；隐式积分器因此会退化成不精确牛顿。这一条必须在启用 `jacobian="analytic"` + 柔性轮对之前处理。
