这份文件回答一个问题：**用 `F:\ai道岔状态反演辨识\75kmh数据` 这四条记录，我们能声称什么、不能声称什么。**
每一条都带判据和复算命令；不能声称的部分同时写明是**数据限制**还是**物理/算法限制**。

## 2. 能声称的（都有数）

### 2.1 检出（prominence，6 dB，25 m 窗 / 5 m 步）

**6 个预注册区段检出 3 个**（S2 差 0.5 dB 未过门限），段级虚警按 5 % 校准，二项尾概率 **0.0022**。
这一条在 `docs/MEASURED_VALIDATION_2026-10-26.md`，判据写在代码之前。

### 2.2 波长锁定的**必要条件**成立

同一 27.5 mm 波长在四个速度上的设计频率 412.5 / 510.1 / 616.5 / 764.9 Hz，相邻比 1.237 / 1.209 / 1.241
与速度比逐位一致。**这是"该特征来自轨道几何而不是车辆模态"的必要条件**，四个速度同时满足。

### 2.3 频段归属可以做成"移动 vs 不动"

40.83 与 75.73 km/h 的比值 1.855：轨距锁定峰按 1.855 位移，车辆模态不动。这是本数据集**唯一可用的
标定通道**（不需要廓形真值）。

### 2.4 L0/L1 通过

里程/单位/采样率台账齐全；两条轴箱通道共位，互相关滞后 **2.25 ms**（判据 ≤25 ms）。

## 3. 不能声称的、以及为什么

| 不能声称 | 判据失败在哪里 | 归类 |
|---|---|---|
| 27.5 mm 的定量深度 | 24 个「区段-速度」只有 **3 个**在 `f=v/λ` 上有峰；其余读的是本底（深度散布 0.3–85.5 µm，**337×**） | **数据限制**：区段短（1–7 个 2.05 s 块）、单速度单方向 |
| 60 mm 的定量深度 | 换到 60 mm + 2.05 s 块后，峰**只在 S1** 出现（3/22），且 S1 三个速度的深度 8.9 / 27.0 / 12.1 µm（**3.0×**） | **数据限制**：S1 只有 57 m，其它区段没有同一条线 |
| "短波定值与速度无关" | 60 mm 在 S1 的三个速度上差 3 倍 | **暂不可分辨**：既可能是算子随速度变，也可能是三条记录的轨面状态不同（无真值可判） |
| 车辆模态标定（SSI/FDD） | Cov-SSI 未稳定收敛（12/154 极点稳定）；FDD 脊在 4–6 区段重复但**无法归属** | **数据限制 + 方法限制**：单方向、单通道对、无激励台账 |
| 幅值/深度绝对精度 | 全链路没有一份同区段廓形真值 | **数据限制**：物理上不可绕过 |

## 4. 只有新数据能解锁的（明确写清需要什么）

| 要做的事 | 需要的数据 |
|---|---|
| 定量深度 | 同区段的廓形测量（轨检车 / 手持廓形仪 / 弦测），哪怕只有 3 个区段 |
| 算子随速度是否变 | 同一区段 ≥3 个稳态速度、同方向、同一转向架（现在 40 与 60 反向，混入了方向差异） |
| 车辆模态标定 | 同区段两条不同速度的**互功率谱**（相频可把车辆传递函数从轨道谱里分出来） |
| 曲线侧 | 曲线段的实测记录（现有四条都在直线/大半径段） |

## 6. 一句话

**能声称"这条轨道上哪些区段有波磨、这条线属于轨道而不是车辆"；不能声称"这条波磨有多深"。**
前者已经有数和判据，后者卡在数据（无廓形真值、区段太短），不是卡在算法——这一点本轮用四速度把
"波长选错"和"分辨率不够"两个候选都排除之后才敢写。
