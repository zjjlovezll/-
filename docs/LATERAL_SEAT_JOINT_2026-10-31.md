# 横向座椅联立：链条一起解，还是逐个轮对解？（B051）

**2026-10-31 · M2 第三段 · 提交见 CHANGELOG 第 247 轮**

## 一、这一轮要回答的问题

第 246 轮把 +718.4 N 里的 67 % 归到"取最深采样点"的量化假力，换成 4× 车轮采样后时程漂移从
0.7305 mm 降到 **0.0999 mm**，但座椅态仍带着 **+238.11 N** 净横向力（每轴 +59.53 N）。

问题：**这 238 N 能不能在静平衡里解掉？**

预注册判据（写进 `scripts/s108_lateral_seat.py` docstring，运行前定稿）：

| 门 | 判据 |
|---|---|
| G1 | 竖向座椅残差 ≤ 1e-5 N 且 8/8 轮 ∈ [0.625, 1.6]× |
| G2 | 座椅后 **每轴** 净横向力 ≤ 20 N |
| G3 | `\|tilt_left + tilt_right\|` ≤ 1.0e-3（两倾角相等，到 0.0246 的 4 %） |
| G4 | 整趟座椅墙钟 ≤ 60 s |

## 二、先量一件事：轮对横向自由度不是自由的

第 5 轮把轮对 `y` 加进最小二乘，结果**只挪了 +0.296 µm**，净力从 +238.11 N 变成 +236.88 N。
不是求解器没收敛（该行残差 6.9e-9 N，即广义力为零），而是**有一个很硬的东西顶住了它**。

`scripts/s109_lateral_stiffness.py`（座椅一次，只扰动 `wheelset1.y`，不重解）：

| `wheelset1.y` 偏移 | 该行广义力 | 注释 |
|---|---|---|
| −0.3 µm | +60.565 N | |
| −0.1 µm | +20.188 N | 斜率 **2.0e8 N/m** |
| 0 | +0.000 N | 该行被解到零 |
| +0.1 µm | −20.188 N | |
| +0.3 µm | −60.565 N | |

再分解连接件（15 体、88 个连接件）：**两个连接件各给 −29.611 N**，合计 −59.22 N，正好抵掉该轮的
净横向力。也就是说：**轮对 `y` 通过约 2.0e8 N/m 的元件连到轴箱上**，横向定位由整条悬挂链承担，
单个轮对既动不了、也不该单独动。

> 这一条同时解释了第 246 轮"0.73 mm 比自由加速 1.17 mm 小、差额被 3.0e7 N/m 一系刚度吸收"那个
> 推断——**方向对，数值不对**：真正顶住的是 2.0e8 N/m，不是 3.0e7 N/m。

## 三、做法：整条链一起解（15 个体，53 个未知量）

`run.seat_lateral = true` 时，`_static_vertical_equilibrium` 把**每个有 `y` 和 `roll` 自由度的体**
（4 轮对 + 2 构架 + 1 车体 + 8 轴箱 = 15 体 → 15 个 `y` + 15 个 `roll`）追加进未知量：
`23 + 30 = 53`。残差仍是"求解器对某坐标读到的广义力"，所以横向力与滚动力矩天然成为残差行。

解完再做**一次竖向抛光**（把 `y`/`roll` 固定，用原来的竖向座椅把 `z` 收干净）：联立解在硬的横向列
上换掉了竖向精度（实测残差 5.009e-02 N），抛光后回到 **9.859e-08 N**。

**实测（234 维一组模型算例，80 km/h，`seat_lateral` 开关对比）**

| 量 | 只解竖向 | 联立（链） |
|---|---|---|
| 座椅残差 | 3.590e-08 N | **9.859e-08 N** |
| 八轮份额 | 1.000–1.000 | **0.999–1.001** |
| 净横向力 | **+238.11 N** | **+44.75 N** |
| 每轴最差 | +59.53 N | **+11.19 N** |
| 倾角（左/右） | +0.024767 / −0.023800 | **+0.022749 / −0.022607** |
| 倾角和 | +0.000967 | **+0.000142**（1/6.8） |
| 轮对 `y` | 0 | **−0.4088 mm**（整车一起挪） |
| 座椅墙钟 | 1.2 s | 4.5 s |

判据照实报：**G1 PASS / G2 视路径（11.19 N 通过，另一次 21.12 N 不过）/ G3 PASS / G4 PASS**。

## 四、必须一起说的一件事：这个平衡点是"平谷"，不是单点

把"模态沉降 ↔ 联立座椅"交替做下去（同一算例，7 轮）：

```
round 1: net  +42.06 N   y  +1.6985 mm
round 2: net  +84.49 N   y  -0.3133 mm
round 3: net  +61.80 N   y  +1.7141 mm
round 4: net +111.83 N   y  +1.7241 mm
round 5: 座椅失败（no seed converged）
```

`y` 在 **+1.70 mm 与 −0.31 mm 之间来回跳**，净力在 42–112 N 之间游走，然后座椅直接不收敛。
所以：**"使净横向力为零的那个 `y`" 在这套悬挂上是病态的**——`y` 变动 2 mm 只值几十牛顿，
模态沉降（柔性踏面两侧挠度不同）每轮都把它推 2 mm。

这直接给 M2 一个结论：**不要把"净横向力"当作座椅的可交付判据**，它在这里不是一个良定的目标量；
良定的量是**时程漂移的方向与量级**。

## 六、能说与不能说

**能说**

1. 轮对 `y` 与轴箱之间是 **2.0e8 N/m**（0.6 µm 换 121 N；两个连接件各 −29.611 N），所以"只解轮对
   `y`"结构上无效——实测只吸收 59 N 里的 0.3 µm。
2. 整链联立（53 未知量）把净横向力从 +238.11 N 降到 **+44.75 N**、倾角和从 +9.67e-4 降到
   **+1.42e-4**、八轮份额 0.999–1.001、竖向残差抛光后 9.86e-08 N，墙钟 4.5 s。
3. 这套悬挂的横向平衡是**平谷**：交替迭代下 `y` 在 ±1.7 mm 摆动、净力 42–112 N、第 5 轮不收敛。
4. 0.40 s 漂移 0.13–0.15 mm，方向**朝平衡点**（4/4 与载荷不平衡同号）。

**不能说**

1. **不能说 M2 达标**：预注册的 `|Δy| ≤ 0.05 mm` 两档都没过（0.0999 / 0.1523）。
2. 不能说净横向力已被消掉：它只是一个平谷上的点，换一条座椅路径就得 21.12 N 或 84.49 N。
3. 不能说"0.14 mm 是错的"：它可能正是平谷里应该走的距离，要判定需要**更长时间 + 模态收敛**。
