# Velch 0.4.21 发布说明

发布日：2026-10-23　｜　和 0.4.20 的差别：**页眉多了「已知问题」**。

## 这一版改了什么

- 页眉新增「已知问题」窗口：每条已知未修项一行标题 + 一段"该怎么办"，按 `open` / `by_design` /
  `closed` 三态着色。顶部一句"已知未修 3 项，另有 1 项是设计约束"。
- 数据住在 `velch/open_items.py`（程序可读），`docs/BUGS.md` 仍是人读账本；两者由
  `tests/test_open_items.py` 双向守卫，谁先漂移谁红。
- `docs/BUGS.md` 里过期的 `O006` 行更正为 ✅ 已实现（0.4.10）。

## 仍然没有的四项

1. Simpack 横向布置的双侧导入（`O008`，需要两条轨都有断面表的模型）。
2. Simpack 侧轴重/刚度/阻尼只作对照（`O005`，设计约束）。
3. 没有代码签名。
4. `physics_validation_status` 仍未标定。

## 验证

- `pytest` **601 passed, 1 skipped**
- `--selftest` 7 屏 0 报错、退出码 0
- 截图核验：窗口列出四条待修/约束项，颜色区分正确
