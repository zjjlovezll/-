# Velch 0.4.32 发布说明

日期：2026-10-24。这一版没有新功能，只有一条**判决**与它的证据。

## 本轮结论

用轴箱加速度反演轨面不平顺的线性路线，走到头了：两带（0.1 m、2.0 m）可分辨、单带标定下闭环 8.39 %，
但绝对误差 65 %（门槛 30 %）。本轮新增的**双带同时激励**实验给出判决：同一带只因为另一个带同时在振，
增益就变 14 %，闭环也跟着退化到 14.28 % → **线性常数矩阵不成立，继续调 λ/加带/加平均都不会收敛**。

主张因此显式降级（任务书 §5d）：可以说"两带可分辨、闭环自洽"；不能说"30 % 精度内反演幅值"。
下一步只有非线性辨识（分段 `H(A)` 或可微代理）。
