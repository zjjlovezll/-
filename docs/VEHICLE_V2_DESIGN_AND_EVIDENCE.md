# Velch v0.2：车辆—轮对—道岔轨道耦合的证据与实现

## 结论范围

v0.2 新增独立可运行的 4 轮对、2 转向架、1 车体车辆模型。车辆 35 个广义自由度；合成算例每轴设左基本轨、右基本轨、右尖轨各一个双向轨道补丁，合计 59 自由度。车辆纵向速度仍为规定输入；轨道补丁仅有横、竖平移。此次**没有**实现用户计划的轨枕、扣件、板下胶垫、轨道板动力学，亦没有把 Simpack 反编译伪代码当成方程源码。

## 本版方程与接口

状态顺序见 `vehicle_solver.py` 和 `manifest.json`：4 轮对各 `[y,z,roll,spin,yaw]`，2 转向架和车体各 `[y,z,roll,pitch,yaw]`，然后每个轨道补丁 `[y,z]`。这里相对横/竖平移和小转角是降阶坐标，**索引顺序与 MATLAB 不完全相同**。

每个一系/二系连接器定义变形 `e=Jq-e₀`、变形速度 `ė=Jq̇`。广义力为 `Q=−Jᵀ(ke+cė)`，刚度贡献 `K=JᵀkJ`，阻尼贡献 `C=JᵀcJ`。左右弹簧用横向臂长产生侧滚，前后安装点用纵向臂长产生点头和摇头耦合。`e₀` 由质量、重力和弹簧数量形成合成算例的名义静载；竖向静平衡求根后才开始时域积分。该预载规则是 Velch 的独立选择，并非从 Simpack 求得。

每个轮对在规定里程 `x_i(t)=x_start+v t+x_i` 读取对应轨型。v0.1 的图形截面法向力和双向蠕滑力被复用；每轴可同时有多根候选轨。轮对与轨道补丁接触平移力严格相反。纵向运动由外部规定，故纵向接触力对应的车体平动反力没有被求解，能量变化可包含外部驱动/截面运动功。轮对摇头角只以小角攻角近似进入横向蠕滑，并未旋转完整三维轮廓。

## 执行与核对

```powershell
cd 'F:\ai道岔状态反演辨识\Velch'
python examples\make_vehicle_v2_case.py
$env:PYTHONPATH='src'
python -m velch run-vehicle examples\vehicle_v2\case.json --output examples\vehicle_v2\output
python diagnostics\vehicle_v2_checks.py
python -m pytest -q --basetemp .pytest_tmp
```

合成样例 59 DOF、12 轨道补丁、30 个连接器。`manifest.json` 保存算例与截面 SHA-256、状态顺序和质量门。已通过竖向静平衡残差、平移作用反作用、非负侵入量、摩擦上界、接触区域边界、步长减半以及固定截面零耗散能量试验。`vehicle_v2_checks.json` 给出数值差异。右尖轨只在第 1 轮对的指定过岔事件中出现活动输出，表明 4 个轮对按各自里程采样。

## 适用边界与第三版接口

本版没有 MATLAB 追加的 16 个非线性减振器自由度、非线性止挡、完整车体六自由度、轮对纵向平动、轮轨三维曲面、多点斑、柔性轮对、长轨连续梁/模态耦合，以及实车/Simpack 同工况误差检验。示例中的轨道补丁彼此没有沿线路的弯曲耦合，所有车轮轨道接触参数与轨道几何都是合成演示输入。因此结果仅标 `numerically_checked`。

第三版拟保持本版车辆状态和接触接口，替换当前轨道补丁 `support` 为“钢轨—扣件—轨枕—板下胶垫—轨道板”的独立质量、刚度、阻尼层；每层建立相互作用力与能量核对。**本轮没有实现第三版，也未把现有 H 盘模型中的 ballast 元件等同于板下胶垫。**
