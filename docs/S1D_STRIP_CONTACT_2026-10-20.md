# S1-d：分布接触（条带积分）——实现与 A/B

日期：2026-10-20 　代码：`Velch/src/velch/contact.py::find_strip_contact` 　算例：`validation/crh380a_m/case_frog_N_*`

## 1. 为什么做这一步

S1-c 用频谱判据排除了"接触点在采样节点之间跳动"这个候选（150–250 Hz 份额
73.9% → 72.5%，主频不变）。剩下的解释只有一个：**单点赫兹弹簧本身就是一个
硬弹簧**。1780 kg 轮对压在它上面，任何几何激励都会激起 ~150 Hz 量级的振荡。

而厂商的 `rw.cont.meth = 2` 是**离散弹性接触**（`p_eqv` 通道恒 0 是它的指纹，
`cont_disc_delta = 5e-4` 是它的离散步长）。它把载荷分布在一条斑上，最深的那
一条卸载时，旁边的条带仍在承载——这是单点律在原理上做不到的。

## 2. 实现

`find_strip_contact()`，策略名 `contact.normal_policy = "strip_integral"`（默认
`"point_hertz"`，旧算例逐位不变）：

- 在轮/轨重叠带内按 `strip_dy_m`（默认 0.25 mm）离散，取法向投影间隙 `δ(y)`；
- 每条带用平面应变赫兹线载荷 `n = (π/4) E* δ` 积分：`N = (π/4) E* Σ max(δ,0) Δy`；
- 返回**自洽的一对**：等效侵入 `δ_eq = (N/C)^(2/3)` 与单点刚度 `C = (4/3)E*√R*`。
  这样下游（阻尼、蠕滑饱和、history 通道、7 项数值门）**一行都不用改**，
  而积分出来的力被精确保留；
- 法向角度取"压得最深的那条带"，因为两肩接触时质心可能落在中间的槽里，
  那里的斜率不能代表接触；
- 需要 `E*`，所以要求 `stiffness_policy = "local_circular"`（否则显式报错，
  不静默退化）。

测试 `tests/test_contact_strip.py`（5 项）：自洽性（力 = 刚度 × 侵入^1.5）、
槽形两侧肩部保持承载（比单点律软 2.6 倍）、无接触返回 `None`、缺 `E*` 报错、
策略名校验。**全套 56 passed。**

## 3. 两次修 bug 的过程（必须留档）

1. **第一次**：`find_graph_contact` 转调 `find_strip_contact` 时漏传
   `stiffness_policy`，于是条带律永远走 `effective_radius_m = 0.02` 的回退分支，
   给出 `R* = 0.0200 m`、`C = 2.148e10`。这个 bug 让侵入变成 0.447 mm，
   恰好"接近"Simpack 的 0.424 mm——**那是一个假的一致**，已作废。
2. **第二次**：曲率拟合窗口用 `max(0.5·strip_dy, 1 mm)`，而轮型面节点间距
   0.49 mm，±1 mm 内只有 4 个点 < 5，`_window_quadratic` 返回 `None`，
   于是又回退到固定半径。改为 `max(1 mm, 2.5×各带节点间距)` 后，
   `R* = 0.6609 m`（右）、`0.6344 m`（左），落在 MATLAB 三条公式给出的
   0.55–0.71 m 区间内；`C = 1.235e11`，与厂商反算的 1.117e11 差 10.5%。

`probe_policy.py`（新建）就是为抓这类"策略没生效"而写的：它打印实际生效的
策略名、接触点、`R*`、`C`、`N`，比看峰值可靠。

同时输出绝对 band RMS，判据也改成绝对值。

## 6. 158.4 Hz 是什么（下一次要证的）

窗口只有 0.05 s / 101 点 → 分辨率 19.8 Hz，158.4 Hz 只是第 8 个频点，真实峰在
138–178 Hz 之间。两个候选：

1. **轮对压在接触弹簧上的弹跳模态**：`f = √(K/m)/2π`，`K ≈ 1.2e11·1.5·√δ` 在
   工作点约 `8e8 N/m`、`m = 1780 kg` → ~110 Hz。条带律在该工作点软了约 10%，
   主频却一点没动 → 说明它不是由接触刚度单独决定的模态。
2. **轨下离散支撑（600 mm 岔枕）**：图纸附注 7 明确"岔枕全部垂直于直股、
   间距 600 mm"；350 km/h 下 `f = 97.2/0.600 = 162 Hz`，正落在上面那个区间里。
   我们的轨道目前是**刚性**的，理论上不该出现这个频率；要证实/证伪，
   必须把轨下结构建出来（原四阶段计划的第③步）。

所以 S1-d 的结论是：**接触律能改幅度，改不了频率**；频率指向轨下支撑或几何周期。
