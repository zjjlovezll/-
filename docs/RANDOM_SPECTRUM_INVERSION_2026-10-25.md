# 随机谱 → 加速度 → 反演随机谱：三次实测与它们各自的结论

**问题（用户提出）**：生成一条随机不平顺谱，用它激励得到轴箱加速度，再从这个加速度反演出
"一条随机不平顺谱的激励"，与生成的那条**整体**对照，看精度。

**结论先说**：这件事能做，但**单次宽带随机激励做不到"整体一次反演"**。三次实测依次否掉了两个
做法、留下一个可用但有明确适用范围的：
① 单次随机轨迹 + 逐带比值 → 失败（激励淹没在车辆自身的本底里）；
② 换成"已知谱学传递、未知谱反演"（同一套参数的另一个种子）→ **出现假精度**，必须纠正；
③ 差分对（+A / −A 相减）→ 本底精确抵消（对照 0.00e+00），但只有**响亮的带**能反演，
安静的带被约 10–16 µm 的串扰底噪抬起。

## 1. 第一次：假精度（必须记下来）

最初的协议是"校准轨 A → 测传递，测试轨 B（同谱异种子）→ 反演"。结果：**8 个带里 6 个误差 0.0 %**，
看起来完美。它是假的。原因：

> 校准轨与测试轨**逐带幅值几乎相同**（同一条谱的两次实现），而当分析窗里包含起振瞬态时，
> 每个带的加速度 **≈ 无激励空跑的本底**（SNR 约 0 dB）。于是 `G = a_校准 / r_校准 ≈ 本底 / r_校准`，
> 反演结果 `a_测试 / G ≈ r_校准` —— **不管传递对不对，答案都等于校准轨的幅值**。

证据（`F:\velch_tmp\s9k\random_spectrum.json` 第一次运行）：`german_low` 8 个带的 SNR 全在
−0.1…+1.7 dB，而"反演值"逐带等于校准值。**所以任何"同谱异种子"的验证都必须让测试谱与校准谱
在逐带上明显不同**，否则得到的是自证。

## 2. 第二次：异形谱 + 逐带比值 —— 失败

把测试谱换成逐带 ×0.4…2.4 的异形谱，再跑"校准 → 反演"（`s9k`，每设计 3 次运行）：

`german_low`（测试轨整体 rms 11.96 µm，校准轨 13.31 µm）：

| 带 (m) | 校准 | 真值 | 反演 | 误差 | SNR |
|---|---|---|---|---|---|
| 0.05–0.1 | 0.014 | 0.031 | 0.006 | −80 % | 0.6 dB |
| 0.1–0.2 | 0.040 | 0.018 | 0.041 | +130 % | 0.0 |
| 0.2–0.4 | 0.113 | 0.192 | 0.116 | −40 % | 0.0 |
| 0.4–0.8 | 0.319 | 0.175 | 0.323 | +85 % | 0.0 |
| 0.8–1.6 | 0.889 | 2.134 | 0.898 | −58 % | 0.0 |
| 1.6–3.2 | 2.433 | 1.460 | 2.461 | +69 % | 0.0 |
| 3.2–6.4 | 5.953 | 10.716 | 5.961 | −44 % | 0.0 |
| 6.4–12.5 | 11.612 | 4.645 | 11.608 | +150 % | 0.0 |

**反演列逐行等于校准列**（0.006≈0.014、0.041≈0.040、0.116≈0.113 …），误差全部来自"测试谱与校准谱
不同"，而不是来自反演。SNR 一列说明原因：7 个带里"有激励"与"零激励"的带 rms **无法区分**。
可定量的带数：**0 / 0**（没有任何带越过本底门）。

`flat` 设计同样失败（0 个可用带），唯一越过本底的是 0.05–0.1 m 带（SNR 27 dB），那里反演 20.2 µm
对真值 11.0 µm（**+83 %**）。

## 3. 第三次：差分对 —— 本底精确抵消，但只剩响亮的带

用 S7e 的做法：同一算例跑 `+A` 与 `−A`，取 `(a(+A) − a(−A))/2`。凡是**不随激励变化**的部分（起振瞬态、
车辆自身模态的余振、轨道几何）两次相同，**精确抵消**——对照组（零激励 ± 零激励）的逐带结果为
**0.00e+00**，这是这台机器上能做到的最干净的零。

`flat` 校准谱（每带 5 µm）→ 异形测试谱（每带 2–12 µm），4 次运行 1532 s：

| 带 (m) | G (m/s²)/m | 真值 | 反演 | 误差 | dB |
|---|---|---|---|---|---|
| 0.05–0.1 | 9 557 | 11.0 | 9.26 | **−16 %** | −1.50 ✔ |
| 0.1–0.2 | 11 780 | 2.25 | 4.46 | +98 % | +5.95 |
| 0.2–0.4 | 1 426 | 8.50 | 10.77 | +27 % | +2.06 ✘（差一点） |
| 0.4–0.8 | 4 406 | 2.75 | 10.28 | +274 % | +11.45 |
| 0.8–1.6 | 122 700 | 12.0 | 13.35 | **+11 %** | +0.93 ✔ |
| 1.6–3.2 | 190 700 | 3.00 | 14.72 | +391 % | +13.82 |
| 3.2–6.4 | 5 063 | 9.00 | 16.39 | +82 % | +5.21 |
| 6.4–12.5 | 4 147 | 2.00 | 16.43 | +721 % | +18.29 |

**判据结果：2 / 8 个带 ≤2 dB。**

但表里有一个清晰的模式，比"2/8"更有信息量：

- 真值 ≥ 8.5 µm 的四个带：11.0→9.26、8.50→10.77、12.0→13.35、9.00→16.39，即 **−16 % … +82 %**；
- 真值 ≤ 3 µm 的四个带：2.25→4.46、2.75→10.28、3.00→14.72、2.00→16.43，反演值全部**挤在
  4–16 µm**，与真值无关。

读法：存在一个**约 10–16 µm（等效深度）的逐带串扰底**。低于这个水平的带，反演输出的不是它自己，
而是"相邻带经过接触非线性折过来的能量"。这与我们此前"没有常数 H、叠加误差 61.5/213/210 %"
是同一条物理：单边 Hertz 接触 + 蠕滑饱和，使带与带之间**互相泄漏**。

## 4. 结论（对一个"随机谱整体反演"的问题）

1. **能做**：只要某带的真值高于串扰底（本例约 10 µm），它的幅值就能被反演到 −16 % … +82 %
   （随带而异，不是常数）；
2. **不能一次做完**：一条真实的 `german_low` 在 0.05–6.4 m 各带的 rms 是 0.01–6 µm，**几乎全部落在
   串扰底之下**；用单次宽带激励去反演整条谱，得到的会是校准谱的形状；
3. **窄带仍成立**：此前用单一波长（25/50/100 mm）测到的 10 %–25 % 与 20/40 m 的 0.7 %–3.8 %
   不受影响——它们是"一次只激励一个带"，天然没有带间串扰；
4. **要"整体"就必须分带做**：逐带窄带激励（或用带限噪声逐带扫），把每带的传递与串扰底一起标定，
   再合成整条谱。这样做的代价是带宽 × 8 次运行，换来的是可定义的分带精度。

## 6. 边界

- 单一车型、单轴单侧、刚性轨道、80 km/h；
- 谱只有 `german_low` 与平坦两种形状，`TEST_SCALES` 是固定的一组，不是统计分布；
- 串扰底"10–16 µm"是这一组运行的读数，尚未扫幅值（若它与幅值成比例，则"信噪比墙"会随线路等级移动）；
- 没有传感器噪声，没有实测参与。
