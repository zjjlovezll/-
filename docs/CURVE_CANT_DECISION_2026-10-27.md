# ADR：几何路由上的超高，为什么仍然拒绝

状态：**保留拒绝**（2026-10-27）。力路由（`curve_geometry: false`）的超高可用，几何路由不可用。

## 1. 这一轮试的是什么

第 34–44 轮已经把超高在几何路由上"发布三次再撤三次"：轨面旋转（`RolledSeries`）、外轨抬高（`rise`）、
车辆随坡面 roll（`_place_on_alignment`）。这一轮补上第四节——**把重力放进倾斜坐标系**
（`force[y] += m g sin(phi) inward`，`force[z] -= m g (1 - cos phi)`），并恢复被写死成 `rise = 0.0`
的外轨抬高。

结果：`cant0` 的几何曲线仍然 `numerically_checked`、7/7 通过（说明两处改动对无超高工况是惰性的），
而 `cant = 0.107 m` 的工况**在加载阶段就被 `F:\ai道岔状态反演辨识\Velch\src\velch\vehicle.py:503`
拒绝**，拒绝理由不变。于是两处改动在当前配置下都是死代码，已回退。

## 2. 为什么补上倾角还不够（算术）

设轨距 `g = 1.493 m`、半轨距 `b = 0.7465 m`、超高 `h = 0.107 m`（R=1100 m、100 km/h 的平衡超高）、
`phi = asin(h/g) = 0.071729 rad`、车轮半径 `R = 0.43 m`。

| 量 | 值 | 由谁提供 |
|---|---|---|
| 外轨抬高 | `+b sin phi` = **+53.5 mm** | `_curve_placement` 的 `rise` |
| 内轨降低 | `-b sin phi` = **-53.5 mm** | 同上 |
| 车轮随 roll 的竖直位移 | `±b sin phi` = **±53.5 mm**（左右相反） | 轮对 `roll` 坐标 = `+phi` |
| 滚动圆接触点的横向位移 | `R sin phi` = **30.8 mm**（向曲线内侧） | 轮对 roll |

也就是说：**抬高与 roll 必须成对出现，且符号一致**；缺一边就是 `2 b sin phi = 107 mm` 的错位——这与
第 38 轮实测的"峰峰 103 mm"一致（103 = 2·b·sinφ 在 0.069 rad 下的值）。

补上重力倾角解决的是**横向力**这一半（平衡超高时重力沿坡面的分量抵消 `m v²/R`），但**不解决竖向错位**
这一半。竖向错位需要静平衡同时解出**每个轮对的 z 与 roll**，而：
- 速度为 0 时横向方程没有平衡解（蠕滑力为零，见 `Elkins & Gostling 1977` 的准静态曲线通过理论），
  第 30 轮实测：以 z+y+roll 为未知量时 `cond = 3.76e12`、最小奇异值 `2.7e-11`、所有种子停在 `|r| = 2.39`（240 kN）；
- 只解 z（第 31 轮）能收敛到 `1.07e-12` 与八轮 65.47 µm，但那是**无超高**的情形。

真正的物理是：刚性轮对两侧走不同的滚动圆半径（锥度）才能同时贴住两条不同高度的轨——这需要**轮对横向
位置 + roll + 接触点搜索**一起解，属于**运行态**平衡，不是静平衡。

## 3. 决定

1. **几何路由继续拒绝 `curve_cant_m != 0`**，理由保留在代码里（`vehicle.py:503`），并把本 ADR 的算术补进
   注释，让下一个人不必重推。
2. **力路由的超高可用**：`curve_geometry: false` + `curve_cant_m = 0.107` 在 R=1100 m、100 km/h 下
   `numerically_checked`、7/7、八轮 59 652–59 708 N（平衡超高，等分 59 662 N）。
3. **要支持几何路由的超高，正路是"运行态坐车"**：先用无超高几何曲线坐到 8/8，再以 `cant` 为参数在
   时间推进中把坡面"抬"进去（每步重解 z/roll，横向方程由蠕滑力闭合），或在第一步就以 `v > 0` 的姿态
   做一次带速度的平衡。这条属于 item 4 的后续，不在本轮实现。
4. 不允许的做法（已写进目标硬约束）：放宽容差、加大接触搜索窗、提高接触刚度把失败变绿。

## 5. 边界

- 这条 ADR 只关几何路由的超高；**无超高几何曲线（R=350/80 km/h、R=1100/100 km/h）是可引用的**；
- 力路由的超高是"等效直线"近似：轨道质量不承受离心力、超高只改力不改几何——这两条限制在
  `docs/CURVE_SEAT_AND_CREEP_2026-10-27.md` 里已写明，本 ADR 不改动它们。
