# 非线性力元

**日期**：2026-10-23 · **版本**：0.4.28

## 1. 为什么需要一条"非线性通道"

到 0.4.27 为止，求解器里的每个力元都是一条直线：

```
F = -(k·δ + c·δ̇)，δ = J·q − 预载
```

这对弹簧、减振器、衬套够用，但 Simpack 里真正决定过岔峰值的那几个元件都不是直线：
**止挡**（空行程后突然顶住）、**卸荷阀减振器**（速度超过阈值后阀门打开）、**空气簧**（刚度随
高度变）。它们的力律对位移/速度是分段的，而求解器的隐式积分器要的是**导数**，不是力。

所以这一版给 `Connector` 加了一个可选字段 `law`：有 `law` 时力来自 `law.force(δ, δ̇)`，
**局部斜率**来自 `law.stiffness(δ)` / `law.damping(δ̇)`，势能来自 `law.potential(δ)`。
三者必须自洽——`potential` 的导数就是 `−force`，这条由测试钉住，否则能量守恒会悄悄破掉。

## 2. 现在有的两种非线性元件

### 止挡 `bump_stop`

参数：`stiffness`（N/m，必填）、`gap_m`（m，缺省 0）、`preload_force`（N）。

```
行程 t = −δ − gap
F = −k·t      (t > 0，压缩到极限)
F = 0         (t ≤ 0，自由行程)
```

`gap_m = 0.002`、`k = 1e6` 时：压 1 mm 无力量，压 4 mm 得到 −2000 N，斜率 1e6 N/m。

### 卸荷阀减振器 `damper_blowoff`

参数：`low_speed_damping`（N·s/m）、`high_speed_damping`（N·s/m）、`blowoff_speed`（m/s），三个都必填且必须为正。

```
|δ̇| ≤ v₀ :  F = c₁·δ̇
|δ̇| > v₀ :  F = sign(δ̇)·(c₁·v₀ + c₂·(|δ̇| − v₀))
```

`c₁ = 4e4`、`c₂ = 5e3`、`v₀ = 0.05` 时：0.01 m/s → 400 N，0.05 → 2000 N，0.20 → 2750 N。

## 3. 求解器怎么用它

| 位置 | 线性 | 非线性 |
|---|---|---|
| 力 | `−(k·δ + c·δ̇)·J` | `−law.force(δ, δ̇)·J` |
| 雅可比（q 块） | `−k·J⊗J`（构造时算好） | `−law.stiffness(δ)·J⊗J`（**每个状态现算**） |
| 雅可比（v 块） | `−c·J⊗J`（构造时算好） | `−law.damping(δ̇)·J⊗J` |
| 机械能 | `½k·δ²` | `law.potential(δ)` |

只有带 `law` 的连接会走"现算"，其余仍用构造时缓存的那几块——所以**冻结基线的轨迹一位没动**
（`verify_vehicle_ref.py` 仍 `VERDICT: EQUIVALENT`，`history.csv` 逐位相同）。

## 4. 诚实地说清两条限制

1. **间隙处是 C0 而不是 C1**：δ 穿过 −gap 的那一瞬，斜率从 0 跳到 k。这就是真实止挡的物理，
   但隐式积分器会因此缩小步长（可能缩得很小）。我们**没有**做事件检测，也不打算在元件里偷偷把它
   抹平——要平滑得由建模的人显式给过渡段（下一步会给 `transition_m` 参数）。
2. **没有内部状态**：卸荷阀在这里是"速度的代数函数"，不是带滞回的状态机。真实减振器的阀片
   有开启/关闭的滞回环，要复现它必须给元件加状态量并让积分器一起积分——这是下一层工作。

## 5. 台架测试（怎么算"搬对了"）

`tests/test_elements_nonlinear.py` 7 项，不依赖车辆模型：

* 止挡的力-位移分段、斜率分段、**势能导数 = 力**（四个工作点，避开间隙点）；
* 卸荷阀的两段斜率、负速度对称、**dF/dδ̇ = 报告的阻尼**；
* 类型表里有这两个元件、参数名与单位正确；
* 缺参数/零参数被拒且报错带参数名；
* 装配出的 `LinkSpec` 带 `law` 而不是带刚度；
* **端到端**：拿真实算例，把一根二系垂向连接换成"已压到限位"的止挡，再用
  `frozen_geometry_error` 比较解析雅可比与中心差分（`dq_worst_column`、`dv_worst_column` 都 < 2e-4），
  并把预载放到未接合处确认那一行的刚度归零。
