# 直向横向：起点偏移是零，漂移是 B047（横向定位刚度 ~10³ 倍）

日期：2026-10-29（目标第 14 轮）
脚本：`scripts/s72_straight_stock_baseline.py`（新增 `lateral.csv` 与 `lateral_*` 汇总）、`scripts/s73_straight_pair.py`（新增 `--creep-kalker`，诊断专用）

## 一句话

直向算例的横向问题**不是**"初始就偏了"，而是**横向定位刚度比物理值大约三个数量级**——也就是早已登记过的 **B047**；
它同时解释了直向横向漂移、0.45 s 的左右载荷不均，以及把蠕滑刚度调到 Kalker 量级之后**更早**撞斜率门。

## 一、起点偏移是零，漂移是真的（40 → 50 m，0.45 s，80 km/h）

```
lateral start (mm): +0.0000, +0.0000, +0.0000, +0.0000     ← 四根轮对都在正中
lateral drift (mm): -37.7657, -21.3213, +0.1107, +0.5043   ← 0.45 s 后
```

前转向架两根轮对沿 −y 走了 **37.77 mm / 21.32 mm**，后转向架两根几乎不动（+0.11 / +0.50 mm）。
所以这是**导向轮对的横向失稳/游走**，不是座椅偏心。
（同时说明：`_seat` 只解垂向，横向初值是 0，这个"零"是可信的，不是没测。）

## 二、横向刚度实测：−235 kN/mm，比物理值大约 10³

在坐好的状态下把 `wheelset1` 横向平移 ±1/±2/±3 mm，冻结其它坐标求一次力：

| dy (mm) | ΣFy (kN) | ΣMz (kN·m) | 左斑 N (kN) | 右斑 N (kN) |
|---|---|---|---|---|
| −3.00 | **+705.2** | −537.2 | 1362.4 | **0（无接触）** |
| −2.00 | +162.6 | −402.3 | 669.9 | **0** |
| −1.00 | +44.4 | −195.6 | 297.4 | **0** |
| 0.00 | +0.7 | −8.5 | 65.7 | 53.8 |
| +1.00 | −36.5 | +177.1 | **0.8** | 267.2 |
| +2.00 | −147.0 | +376.0 | **0** | 621.8 |
| +3.00 | −564.3 | +586.4 | **0** | 1279.8 |

三点判读：

1. 斜率 ≈ **−235 kN/mm**（±3 mm 之间 1 269 kN / 6 mm）。一个 920 mm 车轮、1:40 踏面、等效锥度 λ≈0.05 的轮对，
   这个量级应是 **0.2–0.3 kN/mm**——差 **约 900 倍**，与已登记的 **B047「横向定位硬 927 倍」** 同一个数。
2. **±1 mm 就有一侧完全失去接触**（右斑 0 N / 左斑 0.8 kN）：物理上 1 mm 只让轨顶高度变 1.7 µm，
   不可能掉接触。这说明横向位移被映射成了**深度**尺度的变化，而不是沿轨顶的微小滑动。
3. 符号是**恢复**的（dy>0 给 −Fy），所以不是"发散的锥度"，而是"过硬的定位"——这和曲线侧"
   轨顶横向力被冻结在 2.5 %"（b33）是同一族病根的正反两面。

## 四、结论与下一步（顺序被改写）

- 直向横向问题的**根因是 B047**（横向定位刚度 ~10³ 倍），不是尖轨几何、不是座椅偏置、不是蠕滑标定；
- 因此尖轨区（50.578–57.304 m）与心轨区（103.28–116.44 m）的降低值反演，**都必须等 B047 定位清楚**；
- 下一步（预先写死的判据）：在 `contact_search` 里量出"横向位移 1 mm → 接触点/侵入量各自变化多少"，
  判定它是**型面横向标尺错**（`y_scale_m`/`y_offset_m`/镜像）还是**搜索的横向窗太窄**；
  判据：修好后 `dΣFy/dy` 落在 **0.05–0.5 kN/mm**，且 ±3 mm 内**不出现单侧掉接触**；
  再回到 0.45 s，要求漂移 < 1 mm。

## 二b、B047 的机制：1 mm 横向被映射成 ~210 µm 深度，因为接触落在轨距角而不是轨顶

在坐好的状态上逐点打印侵入量与接触点位置（`wheelset1` 横向平移 ±1 mm）：

| dy | 左斑 N / pen / lever_y | 右斑 N / pen / lever_y |
|---|---|---|
| 0 mm | 65.72 kN / **74.62 µm** / −0.73654 | 53.79 kN / **62.94 µm** / +0.73707 |
| +1 mm | 0.78 kN / 3.59 µm / −0.73927 | 267.22 kN / **273.09 µm** / +0.73083 |
| −1 mm | 297.38 kN / **292.12 µm** / −0.73041 | 0 kN / — / — |

两条读数直接指出机制：

1. **横向 1 mm → 深度 63→273 µm**（+210 µm）。物理上 r≈300 mm 的轨顶，1 mm 横向只对应 **1.7 µm** 高度变化，
   即这条链把横向放大了 **约 1.2×10⁵ 倍**（与 B047 的 927 倍是同一族，且量级更大）。
2. **`lever_y` 比两轨冠位置（∓0.75325）内移了 16.7 mm**（−0.73654 / +0.73707）。也就是说
   **车轮不是坐在轨顶上，而是压在轨距角/圆角上**——那里的型面坡度远大于 1:40，所以横向一动就是几百微米深度。

这正是 B047 的可用定义：**判据不是"力太大"，而是"接触点应当落在轨顶（|lever_y − 轨冠| ≲ 2 mm）"**。
所以下一步修的是**横向对位**（车轮滚动圆在断面里的 `local_y` 与轨冠的配准），而不是任何刚度。

三条读数：

1. **接触点在内外都不随车轮横移而移动**：车轮横移 36 mm（−0.7465 → −0.78275），`lever_y` 只从 −0.7365 变到 −0.7304（6 mm）。
   物理上接触点应当跟着横移走满 36 mm——这说明**接触是由轨头的一个离散特征决定的（内侧肩部/圆角）**，不是由"踏面压轨顶"决定的。
2. **刚度随车轮内移单调下降**（211.6 → 5.08 → 1.73 kN/mm，每 4 mm 约降 2 倍），方向与"接触从陡坡移向平台"一致。
3. **"把轨冠配准到轮距"这条捷径被否证**：把两轨冠精确移到 ±0.74650（与轮心同位置，实测 `crown y = ∓0.74650, z = +0.000072`）
   之后，座椅直接 `gtol` 不收敛——说明"轮心正上方就是踏面"这个假设不成立，**车轮断面在它自己的 y 坐标里是偏置的**
   （实测：`|y|<30 mm` 内最深的点在 `local y = ±0.0295, z = −0.43364`，比名义滚动圆 −0.4298 深 3.8 mm，
   也就是那个点已经在轮缘根上，不是踏面）。

所以下一轮的第一步不再是"调对位"，而是**读 `.prw` 原始点集，把踏面带（r ≈ 0.430 的那一段）在自己的 y 坐标里框出来**，
用它的中点做配准基准；在此之前任何对位扫描都只是在"轨头肩部"上滑动。

## 三、B047 的机制不在这条接触律，也不在蠕滑量级（第 221 轮）

### 3.3 所以 B047 的靶点是横向基准，不是律、也不是蠕滑

配合第 15 轮已量的两条（车轮横移 36 mm 而接触点只动 6 mm；dΣFy/dy = 211.6 kN/mm），机制收成一句话：

> **轮心正上方不是踏面**（`z_loaded = z_raw − 0.4411`，滚动圆在 `z_raw = +0.0111`），于是左右两侧各被安置在一个"比踏面深 3.6 mm"的轮缘根上；左右滚动半径因此不等，产生恒定的差动纵蠕滑 → 恒定摇头力矩 → 恒定横向速度。蠕滑系数放大只会把这个过程做得更快，这正是 Kalker 档 0.29 s 就撞门的原因。

## 二f、按 SDITT 的接触实现反查（这是本轮真正的线索）

用户建议"用 SDITT 跑曲线的代码来找我们的问题"。读过之后，SDITT 的接触层给出三处与我们**结构不同**的做法，
其中第一处直接解释了 25 µm/mm 与"理论 6.7"之间的差：

**① 它不用几何贯入量做 Hertz，而用"虚拟贯入量" `h_0 = ε·δ`（`NF_STRIPES_230623.m:41-43, 96-101`）**

```matlab
epsilon = (inp_n.^2) ./ inp_Con_r ./ (1+(inp_n./inp_m).^2);   % 曲率修正
h_0     = epsilon .* inp_Con_wheel_2_II(:,5);                 % 虚拟贯入量
...
NorGap_ConCS{i,5} = [ ... , NorGap_ConCS{i,4}(:,3)-NorGap_ConCS{i,3}(:,3)];   % 法向间隙
NorGap_ConCS{i,6} = [ ... , h_0(i,1)-NorGap_ConCS{i,5}(:,2)];                 % 虚拟渗透量
```

`m`、`n` 是接触点处**车轮与钢轨的横向曲率半径**，`r` 是滚动圆半径。也就是说：SDITT 的力对**间隙的
导数**是 `ε·(dδ/dy)`，而我们对同一个 `δ` 直接用 Hertz——`ε` 就是那个被我们漏掉的系数。
（对踏面/轨头 `m ≈ n ≈ 0.3 m`、`r = 0.43 m`：`ε = 0.09/0.43/2 = 0.105`，即 **十分之一**。）

**② 它的接触斑是"先把所有局部极小找出来再按 1 mm 去重"，不是围着上一帧的点开窗搜索**
（`Multi_Con_250812.m:309-354`：`sortrows(...,2)` 排序 + `y_lim` 去重，`limit_1 = 1e-3`）。
我们的 `find_strip_contact` 是"带种子 + `patch_window_m` 的局部搜索"，两者在**多斑/陡区**行为不同。

**③ 它的法向刚度来自一张 Hertz 表**（`Par_Con.m:5-26` 的 `BGmn`：`δ` 0.1–1.0 mm 对应半轴 a、b），
不是单一 `C·δ^1.5`。

**顺着 ① 再算一遍，就发现我们的法向刚度本身也不对**：

| 量 | 值 | 出处 |
|---|---|---|
| Hertz 在 δ = 65.47 µm、F = 59.68 kN 处的 `dF/dδ = 1.5F/δ` | **1 367 kN/mm** | 解析 |
| 同一式在我们的 strip 态（δ = 197.6 µm） | 453 kN/mm | 解析 |
| **实测** `dN/dδ = dN/dy ÷ dδ/dy = 9.74 / 0.0250` | **0.39 kN/mm** | 本轮 s91/s92 |

实测比解析软 **1 100 倍**。这不是"轨冠曲率"的问题——**载荷是被许多条带共同分摊的，单条带的 δ 变化几乎
不改变总力**，所以横向位移改变的不是"压多深"，而是"有几条带在压"。也正因如此，"25 µm/mm 比 6.7 µm/mm
硬 3.7 倍"这个比较从一开始就用错了框架：横向增益由**条带接合范围**决定，而不是由冠半径决定。

**下一轮的顺序（都被上面钉住）**：
1. 打印一个接触斑的**条带表**：条带数、每条带的 `δ_i`、`F_i`、以及 ΣF 对 δ 的偏导——确认"多带分摊"就是那个 1 100 倍；
2. 若确认，按 SDITT 的 ① 引入 `ε` 与 `m`/`n`/`r`（先做成默认关闭的选项，冻结基线不动），再看 `dN/dδ` 是否回到 10² kN/mm 量级；
3. 再做 ② 的"全极小 + 1 mm 去重"检测器，替代种子窗口。
