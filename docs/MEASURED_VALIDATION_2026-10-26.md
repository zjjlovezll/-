# 实测数据第一次验证：26 mm 波磨，声学 5/6、轴箱 3/6

这篇记录的是**我们第一次拿真实测量数据检验自己的东西**。结论有两层：论文的核心物理（波磨波长恒定在 26–30 mm）被一个**独立实现的指标**从零复现了；而"用振动还是用声学去发现它"，实测给出的是**声学更强**，不是我们原先假设的轴箱加速度。

## 1. 数据与真值

数据是随附论文的那套地铁实测（Soto-Ocampo et al., *Mathematics* 2025, **13**, 2815）：

| 项 | 内容 |
|---|---|
| 文件 | `Run_75kmh_E1toE2.mat`（117.8 MB，MATLAB 5） |
| 里程 | **3.798 – 6.303 km**（2.505 km） |
| 速度 | 均值 62.2 km/h、最大 85.4、两端降到 1.1 km/h（含起停） |
| 振动 | `Vi_y` **两个轴箱垂向加速度**，4 kHz / 16 bit（ICP KS-76C-100，100 mV/g，±60 g），rms 10.79（单位未标，若 m/s² 即 1.1 g） |
| 声学 | `So_y` **车内麦克风**，48 kHz / 32 bit，rms 0.132 |
| 速度/位置 | `Vi_Speed`（多普勒，km/h）、`Vi_pks`（**已经是 km**，由速度积分得到） |

论文 **Table 4** 给出了他们量到的中心频率与波长：75 km/h 下 **692–844 Hz ↔ 24.4–30.4 mm**，40–60 km/h 下频率随之下降而**波长基本不变**（24–31 mm）。

**这份数据里没有轨面剖面**，所以能验证的是**定位（有没有、在哪里）**，不是幅值反演。这一点在脚本的 docstring 里就写死了。

## 2. 指标（刻意与论文不同）

每个 **25 m 空间窗**（步长 5 m，一段 57–139 m 的区段因此有多个重叠估计），取两个轴箱里更差的那一路：

```
index_db = 10·log10( 带内 Welch PSD 峰值 / 带内 PSD 中位数 )
带 = 由**当地速度**把固定波长区间换算成频率：f = v/λ
```

关键设计：**带是随速度走的**，所以 40 km/h 与 75 km/h 问的是同一批波长——这正是论文的核心主张（"position depends on speed but wavelength remains constant"）。判据在跑之前写死：AUC（尺标无关）+ 段内峰值超过段外 95 分位（5 % 虚警）即算检出。

## 3. 第一次跑错了波段，而且错得很有信息量

最初按"波磨波长 20–350 mm"取带（那是文献综述里的通用范围）：

| 通道 | AUC | 段内中位 − 段外中位 | 检出 |
|---|---|---|---|
| 振动（轴箱） | 0.659 | +1.87 dB | 2/6 |
| 声学（麦克风） | **0.297** | **−1.62 dB** | 0/6 |

声学的 AUC 只有 0.297，**比随机还差**。这不是"声学不行"，而是提示**带选错了**：带太宽，26 mm 那条线被邻近内容淹没，指标测到的其实是别的东西。

## 5. 三条判读

1. **论文的物理被独立复现了。** 我用的是"带内峰/中位"的粗糙指标（不是他们的 IIAPD/EWISI 双指标），在**写完代码之前就把 18–40 mm 写进常量**（来自 Table 4），结果六段里五段在 5 % 虚警下被检出、定位误差 0 m。这不是"照着答案调参"。
2. **轴箱通道有信号但更弱：AUC 0.741 / 3 段。** 这与我们模型的预测一致——在 `f > f_n` 区，轴箱响应 `a ≈ (2πf_n)²·A` 对波长**不敏感**（一个常数），所以它天然不如声学那样区分"这一段的波磨线"，而且被道岔/接头的宽带冲击污染。0.741 说明信息在，但**换不来同等水平的检出率**。
3. **声学比轴箱强这条，只有实测能告诉我们。** 我们此前所有短波结论都建立在自己造的激励上（`gain ≈ 24 398 (m/s²)/m`、波长无关、10–25 % 幅度精度）。这份数据第一次说明：**在真实地铁线路上，同一段波磨在声通道里的可分辨性（AUC 0.88）高于轴箱（0.74）**。

## 6. 这份结果不能证明什么

- **不能验证幅值反演**：没有轨面剖面，任何"反演出的深度是多少"的对比在这份数据上都不成立；
- **只跑了一趟**：`Run_75kmh_E1toE2.mat` 是 75 km/h 那一趟，且实际均速只有 62 km/h（含起停）；论文另有 60/50/40 三趟（反方向），**速度不变性还没有检验**；
- **指标不是论文的方法**，所以"5/6"不能读成"我们超越了论文的 91.6–100 %"——两者不可比；
- **单位未标**：`Vi_y` rms 10.79 若为 m/s² 则 1.1 g（合理），若为 g 则 10.8 g（偏高）。检测是尺标无关的，所以不影响本节结论，但**幅值结论必须等确认**。

## 7. 过程中我自己犯的两个错（都已写进代码注释）

1. **位置单位**：`Vi_pks` 本来就是 km（3.798→6.303），我又除了一次 1000，打印出"0.004–0.006 km"，并让所有窗口落空（`percentile` 报 `IndexError: index -1 is out of bounds for axis 0 with size 0`）。
2. **波段**：第一版把"20–350 mm"当通用范围，导致声学 AUC 0.297（比随机差）。**这个数字本身是有价值的证据**：指标对波段极其敏感，而正确波段只能来自被测对象的实测波长。

## 9. 下一步（按价值排序）

1. **把四趟都跑一遍**（75/60/50/40，两个方向）——速度不变性是我们模型里唯一还没定的口径（25 vs 50 mm 差 1.1 %，但 80 vs 350 km/h 差 13.6 %）。四趟实测可以直接裁定。
2. **同工况谱对比**：用 `CRH380A_M_axlebox` 在 62 km/h 直线上跑一段 26 mm 波磨，把模型轴箱谱与实测 `Vi_y` 谱画在一张图上，看量级差几个 dB（这是检验"轴箱通道定义"的第一步，之前那个 13.7 Hz 自由模态的隐患也在这里暴露）。
3. **声学+振动联合**：既然两者 AUC 是 0.88/0.74，联合指标应当更高；这是论文没做的部分，也是我们唯一可能做出增量的地方。
