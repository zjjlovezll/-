# 峰数从数据里数：选择子在两个峰上成立，在三个峰上不成立（2026-10-31，第 274 轮）

> 第 273 轮的两个峰是**给定**峰数的。真实波磨的峰数不写在数据里，所以这一轮问：
> **能不能让数据自己说有几个峰？** 判据（BIC 选 K）在跑之前写死，
> 结果是一半成立、一半不成立，而**不成立的原因不在选择子**。

## 一、预注册

```
真值：K 个高斯，宽度固定为声明先验 0.35 m
估计器：同样宽度的 K 个高斯，2K 个参数（A_i, s_i），K = 1..5
选择律：BIC = n·ln(SSE/n) + 2K·ln(n)      （最小者胜）
判据
  G-COUNT  被选中的 K 等于真峰数（两峰那趟是 2，本轮是 3）
  G-LOC    每个被选峰与它最近的真峰相距 ≤ 0.20 m
  G-AMP    每个被选峰幅值相对误差 ≤ 2 %
  G-ABS    被选模型 p95 ≤ 22 µm
  G-SEP    相邻被选峰间距 ≥ 0.5 m
```

**顺序**：先在**已归档**的两峰剖面上跑选择子（答案已知是 2，且不花仿真），再在新的三峰剖面上跑。
一个连"2"都数不出来的选择子，不值得用来数"3"。

## 二、选择子的第一次实现是坏的（先说）

第一版用 2K 参数冷启动（多起点 `least_squares`）。读数立刻自曝：**K=1 与 K=2 的 SSE 逐位相同**
（`1.6697e-01`）——第二个峰从头到尾没被用上。这是局部极小、不是物理。
改成**前向选择 + 每步联合重解**（对每个候选中心整组重解，保留残差下降最多的那个），
同一份数据立刻给出 K=2 明显优于 K=1（`6.94e-02` 对 `1.67e-01`）。

## 三、读数

**两峰剖面（已归档，真值 2）**

| K | SSE | BIC |
|---|---|---|
| 1 | 1.6697e-01 | −2270.68 |
| **2** | **6.9404e-02** | **−2526.12** |
| 3 | 6.9374e-02 | −2514.82 |
| 4 | 6.9314e-02 | −2503.65 |
| 5 | 6.9183e-02 | −2492.79 |

选中 **2**、p95 **5.26 µm**；`G-COUNT / G-LOC / G-AMP / G-ABS / G-SEP` **全 PASS**。
K=2→3 的 SSE 只动 0.04 %，说明残差已经到底——BIC 于是正确停下。

**三峰剖面（本轮新算例，真值 3）**

| K | SSE | BIC |
|---|---|---|
| 1 | 5.0210e+00 | −1236.00 |
| 2 | 1.4084e+00 | −1610.99 |
| 3 | 9.2353e-01 | −1727.86 |
| 4 | 6.1170e-01 | −1841.66 |
| **5** | **4.0856e-01** | **−1952.92** |

选中 **5**（不是 3），BIC 间距 **111.3**；`G-COUNT / G-LOC / G-AMP / G-SEP` 全 FAIL、
只有 `G-ABS`（p95 13.96 µm）PASS。**残差一路下降、没有平台**——这正是"模型错、不是数据不够"的指纹。

## 四、机制：实测律不复合

把真值剖面直接喂给实测份额律，与实测份额比（这是不需要拟合的直接测量）：

| 算例 | 叠加的峰数 | 份额律 rms | 最大偏差 | 站数 |
|---|---|---|---|---|
| `one_set_twopeak` | 2 | **0.0165** | 0.1353 | 304 |
| `one_set_threepeak`（首版设计） | 3 | **0.0385** | 0.1859 | 286 |
| `one_set_threepeak_obs`（本轮） | 3 | **0.0317** | 0.1942 | 304 |

这个律是**一次只抬一个鼓包**标定出来的（第 254–256 轮）。单峰时它准，两个峰叠加时残差
rms 0.0165，三个峰时翻倍到 0.0317/0.0385。于是：

- 两峰那趟的拟合残差（rms 0.015）正好落在复合误差的量级上 ⇒ BIC 停在 2；
- 三峰那趟 K=3 的拟合只剩 rms 0.055，比复合误差 0.032 还大（前向选择未到最优）；
  而 K=5 把 rms 压到 0.037 ≈ 复合误差 ⇒ **多出来的两个高斯买的是"律不复合"这部分误差**。

⇒ **峰数不可辨识的根源是正演（律），不是选择子。** 换更聪明的选择律不会有用。

## 五、一次设计错误（保留在脚本里）

第一版把三个峰放在 `57.4 / 58.5 / 59.7 m`。其中 **57.4 m 的零点份额是 0.000**（尖轨还没承载），
低于可观测下限 0.02 ⇒ 那个幅值没有任何数据约束，拟合把它推到 **398.2 µm**（上界 400）、p95 346 µm，
**但峰数仍然数对了**。可观测带实测为 **58.13–63.33 m（5.20 m、469 站）**；宽度先验 0.35 m 的峰要完全落在
带内，中心须在 **58.58 … 62.88 m**。第二版据此把中心移到 `58.5 / 59.5 / 60.5 m`——数对了、但撞上第四节。

## 六、能说 / 不能说

**能说**：在正演律成立的范围内（单峰或两个峰、宽度先验给定里），**BIC + 前向选择能把峰数数出来**
（两峰 → 选 2，五门全过，p95 5.26 µm），且这是零仿真成本的复算。

**不能说**：三个以上叠加时峰数可辨识——本轮两版都选成 5；也不能说"多选是选择律太宽"，
复合误差是量出来的（0.0165 → 0.0317/0.0385），下一版选择律不会改变它。
另：仍只测 80 km/h、单侧、直向、一组宽度先验；`G-ABS` 在错模型下也能过（13.96 µm），
所以**不能**只看 `G-ABS` 判峰数。

## 七、下一步（两件，按代价排）

   仍然是 0/3 的那套结构，但它**按定义可叠加**；判据不变，看三峰能否选 3。

   代价是多一轮静探（每组秒级），收益是保留"实测"这一优点。
