# Velch 0.4.22 发布说明

发布日：2026-10-23　｜　和 0.4.21 的差别：**⑥ 对照屏把"选了哪两列"常驻显示**。

## 这一版改了什么

- ⑥ 对照屏在列选择下面多一行常驻说明：`里程列 ← ch_003（自动）；力列 ← SumQ（自动，另有 2 个候选）`。
- 改动下拉框后立刻变成「手动选择」；多个候选会明说，并提醒"猜错的代价是比较了两根不同的轨"。
- 列名全不认识时写「列名无法识别，请确认」，不再静默取第一列。

## 账本

`O003` 关闭。仍开放：`O001`（语料探测靠源码文本）、`O008`（横向布置不可双侧导入）；
设计约束：`O005`（Simpack 侧物理量不自动映射）。
