# 表示误差的第二个排除：不是查表插值分辨率（2026-10-31，第 279 轮）

> 到上一轮为止，随机剖面失败的归因只剩"正演不复合"。但"不复合"仍有一个廉价解释没排：**查表太粗**。
> 实测份额律是七个节点（`u = −200 / −100 / −50 / 0 / 50 / 100 / 250 µm`）的线性插值。一个剖面若有大量站位
> 落在**两个节点之间**的陡段，就会被一条直线跨过曲率很大的那一段——而分量越多，落在陡段的站位越多。
>
> 这个假说可以给出两个可证伪的预测，而且**不需要任何新仿真**。

## 一、预注册

```
P1  六分量剖面落在陡段（σ ∈ [0.2, 0.8] 的两个节点之间）的站位比例，**高于**两峰剖面
P2  同一运行内，站位离最近节点的距离越大，|误差| 越大（相关系数 ≥ 0.5）
读数：两条都成立 ⇒ 误差主要来自插值分辨率，修法是**把律在陡段测密**，不必重建接触层
```

## 二、读数

```
knots u: [-200.0, -100.0, -50.0, 0.0, 50.0, 100.0, 250.0]

run                           usable  steep%  knot med  knot p90   floor    corr
one_set_twopeak                  469  100.0%      23.1      23.4  0.0133  -0.282
one_set_threepeak_obs            469  100.0%      19.1      23.5  0.0427   0.595
one_set_random                   381  100.0%      12.9      23.6  0.1314   0.479

P1 steep fraction grows with components: NO
P2 error follows the knot distance: NO
VERDICT: neither prediction holds: interpolation resolution does not explain the floor, so the
         per-station assumption itself has to be re-measured
```

三条读数各自否掉一半：

1. **P1 不成立**：三条运行**全部 100 %** 落在陡段（`knot med` 只有 12.9–23.1 µm，节点间距本身就在陡段里），
   所以"分量越多越压在陡段"这个差别**不存在**；
2. **P2 不成立**：六分量那趟的相关系数是 **0.479**（低于 0.5 的门），而两峰那趟是 **−0.282**——**方向还反了**
   （离节点越远误差越小）。这不可能由插值解释；
3. 两峰与六分量的节点距离分布几乎相同（p90 都是 23.4 / 23.6 µm），而 floor 差 **10 倍**（0.0133 → 0.1314）
   ⇒ **两件事无关**。

## 三、排除表（到现在为止）

| 候选 | 排除依据 | 轮次 |
|---|---|---|
| 估计器 / 罚项 / 求解器 | 空跑对零判 p95 **0.01 µm** | 277 |
| 可观测窗饱和 | 饱和站 **0.0 %**、份额最大 0.980 | 277 |
| 曲线 u 量程钳位 | 钳位 **0 %**、量程内重算逐位相同 | 278 |
| 查表插值分辨率 | P1/P2 都不成立、相关 0.479 与 −0.282 | **279** |

**剩下的是假设本身**：σ 在站位 s 只依赖"该站的一个标量间隙"这句话。六分量剖面的 floor 是两峰的 **10 倍**，
说明这个假设在叠加状态下失效，而且失效既不是量程、也不是查表粗细。

## 四、下一个可测量（已写入任务书，本轮未做）

被测到的、能支撑"第二个坐标"的实测事实是：**接触半宽跨过渡带从 5.75 mm 变到 7.47 mm（1.30×）**
（第 254 轮）。`s99` 从第 270 轮起把 `contact_half_width_m` 逐帧逐轨归档了，所以下一轮可以直接问：

```
H  把 (u, b) 两坐标的律与 (u) 一坐标的律比，六分量 floor 是否显著下降
判据：floor 从 0.1314 降到 ≤0.02，且两峰不劣化
```

这条比"重建接触层"便宜得多，而且是**同一份归档数据**能回答的。

## 五、能说 / 不能说

**能说**：第 277 轮的 0.1314 **不是**查表插值分辨率造成的（三条运行陡段占比都是 100 %、节点距离分布相同、
误差与节点距离不相关且在两峰上符号相反）；在此之前已经排除估计器、饱和、量程钳位。

**不能说**：① 不能说机理已定——只把候选从四个减到一个（**逐站单标量假设**）；
② 不能说 (u, b) 两坐标律一定能把 floor 压到 0.02——未做；
③ 不给任何随机剖面的幅值数字（`G-RES` 仍是 0.02，第 277 轮三门仍 FAIL）。
