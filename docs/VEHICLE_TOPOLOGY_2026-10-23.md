# 车辆拓扑：从写死的 35 个坐标到节点表

**日期**：2026-10-23 · **版本**：0.4.26

## 1. 为什么要有这一层

冻结求解器把车辆拓扑写死在代码里（`velch/vehicle_solver.py` 早期的 `_build_connectors`）：
四根轮对各 5 个坐标、两个转向架各 5 个、车体 5 个，共 35。这个布局能跑出冻结基线，但它
表达不了两件事：

1. **纵向自由度**：牵引拉杆、一系纵向刚度都需要车体/转向架有一个 `x`，而 35 坐标里没有；
2. **别的车型**：三轴转向架、铰接车、单转向架机车都装不进去。

节点表把"有哪些刚体、每个刚体有哪些坐标、哪些元件连在谁身上"变成**数据**。求解器只认表。

## 2. 两套布局

| 布局 | 刚体坐标 | 状态维数 | 用途 |
|---|---|---|---|
| `v2-5dof` | 轮对 5、转向架 5、车体 5 | 35 | 冻结基线，一个字都不许动 |
| `v2-node` | 由 `topology.bodies[].dof` 决定 | `sum(len(dof))` + 轨道块 | 新车型、六自由度 |

`v2-node` 的元件写在 `topology.elements`，两种：

* `axial`：两点之间沿 `direction` 的弹簧-阻尼（一系、二系、减振器、牵引拉杆）；
* `torsional`：两体之间绕 `roll|pitch|yaw` 的扭簧（抗蛇形、抗侧滚、一系摇头）。

坐标里质量与惯量可以写成 `"$vehicle.bogie.mass_kg"` 这样的引用，指向这台车自己的参数块——
"Simpack 给的数只能有一处"这条规矩因此仍然成立。

## 3. 等价性怎么验的

`vehicles/CRH380A_M_node.json` 用节点表**重述**冻结的 30 个连接器（12 行动力元件）。

判据不是"看着差不多"，而是**逐元件按 (刚体, 坐标) 比较雅可比系数**：

```
worst coefficient difference over shared connectors: 0.000e+00
```

这条比较抓出了两处我一开始写错的地方，都是真实物理约定：

1. 二系垂向弹簧在冻结模型里**没有点头力臂**（车体锚点放在转向架站位的 x，转向架锚点放在
   自己中心），我先按对称写了 x，多出 −8.75 的点头项；
2. 反过来只把两侧都放 0 又丢了车体那一侧的 −8.75。

改对之后 30 个元件全部逐位相同。

**轨迹上还有一处没对上**（如实记录）：0.05 s 辙叉窗口，最大侵入 154.97 µm（节点表）vs
155.03 µm（冻结），但**各轨峰值出现的位置轮换了**——冻结版 `axle1_left` 82.2 kN，
节点表版同一轨是 0，而 208.7/170.6/89.1/82.2/72.6/67.3/67.2 kN 这些数值本身在两版里都出现。
峰值集合相同、归属不同，说明还差一个相位或映射，**不能称这一版与冻结基线等价**。
下一步要查的是轮对与轨道站位的时间对齐（`axle_x_positions` 与首帧接触时刻）。

## 4. 六自由度机型

`vehicles/CRH380A_M_6dof.json` 在等价重述之上装上了三样此前只能写在文档里的东西
（数值来自 `CRH380A_M_Bogie.spck`，见 `docs/SIMPACK_BOGIE_MINING_2026-10-23.md`）：

| 元件 | 数值 | 此前为什么装不上 |
|---|---|---|
| 牵引拉杆 ×2 | 7.88e6 N/m | 需要车体的 `x` |
| 抗侧滚扭杆 ×2 | 1.0e6 N·m/rad | 需要绕 `roll` 的扭转元件 |
| 二系横向减振器 ×2 | 17.15e6 N/m + 40 kN·s/m | 冻结模型 `secondary.c_y = 0` |

轮对仍然只有 5 个坐标（纵向 `x` 由走行速度给定，不求解）——这是声明过的建模选择，
`not_verified` 里写着。

## 5. 命令

```powershell
python -X utf8 -m velch vehicle list
python -X utf8 -m velch vehicle show CRH380A_M_6dof
python -X utf8 -m velch vehicle validate CRH380A_M_node
python -X utf8 -m velch run-vehicle <case> --output <dir> --fast
```

## 6. 还没有的

* 节点表与冻结基线的**轨迹等价**（见 §3 末段）；
* 轮对纵向自由度（需要牵引/制动工况与钢轨纵向约束，是另一个物理问题）；
* 止挡、齿轮箱吊杆、二系垂向减振器的串联刚度；
* 三轴转向架与铰接车——节点表已经能表达，但还没有一台真实的表来试。
