# 实测反演的判定页（L0–L5）

这一页只做一件事：把 README 自带的那份实测数据（`Run_75kmh_E1toE2.mat`）在反演流水线上**逐层**的
判定与数字写下来，并给出机读产物。它不重跑仿真、不重算任何数——每个数都来自前面几轮落盘的 JSON。

- 机读判定：`reports/inversion_measured_2026-10-28/verdict.json`
- 逐段结果：`reports/inversion_measured_2026-10-28/bands.csv`
- 逐窗结果：`reports/inversion_measured_2026-10-28/windows.csv`
- 速度表 / 算子 / 阶次追踪：同目录 `speed_table.json`、`operator.json`、`order_tracking.json`
- 复算：`python -X utf8 scripts/s24_verdict.py`

## 1. 结论两行

```
measurement_validation_status = detection_only
physics_validation_status     = unvalidated_against_measurement_or_Simpack
```

`detection_only` 是本项目允许出现的最高状态，且只有 L5 全过时才可能升到更高一档；这一份数据停在
「能检出、不能给出幅值」。L0/L1/**L2**/L3 已通过，L4 仍未在实测上验、L5 仍差 3 段。

## 2b. L2 的四速度表（第 175→176 轮的差别）

`s14_speed_table.py` 对 `F:\ai道岔状态反演辨识\75kmh数据` 下**全部四份** `.mat` 各建一行；判据是
「≥2 个独立稳态速度」+「跨速度波长散布可接受（≤15 %）」。

| 记录 | 稳态速度 | 线频（中位） | 波长（中位） | 落 18–40 mm | 突出度 |
|---|---|---|---|---|---|
| `Run_40kmh_E2toE1.mat` | 39.9 km/h | 398.4 Hz | **28.1 mm** | 93.6 % | 28.2 dB |
| `Run_50kmh_E1toE2.mat` | 49.2 km/h | 451.8 Hz | **29.9 mm** | 90.2 % | 23.7 dB |
| `Run_60kmh_E2toE1 (1).mat` | 58.0 km/h | 565.2 Hz | **26.7 mm** | 68.3 % | 23.0 dB |
| `Run_75kmh_E1toE2.mat` | 70.8 km/h | 713.2 Hz | **27.5 mm** | 64.7 % | 23.1 dB |

两件事同时成立：**线频随速度缩放**（398→713 Hz，1.79×，速度比 1.77×），**波长不随速度变**（散布 11.3 %）。
这正是「常数波长」假设的正面证据，也是「按速度分键的表」能被允许使用的前提。45 km/h 以下的一段仍是起步
加速，已被 L0 的稳态档规则排除在表外。

## 3. 四项「不能声称」的话

1. **不能声称波磨深度**：27.5 mm 处四个速度给出的深度跨度 **337×**（0.3–85.5 µm），60 mm 处 **3.0×**，
   因为设计频率上没有线的地方幅值就是本底；
2. **不能声称「短波常数与速度无关」**：S1 在三个速度下差 **3 倍**（8.9 / 27.0 / 12.1 µm）；
3. **不能声称车辆模态已标定**：Cov-SSI 在该记录上只出 **12/154** 个稳定极点，与模型三条模态
   （12.0 / 24.9 / 133.3 Hz）**无对应**；FDD 能重复给出 57–60 与 88–92 Hz（4–6/6 段），但归不到车上；
4. **不能声称检测已验证**：6 段里 3 段检出、虚警 5 %，这是「高于偶然」而不是「已验证」。

## 5. 这一页与「95 %」的关系

任务书把 95 % 定义成「6 段检出 ≥95 %（即 6/6）@ 段级虚警 ≤5 % + 定位误差 0 m」。当前 **3/6 + 5 %**，
所以目标第 6 项（直向/曲线过岔随机速度反演）**未达成**，且不能通过调阈值、换波段或加平均来达成——
那三项属于「把失败变绿」，任务书明令禁止。
