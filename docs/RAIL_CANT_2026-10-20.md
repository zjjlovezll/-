# 轨底坡 1:40：把"整体倾斜"换成"绕轨顶中心旋转"

日期 2026-10-20。18 号道岔图纸附注 9.11 要求"道岔区钢轨设 1:40 的轨底坡或轨顶坡"。
此前 Velch 只能用"整条断面平移/整体倾斜"近似，试过一次给出 **1930 kN**、脱空 94/101、
轮心行程 5 mm 的荒谬结果。本文记录正确做法与验证。

## 1. 为什么整体倾斜必错

轨顶面横向宽约 70 mm，绕**轨距面**（y=0）转 1/40 会把轨顶中心抬高

```
Δz = 35 mm × (1/40) = 0.875 mm
```

而静平衡侵入量只有 **65.5 µm**。0.875 mm 是该值的 13 倍，等于凭空给轮子垫了一块
0.875 mm 的板——轮子被抬起、接触全丢，力自然炸到兆牛量级。这不是"参数没调好"，
是坐标系基准错了。

正确的物理是：**轨底坡让轨顶面倾斜，但轨顶中心的高度不变**（钢轨绕自身纵轴转，
设计标高在轨顶中心）。所以旋转必须绕 (轨顶中心 y, z=0)。

## 2. 实现

`src/velch/profiles.py:graph_from_points` 新增三个参数，在符号/缩放/偏移变换**之后**
作用：

```
roll_rad        旋转角（右轨 +atan(1/40)，左轨 −atan(1/40)）
roll_pivot_y_m  支点横位（= 该轨轨顶中心）
roll_pivot_z_m  支点高度（= 0）
```

小角近似下 z' = z + θ·(y − y_pivot)，所以 1:40 的坡度、0.875 mm/35 mm 的横向高差、
轨顶中心高度不变这三件事同时成立。算例里写：

```json
"profile": { "...": "...", "y_offset_m": 0.753,
             "roll_rad": 0.024995, "roll_pivot_y_m": 0.753, "roll_pivot_z_m": 0.0 }
```

左轨 `roll_rad` 取负（镜面对称）。缺省 `roll_rad = 0` 时逐位复现旧算例——这是契约演进
的"物理恒等默认值"要求。

## 3. 验证（平直段，0.05 s，`out_cant/`）

| 算例 | 右轨峰值 | 右轨均值 | 轮心 z 峰峰 | 赫兹侵入 |
|---|---|---|---|---|
| `case_flat_S_local`（无轨底坡） | 59.68 kN | 59.68 kN | 0.0000 mm | **65.5 µm** |
| `case_flat_S_cant40`（1:40） | 59.68 kN | 59.68 kN | 0.0000 mm | **60.8 µm** |

- **静载不变**（59.68 kN 逐位相同）→ 旋转没有引入假支点、没有改变质量路径；
- **侵入从 65.5 降到 60.8 µm（−7.2%）**，等价于等效曲率半径 `R*` 增大 **11%**。

后一条不是噪声，是可通过物理预期的：LMA 踏面本身带 1:40 锥度，轨顶再转 1:40 之后
两个曲面在接触点附近**趋于平行（共形接触）**，横向曲率半径变大、接触变刚、侵入变小。
这也正说明轨底坡不能当"几何装饰"忽略——它直接把静态接触刚度改了 11%，进而改变
力水平与可辨识性。

## 4. 新增的静态门（建议固化为验收项）

任何 `roll_rad != 0` 的算例都必须满足：

| 门 | 判据 | 本次实测 |
|---|---|---|
| 静载保持 | 与 `roll_rad = 0` 版本差 < 0.5% | 0.00% ✅ |
| 轮对不漂移 | 轮心 y 峰峰 < 1 µm | 0.0000 mm ✅ |
| 侵入量级合理 | 侵入变化 < 20%（物理上应因共形而减小） | −7.2% ✅ |

若静载变化 > 0.5% 或轮心漂移，几乎一定是支点选错（把轨距面当成了轨顶中心）。
