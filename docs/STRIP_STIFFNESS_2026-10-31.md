# 条带积分也过不了无凸起那趟：接触层得从求解器来（2026-10-31，第 283 轮）

> 第 281 轮的点接触把尖轨的 1 mm 锐边当成“刀”。这一轮换成**求解器同款的做法**：沿横向切条带、
> 用**轮+轨合并的间隙**与**局部合并曲率**积分，看尖轨的软是被几何真正决定的、还是被点接触模型的尺寸律造出来的。

## 一、模型（一个共同尺度，比值消掉）

```
h_i(u) = z_体,i(u) − z_轮(u)                合并接近高度（轮 LMA_x4，取自 sections/LMA_x4.prw）
g_i(u) = max_u h_i − h_i(u)                 该横向位置的闭合间隙
R_comb(u) = (1/κ_体(u) + 1/κ_轮(u))^-1      局部合并曲率半径
F_i(δ) = Σ_u (4/3)E*·sqrt(R_comb(u))·max(0, δ − g_i(u))^1.5 · Δu
每站：解 F_stock(δ) + F_blade(δ) = 60 153 N 得共同轮心下沉 δ，share = F_blade / 60 153 N
```

条带 `Δu = 0.1 mm`、半跨 **±25 mm**、`E* = 1.154e11 Pa`、站位步长 0.02 m。`share` 是比值，
所以积分尺度的绝对值不影响结果——**不消掉的是 `g_i(u)` 与 `R_comb(u)` 的形状**，而那正是第 281 轮错的地方。

## 三、一个必须写下来的口径问题

“无凸起那趟”对**实测律**不是独立检验：律的零点 `u0(s)` 就是从这趟的份额**反解**出来的，所以它当然
在 0.0133 上“通过”。但对**从几何预测**的前向模型（点接触 281、条带 283），它是**独立**检验——两轮都不过。
因此这条前置门只对“预测型正演”有判别力，**不能拿实测律的 0.0133 去说明“律已经通过前置门”**。

## 四、结论：闭式接触层走不通，接触层要从求解器来

连续两轮（点接触、条带积分）都在**无凸起那趟**上失败，且偏置方向一致（模型少给尖轨份额）⇒
**这套几何的份额不是任何闭式接触模型能给的**。剩下的路只有一条：

> **用求解器逐站标定**：把轴放在该站、按几何给升降，座椅后读 `body_contacts` 得到该站的 σ。
> 座椅一次 **4.5 s**，300 站 ≈ **22 min**，完全可承受；这与“实测律”不同——它是**用模型自己生成**的，
> 与反演目标同源，所以只能算 **A 级（数字闭环）**，不能算 C 级真值。

## 五、能说 / 不能说

**能说**：用轮+轨合并间隙与局部合并曲率的条带积分（`Δu=0.1 mm`、±25 mm、`E*=1.154e11`）给出
floor **0.1912 / 0.2008 / 0.2589 / 0.3718**、偏置 **−0.0768 … −0.3038**，**没过无凸起趟的前置门（0.02）**；
它比第 281 轮的点接触好 **1.6 倍**，但仍差 10 倍。

**不能说**：① 不能说“闭式模型一律不行”——只测了这两族；
② 不能说“必须逐站跑求解器”已可行——只是**代价算得过来**（22 min/300 站），未做；
③ 不给任何随机剖面幅值。
