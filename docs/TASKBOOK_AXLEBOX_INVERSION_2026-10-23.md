改用**单刚体等效**（48.2 kg 并进轮对、轴箱只作输出点），先拿到正确力水平，再谈轴箱独立成体。
判据 A 的 5 % 上限在这两处收敛前不调整。

## 1. 五个阶段与判据（每阶段必须有可复算的证据，缺证据不算完成）

### S1 轴箱体（先解决"在哪儿测"）
- 用节点表新增 `axlebox` 刚体：4 个，每个 `m = 48.2 kg`、`Ixx/Iyy/Izz = 0.72/2.76/2.62 kg·m²`（来自 `SIMPACK_BOGIE_MINING_2026-10-23.md`）。
- 连接：轴箱 ↔ 轮对（一系垂向/横向：`k = 1.18e6 / 9.8e5`，`c = 1e4`，作用点 z −0.322 / −0.585）、轴箱 ↔ 构架（转臂节点：`13.7e6 / 5.49e6`，x 0.5 m、z −0.446 m）。
- **判据 A**：新车型能与老车型对比 —— 在**同一算例、同一时长**下，轮轨力峰值的差异 < 5 %，并把这个差异写进文档（轴箱体必然改变高频，5 % 是上限不是目标）。
- **判据 B**：轴箱垂向加速度的 PSD 在 30–200 Hz 有能量、在 0 Hz 附近无漂移（否则是数值噪声冒充信号）。
- 若判据 A 失败（差异 > 5 %）：不调参掩盖，改为**报出差异的频段与原因**（轴箱体质量/一系刚度分配），并把差异作为后续反演的"前向模型不确定性"。

### S2 加速度通道（让求解器输出加速度）
- `history.csv` 增加 `axleboxN_{left|right}_{ay,az}_m_per_s2`（或按现有命名规则），从 `dynamics.evaluate` 的力/质量推出，而不是对位移做后差分（后差分会把噪声当加速度）。
- **判据**：与"对速度解析求导"的数值校验一致（有限差分 vs 解析，相对误差 < 1e-6），并且零幅值不平顺下加速度的**基线**可复现（同一 sha256）。

### S3 短波不平顺输入（把"能反演的对象"造出来）
- 生成器：可指定 AAR5/TB/T 3352 谱 + 波长下限（0.05 m）+ 步长（≤0.05 m）+ 四通道相位；输出 ASCII `.tre`。
- **判据**：生成的 `.tre` 的 PSD 与目标谱在 0.05–1 m 带内相差 < 10 %（单边谱，含 5 次实现的均值与散差）；`read_tre → write_tre` 仍逐值相同。
- 同时解决**采样代价**：型面采样步长 0.05 m × 100 m = 2 000 点；实测单次 RHS 代价并写入文档（若 > 2× 基线，需在 S4 里按"代价-带宽"权衡）。

### S4 可反演波段表（**决定性实验**，决定 S5 做什么）
- 对每个空间波长带（0.05–0.1 / 0.1–0.25 / 0.25–0.5 / 0.5–1 / 1–2 / 2–5 / 5–10 / 10–25 m）单独施加已知不平顺，测：
  1. **灵敏度**：轴箱加速度对该带的 rms 响应 / 输入 rms（传递增益）；
  2. **可观测性**：`velch.inverse.identifiability` 的条件数与分辨率；
  3. **噪声等效幅值**：给定测量噪声（0.02 / 0.05 / 0.1 m/s²）下，能分辨的最小不平顺幅值。
- **判据**：产出一张**波长 × (增益, 条件数, 最小可分辨幅值)** 的表，并据此划定"可反演带 / 需正则带 / 不可反演带"。**若某带噪声等效幅值大于该带的典型幅值，就明确写"不可反演"，不许用平滑掩盖。**
- 失败即停（这条最重要）：若**没有任何带**能在 0.05 m/s² 噪声下分辨，则本任务的目标不可达，改为交付"为什么不可达"的证据报告。

### S5 反演（Tikhonov 为主，学习为对照）
- 正演算子 `H`：用解析雅可比逐列求"单位不平顺 → 轴箱加速度"的响应（`H` 的每列 = 一次线性化响应，不是 2n 次差分）。
- 反演：`min ‖H r − a‖² + λ‖D r‖²`，`D` 取二阶差分；`λ` 用 L 曲线或 GCV 选。
- **判据（四条，全部要有数）**：
  1. **带限误差**：可反演带内 `rms(r̂ − r_true)/rms(r_true) < 30 %`；
  2. **波长分辨表**：每个带的误差分别报，不许只报总 rms；
  3. **闭环一致性**：`r̂` 再正演回去，`‖H r̂ − a‖/‖a‖ < 10 %`；
  4. **盲测**：留一组从未参与调参的实现（不同相位种子），误差不超过验收线的 1.5 倍。
- 若 S5 不达标：不调参到"看起来能过"，改为**降低主张**（例如只报 0.1–0.5 m 带、或只做"谱级"而非"逐点轨面"），并在文档里写明降级理由。
