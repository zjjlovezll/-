# 摇头刚度与 Kalker 蠕滑都不能让曲线稳定（2026-10-28，第 204 轮）

## 1 为什么做这件事

第 203 轮把离心力的符号改成由设计线形给出之后，R=1100 m、80 km/h 的 0.34 s 运行七门全过、
最大侵入从 120.51 µm 降到 78.40 µm、净横向力方向也对了（`+11 691.2 N`，需求的 53.5 %）。
但把时间拉到 0.60 s，净横向力变成 `+29 544.4 N`（135.3 %），`axle1_left/axle2_left` 到 **1.90×**
（超出 1.6 上限）。**随时间增长 = 没有稳态**，而验收要求的是稳态。

当时给出的链条是 `yaw = f11·κ·v·b / k_yaw`（实测 `1.02 kN·m / 1.96e6 = 0.52 mrad`），
横向力 `≈ f22·yaw·v`。若这条链条是主因，那么把 `k_yaw` 加大应当压低摇头角、从而压低横向力。

## 2 判据（运行之前写定）

```
criterion   ratio = |sum Fy(0.60 s)| / |sum Fy(0.34 s)|  <=  1.2
candidates  k_yaw ×2 = 3.92e6 N·m/rad      （只改车辆参数）
            k_yaw ×5 = 9.80e6 N·m/rad      （只改车辆参数）
            Kalker 蠕滑 f11 3.5e6 / f22 2.5e6 N（--creep-kalker，两个系数一起改）
baseline    第 203 轮，ratio 2.53
rule        比值 ≤1.2 才算稳定；符号方向另报，不用来替代比值判据
```

`scripts/s45_yaw_stability.py` 的 docstring 是这条判据的存档，脚本只读日志、不重算物理。

## 3 实测（六次运行，全部 `numerically_checked` 7/7）

| 配置 | k_yaw (N·m/rad) | 蠕滑 | 0.34 s `sum Fy` | 0.60 s `sum Fy` | 比值 | 判据 |
|---|---|---|---|---|---|---|
| 基准（第 203 轮） | 1.96e6 | 冻结 5.0e5 / 1.0e6 | +11 691.2 N（53.5 %） | +29 544.4 N（135.3 %） | **2.53** | ✘ |
| k_yaw ×2 | 3.92e6 | 冻结 | +12 091.6 N（55.4 %） | +28 111.1 N（128.7 %） | **2.32** | ✘ |
| k_yaw ×5 | 9.80e6 | 冻结 | +11 883.8 N（54.4 %） | +29 305.9 N（134.2 %） | **2.47** | ✘ |
| **Kalker 蠕滑** | 1.96e6 | **Kalker** | **+18 952.7 N（86.8 %）** | +41 516.7 N（190.1 %） | **2.19** | ✘ |

最大侵入：基准 78.40 → 118.46 µm；k×2 91.39 → 129.87；k×5 93.65 → 129.12；
Kalker **383.52 → 478.21 µm**。

## 4 四条读法

1. **`k_yaw` 不是主因，这条路被实测否掉。** 刚度加到 5 倍，0.34 s 的净横向力从 11 691.2 只动到
   11 883.8 N（**+1.6 %**），0.60 s 也只从 29 544.4 到 29 305.9（−0.8 %）。若摇头角真是主因，
   `yaw ∝ 1/k_yaw` 应当让横向力几乎按比例下降；实测没有。
2. **Kalker 尺度把 0.34 s 推到了 86.8 %**（比冻结蠕滑的 53.5 % 高 62 %），峰值 1.06–1.58×
   **全部落在 [0.625,1.6] 带内**——这是迄今最接近合格曲线的一次；但 0.60 s 冲到 190.1 %，
   侵入 383→478 µm，轮子越压越深。**能力够了，稳定性没有。**
3. **增长不是"载荷转移建立"而是"继续压深"。** 基准与 k 组在 0.60 s 的转移分别是 +73 423 / +73 423 /
   +76 839 N，而 Kalker 组反而从 +19 963 掉到 +8 664 N：力的增长没有伴随外轨卸载，
   而是两侧同时被压深（左右合计 259 323 / 250 660 N，比静重 477 295.7 N 多 6.9 %）。
4. 六次运行**七门全过**、没有一次撞上斜率守卫——所以这不是数值故障，是**物理状态本身不存在
   在带内**。

## 5 这一轮把曲线的说法收窄成什么

曲线项（第 4 门）**继续降级**，但降级理由现在是逐项排除过的清单：

| 候选原因 | 结论 | 依据 |
|---|---|---|
| 两点接触没实现（L12） | 已实现，**这条曲线上惰性** | 与冻结 oracle 逐位相同；轮缘根在胎面下 23 mm，最深侵入 0.12 mm |
| 蠕滑系数太小（L13） | 改到 Kalker 尺度后 0.34 s 到 86.8 %，**但 0.60 s 190 %** | 本轮第 4 行 |
| 离心力符号错 | **已修**（B044） | −78.1 % → +53.5 %，侵入 120.51 → 78.40 µm |
| 摇头刚度太软 | **否掉** | 刚度 ×5 只改 1.6 % |
| 缺横向阻尼 | **否掉**（第 189 轮） | 20 kN·s/m 让 0.60 s 从 151 % 变到 172.6 %（更差） |
| 时间积分/接触搜索 | **否掉** | 接触点不迁移（±150 µm 内 `lever_y` 变 0.0 µm）；七门全过 |

剩下**没有被否掉的只有一个**：这份轮轨几何（轨顶间距 1.50667 m 对车轮 1.4930 m、`n_y/n_z = ±0.0250`）
在**带内**能提供的横向力上限是 8 169.6 N = 需求的 **37.4 %**；要拿到 21.8 kN 必须外移约 2.5 mm，
而那里一侧要承担 1.6 倍整车重量。**这意味着：要么改轮轨几何/超高（让重力分量真正参与），
要么接受"曲线只能跑短窗、不能作为定量反演工况"。**
