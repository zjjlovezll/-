# S5 第一轮：按波长反演是**非唯一**的（本工况），并且能给出非唯一的量

日期：2026-10-23 深夜。任务书 S5 第一次尝试，脚本 `scripts/s5_inversion.py`。

## 做法

1. **H 逐列实测**：四个带（0.1 / 0.5 / 2 / 8 m）各单独激励一次（幅值 0.30 mm、幅值相位 0），从每次运行里在**同一组四个分析频点**上读复数响应 → `H[:, i] = 响应 / 幅值`。所以 H 里包含"单带激励在别的频点上留下多少"。
2. **目标工况**：四个带同时存在、幅值带正负号（+0.25 / −0.18 / +0.31 / +0.42 mm），另跑一次。
3. **Tikhonov**：`r = (Hᴴ H + λ²I)⁻¹ Hᴴ y`，λ 取 1e-4…1e1，按**偏差原则**（残差降到 S4 实测噪声量级）挑 λ，**不针对真值调参**。

## 结果

`|H|`（行 = 分析频点，列 = 激励带，单位 (m/s²)/m）：

```
        0.1 m     0.5 m     2 m       8 m
0.1 m   284.6     465.2     300.3     355.9
0.5 m  1335.8    1454.7     568.5     615.5
2 m    4301.5    6710.9    4494.7    5506.3
8 m   52302.7  211504.4   56549.4   99602.5
```

奇异值 `2.464e5 / 4.232e3 / 7.937e2 / 3.655e1`，**条件数 6.7e3**。**非对角项与对角项同量级**——单带激励会在每个分析频点上都留下能量，这是辙叉瞬态泄漏，不是数值噪声。

反演（目标真值 +0.25 / −0.18 / +0.31 / +0.42 mm）：

| λ | 残差 | 相对误差 | 复原（mm） |
|---|---|---|---|
| 1e-4 … 1e0 | 1e-11 … 1e-5 | **136.1 %** | −0.34 / +0.11 / −0.08 / +0.64 |
| 1e1 | 1.0e-3 | 134.4 % | −0.35 / +0.11 / −0.06 / +0.62 |

## 结论（按任务书要求显式降级）

1. **拟合到 1e-11 的同时误差 136 %**：数据被完美解释，复原的幅值却与真值符号都不同。这说明存在近零奇异方向，**大量幅值向量映射到同一条测量曲线**——不是"暂时没调好 λ"，是这一工况下的**非唯一性**。
2. 正则化帮不上：把 λ 拉到 1e1 只把误差从 136.1 % 挪到 134.4 %，符合"误差来自零空间分量而不是噪声放大"的诊断。
3. 因此本工况（辙叉 + 0.40–0.80 s 窗口 + 4 个宽间隔频点）**不具备分带反演能力**，主张必须降级为：*可检测*（S4 已证 SNR 1.9–4.7），*不可分带定量*。
4. 三条已知的改进方向（未做，不在本轮声称）：
   - **换直线段工况**：瞬态泄漏是 H 非对角项的来源，平滑段应当显著降低它；
   - **加密频点**（把 4 个带分成 9 个 1/3 倍频程带）：更多方程不一定更好，但能让"非唯一方向"显式暴露在奇异值谱上；
   - **相干平均用在 H 每一列上**（本轮每列只测了 1 次相位），把列本身的本底压下去。
