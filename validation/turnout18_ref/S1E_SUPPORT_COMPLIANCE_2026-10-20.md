# S1-e：轨下离散支撑（600 mm 岔枕）——把缺失的频率补上

日期：2026-10-20　状态：已实现、已实测、已并入默认关闭的可选块
代码：`Velch/src/velch/support_compliance.py`（新），`contact.py`、`vehicle.py`、`vehicle_solver.py`（接线）
算例：`validation/crh380a_m/case_X_support{,_base}.json`；输出 `out_X_base`、`out_X_support`
对比脚本：`validation/crh380a_m/cmp_support_ab.py` → `support_compliance_ab.json`

## 1. 为什么要做这一层

前几轮的残留误差里，唯一无法用接触律解释的一项是频率：

| 量 | Velch（S1-d 后） | Simpack | 差 |
|---|---|---|---|
| 辙叉窗力主频 | 179.8 Hz | 39 Hz | 完全不同 |
| 150–250 Hz 带 rms | 62.3 kN | — | 振铃 |
| 脱空采样 | 10 / 101 | 0 / 2401 | 存在 |

钢轨不是由连续弹簧托着的：它每 0.6 m 落在一根岔枕上。轮子走过时，支撑刚度在
"压在枕上"与"跨中"之间周期变化，力里必然带 `v/0.6 = 97.2/0.6 = 162 Hz` 的分量。
Simpack 有这一层（`fn_c`、`fn_dref`、RWP 的 track 侧柔度），我们此前完全没有。

SDITT 里对应的实现是 `Par_TrackSystem.m` 的 FT-Modal / FT-FEM 路径：
`RailPad Stiff_X/Y/Z = 20e6 / 20e6 / 25e6 N/m`，`Damp = 20e3 N·s/m`，`Er = 214e9 Pa`。
本实现直接沿用这组数，未新造参数。

## 2. 模型：静力串联柔度

轮心相对**未变形**轨顶的接近量 δ 由两部分承担：

```
δ = (N / C)^(2/3) + N · G(x)
```

- `(N/C)^(2/3)` 是 Hertz 压入（C 仍由曲率导出，S1-d 已验 0.0655 mm 与 Simpack 0.0662 mm 对齐）；
- `G(x)` 是"单位载荷下钢轨在枕木支撑上的沉降"，单位 m/N，随 `x/0.6` 周期；
- 用 Newton 解 N（左端对 N 单调，5 次迭代足够，热路径只有一次查表）。

`G` 由 `_green_function()` 用三跨以上欧拉-伯努利梁 + 离散弹簧有限元一次算好（5 跨、
8 单元/跨、41 采样），运行期只做线性插值。

实测 `G`（`k = 25e6 N/m`、`EI = 6.55e6 N·m²`、`l = 0.6 m`）：

| 量 | 值 |
|---|---|
| `G` 最小（压在岔枕上，u=0） | 9.98e-9 m/N |
| `G` 最大（跨中，u=0.5） | 1.09e-8 m/N |
| 60 kN 下沉（枕上／跨中） | **0.599 / 0.657 mm** |
| 一个枕距内的变化量 | **0.058 mm** |
| 解析无限长梁（连续地基）对照 | 0.809 mm（同量级，离散支撑更硬，合理） |

## 4. 语义变化（必须记住）

开启支撑柔度后，`ContactGeometry.penetration_m` 是**总接近量**
（Hertz 压入 + 钢轨沉降），不再是单纯的 Hertz 侵入。因此：

- `max_penetration_m` 的物理含义变了，`0.003 m` 的门不再有原来的含义，判据应改用
  Hertz 部分（当前 0.15 mm 量级）或直接看 `min_penetration / lost_samples`；
- 与 Simpack 的 `p_geo,max`（0.43 mm 真几何侵入）对比时，必须换算到 Hertz 部分，
  否则会把钢轨沉降也算成侵入（1.23 vs 0.43 的差就是这一项）。

## 5. 接线方式（可回退）

算例 JSON 顶层可选块，缺省即旧行为：

# 6. 补测：满 1.2 s 全工况（结果反转，必须记录）

`case_Y_full_base.json` / `case_Y_full_support.json`（x_start 13.5 m、1.2 s、2401 采样、
翼轨体 + 曲率刚度 + Hunt-Crossley），两例均 `numerically_checked`、7 门全过：

| 指标 | 基线 | + 支撑柔度 | Simpack |
|---|---|---|---|
| 右轨峰值 | **158.04 kN** | **224.88 kN** | 134.97 kN |
| 最小力 | 3.021 kN | **0.000 kN** | 27.67 kN |
| 脱空采样 | **0 / 2401** | **16 / 2401** | 0 / 2401 |
| 最大总接近量 | 0.294 mm | 0.792 mm | — |
| 最大 Hertz 压入 | 0.294 mm | **0.206 mm** | 0.433 mm（几何侵入） |
| 最大钢轨沉降 | 0 mm | **0.682 mm** | — |
| 轮对垂向行程 | 0.593 mm | 0.952 mm | 0.594 mm |
| 力主频 | 175.8 Hz | 72.5 Hz | 31.7 Hz |
| 150-250 Hz 带 rms | 9.05 kN | **5.93 kN** | 1.09 kN |
| 30-60 Hz 带 rms | 1.67 kN | **3.75 kN** | 4.84 kN |
| 能量变化 | +9788 J | +9833 J | — |
| nfev | 336 185 | 577 637 | — |

**结论：频率对上了、峰值反而变差。** 频谱重心从 175.8 Hz 搬到 72.5 Hz，30-60 Hz 带
从 1.67 涨到 3.75 kN（Simpack 4.84），150-250 Hz 从 9.05 降到 5.93；但峰值 +42%、
出现 16 个脱空采样（集中在 80.326-81.007 m 辙叉融合段）。

**机理（已量化）**：这条柔度是"跟随轮子的静力量"，没有钢轨质量与惯性。给定的接近量下，
载荷被钢轨沉降分掉一部分，于是

- 小接近量时力极小，delta->0 附近更容易断力（16 个脱空采样的来源）；
- 大接近量时载荷被削，尖峰变低（0.05 s 窗口 171 -> 119 kN 就是这一条）。

能量变化两例几乎相同（+9788 vs +9833 J，差 0.5%），所以**不是数值不稳定**，是模型缺惯性。

**正确的做法**：把钢轨沉降做成真正的自由度（钢轨质量 + 扣件刚度 + 阻尼，即已有的
`track_dynamics = local_compliant`，或 SDITT 的两自由度"钢轨-轨枕"），而不是静力串联。
有质量的钢轨不会瞬间落下，才能在削峰的同时保住接触。当前 `support_compliance` 因此
**保持默认关闭**，只作窗口诊断与频谱工具使用。

# 7. 决定性结果：钢轨自己带质量和垂向自由度（`local_compliant`）

结论先说：**S1-e 的正确实现不是"静力串联柔度"，而是让钢轨成为带质量的自由度。**
而这条路径**不需要新代码**——`track_dynamics.kind = "local_compliant"` 早就存在，
参数直接从 SDITT `Par_TrackSystem.m`（FT-Modal）取：扣件 `kz = 25e6 N/m / cz = 20e3`
（每个轮下约 2 个扣件 → `50e6 / 40e3`），一个轮看到的有效钢轨质量约 2 m×60 kg/m = 120 kg。

## 7.3 三条可核验的结论

1. **轮对垂向行程 0.5954 vs 0.5944 mm，差 0.17%**——这是全项目第一次在这个量上
   与 Simpack 达到千分级一致（在此之前是 200× 偏差）。
2. **力主频 36.65 vs 31.65 Hz**，量级对上；150-250 Hz 的伪振铃从 9.05 降到 0.577 kN，
   已低于 Simpack 的 1.088 kN（略微过阻尼，`cz` 可取 20e3 而不是 40e3 再试）。
3. **峰值 123.60 vs 134.97 kN（-8.4%）**，且不脱空、最小力 16.76 kN；
   侵入 0.225 mm 反算 `C = N/delta^1.5 = 1.16e11`，与曲率刚度 1.1267e11 自洽。

## 7.4 为什么静力柔度失败、钢轨自由度成功

静力串联柔度把 "钢轨下沉" 当成位置的瞬时函数：给定接近量，钢轨立刻让位，
小接近量时力被吃掉 → 更容易断力（满 1.2 s 出现 16 个脱空采样，集中在 80.326-81.007 m）。
带质量的钢轨不能瞬间让位，于是
- 削峰依旧（载荷被钢轨惯性分担），
- 但 δ->0 附近仍有 16.76 kN 的残余支撑，不会脱空，
- 且 600 mm 扣件间距的周期激励以 39 Hz 的形式出现，而不是在接触弹簧上激出 175 Hz 的伪振铃。

这些定性说法在两张表里都能核验：静力柔度的 `max_settle_mm` 有 0.682 mm 而
`max_hertz_mm` 只有 0.206 mm（力被沉降吃掉）；钢轨自由度的 `max_settle_mm` 为 0
（沉降进了状态量，不再从接近量里扣），`max_hertz_mm` 回到 0.225 mm。

## 8.3 结论与标定立场

- `cz = 20e3`（SDITT 单扣件值，2 个扣件就是 40e3，这里取单值）把 30-60 Hz 带从
  2.84 抬到 3.55 kN，峰值几乎不变（123.60 -> 123.77），轮对行程 0.6012（+1.1%）。
  **推荐 `kz=50e6, cz=20e3` 作为 SDITT 字面基线。**
- 30-60 Hz 还差 27%；把 `kz` 拉到 100e6 会过冲到 6.98（+44%）且主频变 49 Hz，
  所以真值在 50-100e6 之间的某处（约 68e6 可对上 4.84）。
- **但不建议把 `kz` 当拟合参数用**：一个轮对应一根钢轨只给了 1 个垂向自由度，
  等于把"梁在 5-6 个扣件上的载荷分配"强行塞进一个弹簧。`kz` 需要多大，
  取决于这一层梁效应有多强——这恰恰是 S1-f/S2 要显式建出来的东西。
  所以现在停在 SDITT 字面值，把 27% 的缺口记为"单自由度集总的已知代价"。
