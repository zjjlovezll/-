## 4. 已经排除的四个假设（重要：别重走）

### 4.1 不是稀疏模板错
稠密雅可比同样发散，且失败时刻只差 9 ms → 模板不是原因。

### 4.2 不是接触拓扑变化（换体）
`0.2 s` 窗口正是为了跨过辙叉换体设计，稠密/稀疏都通过。换体本身不致命。

### 4.3 不是“右端函数有状态”（我一开始的判断，已推翻）
`Velch/validation/crh380a_m/check_purity.py` 的输出：

```
pure   : |f(s)-f(s)|        = 0.000e+00
pure   : |f_after_jitter-f| = 0.000e+00
impure : |f_after_jitter-f| = 0.000e+00   ← 不纯的版本也毫无差异
```

原因：主算例 `contact_search_half_width_m = None`、`body_hysteresis = False`，所以 `_contact_seed` / `_active_body` **从未被写入**，右端本来就是纯映射。

### 4.4 不是力律不连续（最关键的判决实验）
`Velch/validation/crh380a_m/probe_force_continuity.py`：固定其它状态，把前轮对垂向位移从完全脱离压到初始姿态。

| 抬升 µm（负=抬高） | −300 | −200 | −150 | −100 | −50 | −20 | −10 | −5 | 0 |
|---|---|---|---|---|---|---|---|---|---|
| N kN | 0.000 | 18.87 | 78.49 | 162.37 | 261.03 | 325.69 | 348.01 | 359.18 | 370.43 |
| 侵入 µm | 0 | 31.0 | 75.1 | 121.5 | 167.0 | 193.5 | 202.3 | 206.6 | 210.8 |

`N(δ)` 连续、单调、δ→0 平滑归零。**所以“力律正则化（照 Simpack 的 `fn.dref` 改造）”这条不必做。**

### 4.5 当前诊断
失败点是**内层 Newton 在极端接触切线下用差分雅可比无法收敛**：`∂N/∂δ ≈ 2.3 kN/µm`（量级 `1.5N/δ`），配 `rtol=1e-6`、布尔稀疏模板、无解析导数；Newton 校正被放大的舍入误差推走，步长压到零后溢出。收紧容差要求更高校正精度，反而更早崩（见 §3.2 第三行）。

## 5. 两条待走的路（按推荐顺序）

### 路线 A：解析雅可比（推荐先做）

目标：给出 `∂(dstate/dt)/∂state` 的解析（或半解析）形式，覆盖四个贡献：

1. **质量项**：`d/dt[v, F/m]` 对 `v` 的块 `[[0, I], [0, (1/m)∂F/∂v]]`；
2. **悬挂/连接器**：`Connector.force` 已是 `k·Δ + c·Δv` 线性形式，导数是常数矩阵，可直接组装；
3. **轨道层（`layered` / `local_compliant`）**：同为线性弹簧-阻尼链，常数块；
4. **接触项（唯一难点）**：对每个激活斑，
   `∂N/∂δ = 1.5·C·√δ`（条带律下 `C=(4/3)E*√R*`），
   `∂δ/∂q = −[∂z_rail/∂q − ∂z_wheel/∂q]`，其中对轮对只涉及其 5 个自由度（`y, z, roll, spin, yaw`），对轨道层只涉及其 `z` 自由度；
   切向力对 `q, v` 的导数走 `μN·tanh`/`sditt_cubic_saturation` 的解析式；阻尼项 `c·δ^0.5·v_n` 同理。

施工顺序建议：
- 先写一个**有限差分对照器**（`check_jacobian.py`）：随机抽 30 个状态点，比解析 vs 中心差分（步长 1e-9 相对），要求相对误差 < 1e-6；这一步不通过不要往下走；
- 再把雅可比接进 `solve_ivp(method="BDF", jac=...)`；
- 最后跑 §3.1 的两个窗口回归（必须与 80.5 kN / 83.3 µm 一致），再跑整车。

**风险**：接触激活集切换时雅可比跳变，BDF 仍会在换体附近反复拒步。若出现，配合路线 B 的阻尼项，或对激活集切换做事件检测（见 §6）。

### 路线 B：接触阻尼 / 雅可比正则化

思路：在 δ→0 的擦边带里给法向阻尼一个**下界**（不是加上限）。当前 `damping_force_cap_ratio=0.5` 是**上限**，防的是冲击；这里要的是**下限**，保证 `∂F/∂v` 在 δ→0 时不退化为 0，从而让 Jacobian 的条件数有界。

具体：`c_eff = max(c_law(δ), c_floor)`，`c_floor` 由目标阻尼比反推：
`c_floor = 2ζ√(m_eff·k_eff)`，`k_eff = 1.5·C·√δ_ref`，`δ_ref = 65 µm`（静平衡侵入），`m_eff = 1780 kg`（轮对），取 `ζ = 0.1–0.3`。算量级：`k_eff ≈ 8.4e8 N/m` → `c_floor ≈ 2×0.2×√(1780×8.4e8) ≈ 1.1e6 N·s/m`。

**注意**：这会改变物理（增加擦边阻尼），必须验证：
- 整程峰值不得低于 89.7 kN 太多（否则是把冲击抹掉了）；
- 30–60 Hz 带 rms 不得明显变化；
- 平直段静载仍为 59 680.5769 N、静平衡侵入仍为 65.47 µm。

若二者冲突（物理被改变），说明路线 B 只能作为**数值正则化**使用，并要在文档里明确标注“此项为求解器稳定化，不是物理模型”。

## 6. 如果 A、B 都不成：事件检测（成本最高，但最干净）

在 `δ` 穿越 0（接触生灭）与活动轨体集合变化处插入事件点，`solve_ivp(events=...)` 让积分器**停在非光滑面之前**，重启后再继续。代价：每步都可能触发事件，步数上升，可能吃掉隐式的收益；但能把“跨非光滑面”变成“分段光滑”，从根上解决。

文献支撑（本会话已检索到，可直接引用）：
- 非光滑变分积分器：[Discontinuous variational time integrators (NME)](https://onlinelibrary.wiley.com/doi/abs/10.1002/nme.4764)
- 半 Hertzian / 虚拟侵入：[Pascal & Soua, VSD 2016](https://www.tandfonline.com/doi/abs/10.1080/00423114.2016.1161201)、[道岔专用半 Hertz (HAL)](https://hal.science/hal-01216416v1/document)

## 8. 环境与工具陷阱（本会话反复踩，务必遵守）

1. **PowerShell 没有 heredoc**（`<<'PY'` 报 `'<' operator is reserved`），且 `python -c` 内含引号 / 三引号 / 中文必被解析破坏（`SyntaxError: unterminated quoted string`）。**凡带引号或中文的 Python 一律用 write 工具写成 `.py` 再执行。**
2. **不要用 `ConvertFrom-Json` 读 `manifest.json`**：`asset_hashes` 含 `\\` 转义，抛 `ArgumentException` 并把 200 KB 清单刷满控制台（本会话因此浪费过一次上下文）。改用 Python 只打印标量。
3. **算例里的资产路径是相对算例文件所在目录**（`bodies/*.csv`、`G:\...\*.prr`）。把派生算例写到子目录会报 `FileNotFoundError: ...\fleet\bodies\main_r0791310.csv`。派生算例必须与源算例同目录。
4. `pytest` 默认临时目录有 ACL 问题（`WinError 5`），必须传 `--basetemp F:\velch_tmp\pytest`。
5. 修改 `save_vehicle_result` 时注意 `TrackKernel(...)` 构造参数要同步（历史上漏传 `track_layers` 导致算完却写不出 manifest）。
