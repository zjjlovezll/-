# 直向横向：起点偏移是零，漂移是 B047（横向定位刚度 ~10³ 倍）

日期：2026-10-29（目标第 14 轮）
脚本：`scripts/s72_straight_stock_baseline.py`（新增 `lateral.csv` 与 `lateral_*` 汇总）、`scripts/s73_straight_pair.py`（新增 `--creep-kalker`，诊断专用）

## 一句话

直向算例的横向问题**不是**"初始就偏了"，而是**横向定位刚度比物理值大约三个数量级**——也就是早已登记过的 **B047**；
它同时解释了直向横向漂移、0.45 s 的左右载荷不均，以及把蠕滑刚度调到 Kalker 量级之后**更早**撞斜率门。

## 一、起点偏移是零，漂移是真的（40 → 50 m，0.45 s，80 km/h）

```
lateral start (mm): +0.0000, +0.0000, +0.0000, +0.0000     ← 四根轮对都在正中
lateral drift (mm): -37.7657, -21.3213, +0.1107, +0.5043   ← 0.45 s 后
```

前转向架两根轮对沿 −y 走了 **37.77 mm / 21.32 mm**，后转向架两根几乎不动（+0.11 / +0.50 mm）。
所以这是**导向轮对的横向失稳/游走**，不是座椅偏心。
（同时说明：`_seat` 只解垂向，横向初值是 0，这个"零"是可信的，不是没测。）

## 二、横向刚度实测：−235 kN/mm，比物理值大约 10³

在坐好的状态下把 `wheelset1` 横向平移 ±1/±2/±3 mm，冻结其它坐标求一次力：

| dy (mm) | ΣFy (kN) | ΣMz (kN·m) | 左斑 N (kN) | 右斑 N (kN) |
|---|---|---|---|---|
| −3.00 | **+705.2** | −537.2 | 1362.4 | **0（无接触）** |
| −2.00 | +162.6 | −402.3 | 669.9 | **0** |
| −1.00 | +44.4 | −195.6 | 297.4 | **0** |
| 0.00 | +0.7 | −8.5 | 65.7 | 53.8 |
| +1.00 | −36.5 | +177.1 | **0.8** | 267.2 |
| +2.00 | −147.0 | +376.0 | **0** | 621.8 |
| +3.00 | −564.3 | +586.4 | **0** | 1279.8 |

三点判读：

1. 斜率 ≈ **−235 kN/mm**（±3 mm 之间 1 269 kN / 6 mm）。一个 920 mm 车轮、1:40 踏面、等效锥度 λ≈0.05 的轮对，
   这个量级应是 **0.2–0.3 kN/mm**——差 **约 900 倍**，与已登记的 **B047「横向定位硬 927 倍」** 同一个数。
2. **±1 mm 就有一侧完全失去接触**（右斑 0 N / 左斑 0.8 kN）：物理上 1 mm 只让轨顶高度变 1.7 µm，
   不可能掉接触。这说明横向位移被映射成了**深度**尺度的变化，而不是沿轨顶的微小滑动。
3. 符号是**恢复**的（dy>0 给 −Fy），所以不是"发散的锥度"，而是"过硬的定位"——这和曲线侧"
   轨顶横向力被冻结在 2.5 %"（b33）是同一族病根的正反两面。

## 三、把蠕滑调到 Kalker 量级后，撞门**更早**（诊断，不是修法）

同一算例、同一座椅，只把 `creep_stiffness_x_n / lateral_n` 从 1.0e6/5.0e5 改成 3.5e6/2.5e6：

| 配置 | 结果 |
|---|---|
| 冻结蠕滑 | `graph slope limit at axle1_right/right:stock, x=67.0301769 m`（走 17.03 m） |
| Kalker 蠕滑 | `graph slope limit at axle1_right/right:stock, x=54.3310837 m`（走 **4.33 m**） |

**更硬反而更早爆**——所以蠕滑刚度不是病因，它只是把 B047 的后果放大。

## 四、结论与下一步（顺序被改写）

- 直向横向问题的**根因是 B047**（横向定位刚度 ~10³ 倍），不是尖轨几何、不是座椅偏置、不是蠕滑标定；
- 因此尖轨区（50.578–57.304 m）与心轨区（103.28–116.44 m）的降低值反演，**都必须等 B047 定位清楚**；
- 下一步（预先写死的判据）：在 `contact_search` 里量出"横向位移 1 mm → 接触点/侵入量各自变化多少"，
  判定它是**型面横向标尺错**（`y_scale_m`/`y_offset_m`/镜像）还是**搜索的横向窗太窄**；
  判据：修好后 `dΣFy/dy` 落在 **0.05–0.5 kN/mm**，且 ±3 mm 内**不出现单侧掉接触**；
  再回到 0.45 s，要求漂移 < 1 mm。

## 二b、B047 的机制：1 mm 横向被映射成 ~210 µm 深度，因为接触落在轨距角而不是轨顶

在坐好的状态上逐点打印侵入量与接触点位置（`wheelset1` 横向平移 ±1 mm）：

| dy | 左斑 N / pen / lever_y | 右斑 N / pen / lever_y |
|---|---|---|
| 0 mm | 65.72 kN / **74.62 µm** / −0.73654 | 53.79 kN / **62.94 µm** / +0.73707 |
| +1 mm | 0.78 kN / 3.59 µm / −0.73927 | 267.22 kN / **273.09 µm** / +0.73083 |
| −1 mm | 297.38 kN / **292.12 µm** / −0.73041 | 0 kN / — / — |

两条读数直接指出机制：

1. **横向 1 mm → 深度 63→273 µm**（+210 µm）。物理上 r≈300 mm 的轨顶，1 mm 横向只对应 **1.7 µm** 高度变化，
   即这条链把横向放大了 **约 1.2×10⁵ 倍**（与 B047 的 927 倍是同一族，且量级更大）。
2. **`lever_y` 比两轨冠位置（∓0.75325）内移了 16.7 mm**（−0.73654 / +0.73707）。也就是说
   **车轮不是坐在轨顶上，而是压在轨距角/圆角上**——那里的型面坡度远大于 1:40，所以横向一动就是几百微米深度。

这正是 B047 的可用定义：**判据不是"力太大"，而是"接触点应当落在轨顶（|lever_y − 轨冠| ≲ 2 mm）"**。
所以下一步修的是**横向对位**（车轮滚动圆在断面里的 `local_y` 与轨冠的配准），而不是任何刚度。
