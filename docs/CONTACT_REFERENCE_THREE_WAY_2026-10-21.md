# 三方对拍：解析真值 / 45 µm 网格 / 分段样条 2026-10-21

证据等级 **A（analytic）**。真值来自闭式解，不是更密的网格：1:40 锥形踏面（直线）
压在半径 0.30 m 的圆弧轨顶上，接触点、侵入、`R*`、Hertz 力全部可解析求出。

- 样本：下沉 (0.05, 0.1, 0.2, 0.4, 0.6) mm × 横移 (-8.0, -4.0, 0.0, 4.0, 8.0) mm，共 23 组
- 网格步长 45 µm（与求解器一致），网格臂取 argmax + 三点抛物线顶点
- 样条臂取分段三次样条，接触点为 `d(gap)/dy = 0` 的 Brent 根，不依赖采样密度

## 实测结论

- **Δδ 两臂几乎相同**：网格 0.122–0.278 µm、样条 0.123–0.279 µm。在**光滑单圆弧**几何上，45 µm 网格 + 三点抛物线顶点已把极值恢复到位，分段样条没有可测量的优势。
- **Δy 样条略优**：两臂都偏 10.65–23.14 µm，差值基本恒定 ≈0.81 µm，随下沉量线性放大——这是近水平接触上 `dy/dδ` 放大的几何后果，不是精度排序依据。
- **ΔN 两臂同为 +0.047%～+0.047%**，符号恒定。这不是误差：真值给**法向**侵入，两臂量**竖向** gap 最大值，相差 `cos = 1/√(1+k²)`，`(1/√(1+1/1600))^1.5 = 0.999531` 即 −0.0469 %，与实测吻合到三位有效数字；该项在两臂之间完全抵消，不影响对比。

## 读法

1. `Δδ` 是两条臂对**同一真值**的偏差；网格的偏差主要来自 45 µm 采样落在真极值两侧，
   抛物线顶点只能部分补偿；样条臂直接对导数求根，因此不受采样相位影响。
2. `Δy` 在近水平接触上被 `dy/dδ` 放大，绝对值大不代表几何更差——判据以 `Δδ`、`ΔN` 为准。
3. 本表的真值几何是**单圆弧 + 锥形踏面**。真实道岔断面含台肩槽与折点，那里的真值不可解析，
   只能降到等级 B（`docs\CONTACT_GEOMETRY_ERROR_BOUND_2026-10-21.md` §4），两份报告不可混用。
4. **因此样条不是“更准的通用替换”**：光滑几何上与网格打平（Δδ ≤0.3 µm、力差 ≤0.05 %），
   其价值只在折点/槽壁（等级 B 报告里 3.639 µm 的分歧）；设为默认后端没有精度收益。
