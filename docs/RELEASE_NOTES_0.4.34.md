# Velch 0.4.34 发布说明

**日期**：2026-10-26

**主题**：轴箱少了一个转动约束——找出来、修掉，然后重测长波与短波反演

## 本轮结论

### 1. 那个永不衰减的 13 Hz 不是激励，是一个缺失的约束（B027）

零不平顺算例里，轴箱垂向加速度通道有一条 13 Hz、9.2 m/s² 的谱线，6 s 只衰减 1.1 %，接触占空比 1.0000。模态审计把它定位成 **13.094 Hz 的四重根、ζ = +0.0000**，动能 97.6 % 落在八个轴箱的垂向平动上；它所在的 z 行只有两条元件：`bearing_a*_z`（k 1e8，**c = 0**）与 `primary_*_z`（k 1.176e6、c 1e4），而该模态在这条链上**没有相对速度**，所以加阻尼无效（试到 2e5 N·s/m 仍是 ζ = 0）。

根因是装配：Simpack 的轴箱由 `joint.type = 2`（转臂式铰）定位，我们有平动弹簧但没有**转动**约束，轴箱因此保留了一个刚度恰好为零的方向。补上八个 `box_roll_*`（box↔bogie，**1.4e6 N·m/rad**，取 `k_y·b²`；阻尼 2.0e3 N·m·s/rad）后：

- 四重根消失，10–16 Hz 带变成 `12.005/ζ0.185、12.161/ζ0.171、12.620/ζ0.0042`；
- `decay` 从"6 s 后剩 98.9 %"变成 **0.0 %**；
- 890 项测试通过，其中 `tests/test_axlebox_rotational_restraint.py` 四条专门守着这件事（删掉八个元件，ζ < 1e-3 立刻回来）。

### 2. 短波：8 个倍频程带里 6 个进了 2 dB

|---|---|---|---|---|---|

| 0.1–0.2 | 252 200 | 2.25 | 2.49 | +10.7 % | **+0.88** |
| 0.2–0.4 | 61 310 | 8.50 | 10.63 | +25.0 % | **+1.94** |

### 3. 350 km/h 的深度误差从 +23.2 % 降到 +4.9 %

同一算例（50 mm、20 kHz、`CRH380A_M_axlebox`）重跑：**31.47 µm** vs 30.00 µm 真值，逐窗散布 1.31 → **0.43 µm**。此前的 +23.2 % 不是欠采样（2e-5 s 求解步长给出逐位相同的 36.96 µm），是这个 13 Hz 模态把接触状态与通道方差一起抬起来的结果。

### 4. 深度扫描：短波增益随幅值变化约 30 %

50 mm 波长、10 / 30 / 60 µm：反演 13.26 / 38.41 / 63.57 µm，即 **+32.6 % / +28.0 % / +6.0 %**。所以"一个常数"只在小幅值档成立，精度必须写成"在给定深度档内"。

### 5. 长波（20/40 m）：标定 1.9 %、闭环 0.66 %，两条门槛都过

`scripts/s9_inversion.py --columns` 在延长的站位表上重跑（12 次运行、9 737 s、全部 `numerically_checked`）：

| 变体 | 条件数 | 标定误差 | 逐带误差 | 反演 (mm) | 闭环 |
|---|---|---|---|---|---|
| **V**（轴箱垂向） | 1.37 | **1.9 %** | +0.1 % / −2.5 % | 0.08305 / 0.10043 | **0.66 %** |
| D（车体−轴箱） | 1.16 | 2.6 % | −2.0 % / −2.9 % | 0.08132 / 0.10003 | — |
| V+D | 1.25 | 2.5 % | −1.5 % / −2.9 % | 0.08177 / 0.09999 | — |

真值 0.0830 / 0.1030 mm，H 的 V 对角 957.80（20 m）/ 234.01（40 m）(m/s²)/m。上一轮报的 3.8 % 是在**末站位只到 150 m 而行程到 218 m**的无效记录上得到的（窗口 31 % 自由落体），不能与这 1.9 % 并列。

- 236.5 Hz、373.7 Hz 一带还有 20 个 ζ < 0.005 的模态（接触/钢轨侧）；
- `1.4e6 N·m/rad` 是等效值（`k_y·b²`），不是实测的转臂节点扭转刚度；
- 论文的 345/378 Hz 仍不复现；
- `physics_validation_status` 仍是 `unvalidated_against_measurement_or_Simpack`——所有精度数字都来自自建仿真，没有一条实测标定。
