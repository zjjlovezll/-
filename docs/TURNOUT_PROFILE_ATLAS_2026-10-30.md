# 道岔廓形认图：文件夹里到底是什么形状（第 222 轮）

两个来源文件夹里的 `.prr` **不是里程表**，而是一个断面一个文件；文件名就是断面的名字。

```
直向：G:\研究生\动力学\CRH380A_纯刚性模型\database\database\wheel_rail_profiles   247 个文件
侧向：G:\研究生\道岔\道岔动力学\wheel_rail_profiles\wheel_rail_profiles            191 个文件
```

命名即中文拼音首字母：

| 代码 | 含义 | 出现在 |
|---|---|---|
| `JBG` | 基本轨 | 直向 |
| `JG_XX` | 尖轨（**基本轨 + 尖轨 组合断面**） | 直向，XX = BB…MM |
| `XG_XX` | 心轨（组合） | 直向，XX = DD…LL |
| `YG_XX` | 翼轨（组合） | 直向，XX = BB…DD |
| `YG_DD_XG_DD` | 翼轨 + 心轨 同时出现 | 直向 |
| `R<里程>` / `L<里程>` | 该里程处的单根钢轨断面 | 直向 201 个 / 侧向 148 个 |
| `CB…CF`、`DB…DE`、`JB…JF`、`Z`、`ZS` | 侧向特征断面 | 侧向 |

## 一、形状（已出图，见 `scratch/s78/s78_jg.png`、`s78_xg_yg.png`、`s78_curved.png`）

每一个"组合断面"都被画成**一条连续的上表面**：左（−y）是基本轨（或翼轨），右（+y）是另一根轨，
两者之间是一个 **V 形槽**（轮缘槽）。槽的右壁就是尖轨／心轨的头部。随着断面推进，
槽的位置向左／右移动、第二根轨的头部逐渐外移，`span` 从 72 mm 一路涨到 148 mm。

竖直方向：**z 向下为正**，轨顶在 0，两侧落到 +30 mm。

## 二、从几何里直接读出设计降低值（这是本轮最要紧的表）

组合断面里有两处 crown（局部最高点），它们的**高差就是降低值**。实测（`scripts/s78_profile_atlas.py`）：

| 直向断面 | 尖轨顶 z | 基本轨顶 z | **降低值** |
|---|---|---|---|
| JG_BB / JG_CC | 单头（尖轨尚未露出） | 0.000 | — |
| JG_CC_1 | **+14.000** | 0.000 | **14.000 mm** |
| JG_DD | +8.489 | 0.000 | **8.489 mm** |
| JG_EE / EE_1 | +3.429 | 0.000 | **3.429 mm** |
| JG_FF | +1.401 | +0.001 | **1.401 mm** |
| JG_GG | +0.308 | 0.000 | **0.308 mm** |
| JG_JJ / JJ_1 | +0.124 | 0.000 | **0.124 mm** |
| JG_KK | 0.000 | 0.000 | **0.000 mm** |
| JG_LL | −0.004 | 0.000 | 0.004 mm |
| JG_LL_1 / JG_MM / MM_1 | 单头（已并入走行面） | −0.004 | 0.000 mm |

**这条曲线是本项目现在最硬的一条真值**：它不是我们写进去的不平顺，而是图纸本身。
最大降低值 **14.000 mm**（不是此前假定的 23 mm），并在 KK 断面收敛到 0，
即"尖轨从被埋 14 mm 抬到与基本轨齐平"。

侧向文件夹里同族的两条：

| 侧向断面 | 两 crown 高差 | 判读 |
|---|---|---|
| `JB` | **14.040 mm** | 与直向 JG_CC_1 的 14.000 同族 —— 尖轨降低值 |
| `JC` | 3.078 mm | 降低值序列 |
| `JD` | 0.522 mm | 同上 |
| `JE` | 0.015 mm | 同上（已齐平） |
| `CB/CC/CD/CE/CF` | **11.968 mm**（恒定） | **轮缘槽深**，不是降低值 |
| `DB/DC/DD/DE`、`Z`、`ZS` | 0.000（单头） | 普通断面／已合并 |

所以：**直向看 `JG_*` 的 14 mm 序列，侧向看 `JB…JE` 的 14.04→0.015 序列**；
而 `CB…CF` 那 11.968 mm 是轮缘槽深，量的是另一件事，不能混进降低值。

## 三、这条读数改变了什么

1. **P1 的真值来源换了**：此前用算例站表的 `z_offset_m`（zjg 里程表，23000 µm 到 0）；
   现在直接从图纸断面读出 **14.000 mm @ CC_1 → 0 @ KK**，是几何本身，与站表互相独立。
2. **降低值的量级要改**：20–23 mm 是"峰值"式的估计，图纸给的是 **14.000 mm**。
   这直接影响我们上一轮反演出的 23.0 mm 是偏大还是偏小 —— 现在有了独立答案。
3. **轮缘槽深 11.968 mm** 第一次被量出来，它是接触几何的真实台阶，
   可以用来检查"轮缘是否会压到槽底"这类问题。

## 四、一个必须写下的限制

侧向文件夹里的断面**只有 247 个点**（直向是 1999 个）。
247 点在 105 mm 跨度上平均 **0.42 mm 一个点**，对轮轨接触的曲率与法向精度是不够的；
用它做侧向接触时，这个采样密度必须当成已知误差源写进结论，而不是默认没问题。
