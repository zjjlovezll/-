# M2 第一轮：冠偏移扫描——四条门无一成立（2026-10-31）

本文件记录 `scripts/s104_crown_offset_sweep.py` 的结果与它暴露的一件事：**我预注册的第 2 条门在几何上是不可能满足的，与冻结基线自相矛盾。**

## 一、被扫的是什么

`s85_db_case.py:81` 的 `CROWN_OFFSET_M = 13.0e-3`：

```python
y_offset = side * (0.7465 + CROWN_OFFSET_M) - y_sign * crown_y_m(file)
```

每站先抵消自己的冠位，再把冠推离轮平面 13.0 mm。注释记录该窗口是"12.0–13.7 mm 八轮 1.000× 均分、<10 mm 压肩部 1087 kN、>14 mm 脱空"，但那是拿 **35 坐标刚性轮对车**拟合的；规范算例（`cases/straight_one_set.json`）是 **86 坐标完备车 + 柔性轮对 + 柔性轨**。

扫描不改 `s85`、不覆盖规范算例：把每个站的 `y_offset_m` 平移 `±(offset − 13.0) mm`（左 −、右 +），生成 `scratch/s104/one_set_off{13,10,8,4,0}.json`，然后座椅 + 7 档横移（−3…+3 mm、只求值不重解座椅）。

## 四、这一轮真正的发现：第 2 条门与冻结基线矛盾

第 2 条门写的是 `|lever_y − crown_y| ≤ 2 mm`（"接触必须落在冠上"）。但：

```
1:40 踏面斜率 s = 0.025，轨头冠半径 R = 0.300 m
斜率相等点距冠顶  y = R·s = 0.300 × 0.025 = 7.5 mm
```

**一个 1:40 的锥形踏面压在 300 mm 的冠上，接触点本来就在冠顶以内 7.5 mm**；实测 8.03 mm（差 0.53 mm，来自踏面非严格锥形：实测倾角 **0.02458**，比 0.025 低 1.7 %；按 0.02458 算 `R·s` 是 7.37 mm，仍有 0.66 mm 残差，说明接触处的轨头局部半径比名义 300 mm 大，约 327 mm）。

更要紧的是：**冻结基线自己就不满足这条门**。规范算例座椅态的倾角是 **±0.02458**（冻结 oracle 的文案写 `n_y/n_z = ±0.0250`，差 1.7 %；两者都在 2.5 % 踏面锥度附近），接触距冠 8 mm——也就是说，如果坚持"接触必须在冠顶 2 mm 内"，那么**这个项目从第一天起引用的 59 680.5769 N / 65.4661 µm 那一组数本身就是"错的"**。这条门不能用来判模型，只能判我自己写错了门。

因此按"不许看过结果改阈值"的红线，处理方式不是改门重判，而是：

1. **保留原判**：四条门在五个偏移上全部不成立，`s104` 的 `VERDICT` 就是结论；
2. **另立一条门并记录它为什么必须另立**：`tangent`（接触点必须落在斜率相等点，`|lever_y − crown_y| ∈ [R·s − 2 mm, R·s + 2 mm]` 且 `‖tilt‖ − s| ≤ 0.005`）。按这条门，**13.0 mm 档通过**（8.03 在 7.5±2 内，倾角 0.02458 与 s = 0.025 差 1.7 %），10.0/8.0 两档不通过（倾角 0.03325 / 0.04988，已不是 1:40 踏面在接触，而是踏面更外侧的锥段）；
3. 两条判定**并列写入任务书**，原门保留作废记录，不删。

## 五、由此得到的判据修正（下一轮）

M2 要修的**不是接触点位置**，而是接触阻抗。位置由斜率相等定、倾角 0.0250 与冻结基线一致，这两条都说明**几何注册是对的**；真正可疑的是 `dN/dy = 45 kN/mm` 这个量级——它比"把 25 µm/mm 的贯入变化乘上 dN/dδ"大 4 倍。

下一轮（判据先写）：在规范算例上做**条带宽度收敛**，`strip_dy_m ∈ {5e-4, 2.5e-4, 1e-4}` 三档各跑一次座椅 + ±1 mm 横移，判据是

- `dN/dy` 三档之间相对变化 ≤ 5 % ⇒ 不是条带宽度造成的；
- 若随 `strip_dy` 单调显著变化 ⇒ 是条带积分的离散化，改它（不动接触刚度、不动容差）；
- 无论哪种，冻结基线必须 `UNCHANGED`。
