# Velch 0.4.10 发布说明（2026-10-23）

## 这一版装的是什么

onedir 目录包：`Velch.exe`（窗口版）+ `velch-cli.exe`（命令行）。双击 `启动 Velch.cmd` 或
`Velch.exe` 进入界面，七个屏（① 算例 ② 运行 ③ 时程 ④ 频谱 ⑤ 评价 ⑥ 对照 ⑦ 三维）。

## 相对 0.4.9 的新增

**⑦ 三维屏可以显示接触斑**：叠加一个 `out_*` 运行后拖时间滑块，每个车轮下方的接触斑按
`history.csv` 记录的法向力着色（绿 <80 kN、黄 <120 kN、红 ≥120 kN），并标出整数 kN。

- 位置取"车轮正下方"（轮对状态 + 车轮横向偏置 ±0.7465 m），不是接触通道里那对相对量
  （实测 `y_m ≈ 0`、`z_m ≈ −1.2 mm`，按它画会把八个斑叠在轨道中心线上）。
- 圆环半径是 `sqrt(2Rδ)` 的**几何弦长**（R=0.43 m、δ≈65 µm → 约 7.5 mm），不是 Hertz 解；
  屏上注记写明这一点，也写明旁边那根 20 mm 竖杆是指示杆、不是斑高。
- 视图**不重跑接触搜索**（架构规则禁止 UI import 求解栈），所以它显示的是算过的帧，
  而不是对任意状态现算的接触。

## 同时带上 0.4.9 的修复

空语料首启可读（提示折行并挪到表格上方）、按钮宽度下限（`BUTTON_MIN_CHARS = -3`）、
布局闸门逐屏量按钮（1.0/1.3 × 有/无语料）、语料改显式 `pytestmark = pytest.mark.corpus`、
CSV 列选择不再默默猜。

## 验证

- `pytest` **533 passed, 1 skipped**（有语料）；无语料配置 0 失败
- `velch.ui --selftest`：7 屏 / 0 报错 / 退出码 0
- 冒烟五步：自检、CLI 实跑、缺语料提示、中文+空格路径、安装目录不被改写
- 物理未动：静载门 59 680.5769 N / 65.47 µm、八接触峰值 89.68 / 170.61 kN、七项 manifest 门、
  DOP853 逐位等价——本轮改动全部在 `ui/` 与文档

## 仍然没有的

1. Simpack **横向布置**（双体交接）未导入，单侧导入会改轨距，默认拒绝（O008）。
2. Simpack 的数只作对照值；写进算例的物理量仍由人显式给出。
3. 没有与 Simpack 结果的定量对照报告（下一步）。
4. 无代码签名；卸载 = 删目录；只读安装的 ACL 步骤仍是手工（O009）。
5. `physics_validation_status` 仍为 `unvalidated_against_measurement_or_Simpack`。
