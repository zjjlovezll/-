## 1. 本轮要补的那一半（S9-1，约 1.5 h）

**问题**：现在深度和法向是"事后手改"，接触点位置仍是刚体搜索给的。文献（Gao & Dai, AMM 105-107 (2012) 1284，见 `docs/LITERATURE_LOG.md` L11）的做法是**在变形后的踏面上搜索**：`x = x_rigid + Φq`，接触线由变形后法向给出，接触点取"竖直距离最小"。

**做法**：把变形**放进型面本身**，让搜索自己得出接触点位置与法向。

```
A = normalize(K) · Φ_z              # K: 踏面环高斯核 (n_node × n_node)，一次性预计算
dz(u) = A(u) · q_block              # 每次求值只做一次 matvec（386×33）
z_profile(u) ← z_profile(u) + interp(dz)(u)   # 变形后的车轮型面，交回 find_graph_contact
```

三条理由：① 位置、法向、深度三者自动一致，不会出现"深度说变形了、法向说没变"；② 预计算让每次求值的代价与节点数无关；③ 零模态时变形型面**逐位等于**原型面，刚性算例不受影响。

**判据**：

- 模态 q 全零 → 变形型面与原型面 `np.array_equal`，`history.csv` sha256 与刚性一致；
- 常数 dz（整体抬升）→ 力比 `((δ−d)/δ)^1.5`（1e-6），法向不变；
- 倾斜 dz → 法向转角 `−atan(slope)`（1e-6），接触点横移方向与斜率符号一致；
- 手改法向/深度的旧路径**删除**（避免双重计入），旧测试改成测型面路径。
