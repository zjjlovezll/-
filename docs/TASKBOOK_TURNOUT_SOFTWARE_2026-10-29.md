## P1 道岔真实几何与独立真值（当前阶段）

**目标**：让算例真的含 18 号道岔的五族断面与降低值，然后用"零不平顺 → 反演 → 还原降低值"
这条零对照验证反演链。这是唯一一条**真值来自设计**的验证。

| 步 | 内容 | 判据 |
|---|---|---|
| P1.1 | 按 `CN18-Mileage-*` 五族断面建算例（含角色切换 `zjg_zgyg`、`qjbg`、`cx`） | 零降低值时八轮静载 8/8、`ΣN = 1.000×` 车重；横向线形与现算例一致时历史可比 |
| P1.2 | 降低值按设计表以每站 `z_offset` 叠加 | 尖轨区出现"尖端逐渐承载"的单调过渡（相邻 5 m 内接触力 0 → 均分） |
| P1.3 | 零对照反演（无 `.tre`、无 PRR 改写） | 定位 ≤ 5 m；幅值 ±2 dB；尖轨尖端与心轨鼻端**不互换**；零降低值回落本底 |
| P1.4 | 叠加已知波磨，检验"降低值 + 波磨"能否分离 | 两个特征的定位各自 ≤5 m；幅值互不串扰（≤3 dB） |

**阻塞**：降低值表不在断面数据里（两套数据冠部都与基本轨齐平，实测 −0.019…+0.000 mm）。

或由用户提供 18 号道岔铺设图的降低值曲线。

## P2 横向定位机理（曲线能否"可引用"的分水岭）

**根因**：横向自动定位由 65.47 µm 的 Hertz 压入深度配一个**冻结的 1:48 接触角**决定
（`k_force = 5 404.5 kN/m`、`k_transfer = 240 kN/mm`），真实轮对则由**锥度 + 蠕滑**定位
（`k_grav = 5.83 kN/m`）——**硬 927 倍**（B047）。它的上游是第 203 轮的"倾角冻结"：
接触点在踏面上不随横移演化（`d(n_y/n_z)/dy ≈ 0`，实测 6.9e-16）。

| 步 | 内容 | 判据 |
|---|---|---|
| P2.1 | 让接触点沿踏面演化（等效锥度随横移，解除倾角冻结） | `d(n_y/n_z)/dy` 有量级；等效锥度落在 1:20–1:40 的物理区间 |
| P2.2 | 重测 `k_force` / `k_transfer` | `k_force/k_grav ∈ [0.2, 2]`（B047 关闭） |
| P2.3 | R=1100 m / 80 km/h / cant=0 从 8/8 座实起跑 1.0 s | 八轮全程 ∈[0.625,1.6]×，`|sum Fy| ≥ 0.9×` 需求 |
| P2.4 | 带超高工况重测 | 同上；并证明 `cant=0` 与本文档前数值逐位一致（除 P2.1 的显式版本变更） |

**代价与风险**：这会改变所有算例的数值。冻结基线必须**显式升版**（v0.5），不能静默漂移；
`freeze_baseline` 要留下"旧基线 → 新基线"的对照表与原因。
