# 宽度感知的分离律反演：50 µm 折到 0.53 %，但载荷分配在膝点饱和（2026-10-31）

## 一、为什么做这一步

第 255 轮量到：分离律**不塌缩**到"高出齐平"坐标，半载间隙随尖轨断面宽度移动——45 mm 断面（58.0 m）在
`u = +56.15 µm` 处半载，63 mm（60.0 m）在 `−2.27 µm`，72.2 mm（62.0 m）在 `+0.34 µm`。此前四族的估计器
（表 / tanh / 转移站位 / 接触模型）全部只按 `u = d − z` 标定，这正是它们在 100/200 µm 留出上失手的
候选原因。所以这一步把宽度写进律里，再重跑那三个幅值。

**关键点：这一步没有用鼓包数据拟合任何参数。** 律来自 s118 的**静态探针**，几何 `d(s)` 来自规范算例，
宽度来自断面文件名，`σ(s)` 来自归档运行。因此三个幅值**全部是留出**，包括此前当标定折的 50 µm。

## 二、模型

以 45.2 mm 断面（58.0 m）的实测曲线 `σ₄₅(u)` 为参考，沿间隙轴按"半载间隙"平移：

```
σ(u, w) = σ₄₅( u − g₀(w) + g₀(45.2 mm) )
```

`g₀(w)` 取三个实测锚点，宽度之间线性、范围之外**夹取**（夹取比例如实报出）。

## 三、先修一个符号错

第一版取 `u = −δ`，六个锚点全是镜像（45.2 mm → `−56.15 µm`）。`s118` 里 `delta_um` 就是探针施加的**间隙**：
正值 = 尖轨低于齐平、接触看到的间隙更宽，所以 **`u = +δ`**。改符号后锚点变成
`45.2 mm → +56.15 µm`、`62.5 mm → −2.27 µm`、`72.2 mm → +0.34 µm`，与第 255 轮文档里的半载抬升
（+97.3 / −16.3 / −21.0，那是**绝对抬升**坐标 `d + δ`）逐项对得上：`d(58.0) = 41.1`、`41.1 + 56.15 = 97.25` ✔。

## 四、实测

```
 amp   peak_est  peak_true   rel%    p95(µm)   at s    w(mm)   G-A/G-B/G-C
  50       52.6       50.0    0.53     160.8   57.98    45.0    Y / n / n
 100       63.0      100.0    7.41     210.6   57.81    43.7    n / n / n
 200       62.1      200.0   27.59     236.2   57.58    42.0    n / n / n
folds passing all three gates: 0/3
```

三件事分开说：

1. **50 µm 折的相对误差从 1.37 % 降到 0.53 %**（第 251 轮同一折是 1.37 %），说明宽度感知确实把"小幅值"
   这一端校对了；这是这一步唯一变好的地方。
2. **100 与 200 µm 不再能分辨**：峰值估计 63.0 与 62.1 µm、几乎相同，而真值差 2 倍。原因不是宽度，是
   **`σ` 在膝点饱和**——鼓包把间隙压到 `u ≲ −50 µm` 时 `σ → 1`，反演被夹在实测曲线的端点，任何更大的
   幅值都读到同一个 ~62 µm。这是**可观测量的饱和**，不是模型参数没调好。
3. **p95 变差（160–236 µm）**：窗口内 σ 饱和后 `u` 被夹在端点，误差随真值线性增长；这也说明"逐点剖面"
   在饱和区没有信息。

## 五、饱和区里唯一还活着的观测：饱和起始站位

三个幅值的峰值站位是 **57.98 / 57.81 / 57.58 m**，**单调**随幅值前移（相邻差 0.17 / 0.23 m）。这与第 252 轮
零参数族的"转移站位方程"是同一件事，只是这次用宽度感知的律读出来、且单调。⇒ 幅值信息在饱和区**不是
从 σ 的大小**来，而是从**它在哪一米开始饱和**来。

## 六、判定与下一步

- **能说**：宽度感知的律让 50 µm 折进 0.53 %；`σ` 在这套几何上对 ≳60 µm 的间隙闭合**饱和**，因此
  `σ` 单独不足以承载 100/200 µm 的幅值；饱和起始站位随幅值单调（0.17–0.23 m/档）。
- **不能说**：三个留出通过（0/3）；也不能说"宽度感知已经解决幅值问题"。
- **下一步（M7 的观测选择）**：把**饱和起始站位**当成主观测，与加速度的定位（第 250 轮：加速度定位到
  0.14–0.52 m）配对——站位给幅值、加速度给位置，这正好是第 250 轮写死的"加速度是定位器、逐体载荷是
  幅值载体"的修正版：**载荷分配给的是饱和站位，不是幅值本身**。
