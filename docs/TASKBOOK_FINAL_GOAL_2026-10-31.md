本文件是**最终目标的唯一收口文档**。它取代 [TASKBOOK_TURNOUT_SOFTWARE_2026-10-29.md](TASKBOOK_TURNOUT_SOFTWARE_2026-10-29.md) 中"精度 ≥ 90%"的表述方式，但保留其 P1–P5 的工程内容作为本文件的子集。任何后续轮次若与本文件冲突，以本文件为准；修改本文件必须同时改 §4 的预注册常量并升版号。

## 一、最终目标（用户原话要点，m00003）

1. **一组模型固定**：车辆用最好的车，轮对用**柔性轮对**，轨道用**柔性轨道**，合起来叫"一组模型"。车辆完备模型按现有最完善的车辆标准做，轮对只改踏面形状与若干模态。
2. **不同道岔柔性钢轨的建立先放一边**，之后再去完善如何建立柔性钢轨。
3. 用现有最完备的模型**反演道岔结构不平顺**，即反演**尖轨/心轨表面的整个三维面曲线**。
4. 用该三维面曲线与**该钢轨自己的 PRR 文件中拟合出的三维面曲线**逐点对照，计算精度；**精度 ≥ 90% 即认为算法准确性得到验证**。
5. 在此基础上再展开**随机不平顺**与**波磨不平顺**的反演。

## 三、反演对象

- 观测只能覆盖**接触斑扫过的那条窄带**（横向 10–20 mm）。定义
  `Ω_obs = {(s, y) | 本次运行中至少被一个接触斑覆盖}`，由 `history.csv` 的 `lever_y` **统计生成**，不许估算。
- 反演交付物是 **接触带面 `z(s, y)|Ω_obs`**，不是整个 2-D 场 `z(s,y)`。Ω_obs 外一律标"未观测"，并报覆盖率 `|Ω_obs| / |Ω_design|`。
- 「整个三维面曲线」若指全 `(s,y)` 平面，在轴箱加速度被动观测下**大概率不成立**；本文件按"接触带面"定义执行，若要改回全平面，属目标修订，需用户书面批准（§10 第 1 条）。

## 四、精度 ≥ 90% 的可判定定义（**待用户批准，本文件给推荐值**）

### 4.1 为什么不能直接用"相对误差 ≤ 10%"

设计降低值最大 14.94 mm，10% = **1.49 mm = 静侵入 65.4661 µm 的 23 倍**。也就是说：把尖轨面做错 1.5 mm，相对门照样通过，而 1.5 mm 的几何误差足以让整段"首触里程"位移数十米。相对门在这个尺度上**没有判别力**。

### 4.2 推荐：双门并列，主门为绝对误差

| 门 | 定义 | 阈值（预注册） | 地位 |
|---|---|---|---|
| **G-ABS（主门）** | `\|ŷ − y\|` 在 Ω_obs 上的 **p95**，尖轨区与心轨区分别报 | ≤ **1/3 静侵入 ≈ 22 µm**；工程目标 ≤ 5 µm | 决定"是否验证算法" |
| **G-REL（报告门）** | `\|ŷ − y\| / max(\|y\|, y_ref)`，`y_ref = 0.5 mm` 防分母塌陷；报 p50/p95 与**逐 2 mm 降低值分档**（0–2 / 2–6 / 6–15 mm） | 各档 ≥ 90% 点满足 | 只作分区报告，**不单独作结论** |
| **G-LOC（主门）** | 载荷转移/首触里程误差 | ≤ **±0.2 m**（现测可达，勿放宽到 5 m） | 与 G-ABS 并列 |
| **G-COV** | `\|Ω_obs\| / \|Ω_design\|` | 报数，< 0.2 时必须正式降级表述 | 触发"接触带面"措辞 |
| **G-NULL** | 把降低值置 0 后反演必须回落到本底 | `\|ŷ_null\| ≤ 0.2 × G-ABS 阈值` | 防"反演出自己注入的东西" |

`y_ref = 0.5 mm` 与 22 µm 都是**预注册常量**，一旦写下，看过结果再改即该轮结论作废重跑。

### 4.3 自证陷阱（必须一起写进任何对外结论）

"反演面 vs PRR 拟合面"若不跨表征，就是**自己比自己**：零注入时恒等 100%。因此证据分三级，命名不许混用：

| 级 | 内容 | 允许的措辞 |
|---|---|---|
| **A 数字闭环** | 正演 1999 点、反演粗基，同一模型内自洽 | 只许写 `numerically_checked` |
| **B 留出站** | 标定站与检验站分离 | 只许写"内插能力" |
| **C 独立真值** | atlas 7 个几何读数（+14.000 / 8.489 / 3.429 / 1.401 / 0.308 / 0.124 / 0.000 mm）+ ≥3 区段轨面实测 | 才许写"验证算法准确性" |

**C 级数据今天不存在**（实测数据集无轨面剖面）。所以在拿到 C 级数据之前，§一.4 的"验证算法"最多做到 A+B 级，必须如此标注。

## 六、红线（违者该轮结论作废）

1. **冻结物理不动**：59 680.57685863 N / 65.4661 µm / 八接触峰值 89.68 / 170.61 kN / 七门 / DOP853 逐位等价。要动必须升版并重新冻结，且用户书面授权。
2. **不许用"放宽容差 / 加大接触搜索窗 / 提高接触刚度"把失败变绿**。搜索窗只能改成**随轮心平移**（半宽不变）；接触几何只能**补横向曲率**；容差只能**收紧**，放宽须单独授权。
3. **加门不减门**。任何"某门通过不了就删掉它"的改动等于造假。
4. **看过结果再改阈值 / Ω_obs / 分带 ⇒ 该轮结论作废重跑**。
5. 引用任何数字必须能在 `docs/` 里找到对应脚本与复算命令；未落盘的读数不得写进结论。

## 八、成本与产能（决定能不能做完）

`WALL_PER_NFEV_S = 2.56e-3`、`NFEV_PER_STEP["DOP853"] = 138` ⇒ **1 s 仿真 ≈ 707 s**；66 m 过岔（2.97 s）≈ **2 100 s**；161 站 + 有限差分雅可比 ≈ **94 h / 次 Gauss–Newton 迭代**。

⇒ 全三维面**不可能**用逐列有限差分。可行路径只有三条，按优先级：
1. **准静态/座椅态**做可辨识性（不积分，秒级）；
2. `src/velch/inverse/surrogate.py`（带标定界的 GP 代理模型）压成本，代理必须报标定区间；
3. 时程只在 M1/M7 的最终判定上用一次，其余全部离线线性化。

## 九、需要用户决定或提供的三样

1. **`Ω_obs` 定义（接触带面 vs 全平面）**：是否接受把"整个三维面曲线"改为"接触带面 `z(s,y)|Ω_obs`"（§三）。若坚持全平面，需要用**多条接触线**（不同轮型/直线+曲线/两点接触/超高）——那要多 3–4 个里程碑。
2. **精度主门用绝对误差**（§4.2，推荐 22 µm 起），还是坚持"相对 90%"。两者差别是 1.49 mm 与 22 µm 的差别，直接决定这个任务能不能被"验证"。
3. **C 级真值**：≥3 区段轨面实测剖面（哪怕几十米）。没有它，"验证算法准确性"只能标到 B 级（内插能力）。

另有一条待批：M8 的 L5 口径是否改为"≥3 次过车、≥2 个速度、融合后 6/6 @ 段级虚警 ≤5%"（改验收门需明确授权）。

规范算例因此改用 `sections/LMA_x4.prw`（共线加密，几何不变；`LMA.prw` 不动，51 坐标基线仍用它）。

## 十二、用户 2026-10-31 的三条修订与本文件的执行口径

用户原话要点：① 可以重复跑去完善这个曲面，**重复运行的数据必须留存**，为后续代理模型提供学习数据；② **相对误差可以提高到 98%**；③ **以 PRR 文件为准**——PRR 断面就是最新钢轨断面、完全没有磨耗，可作为"实测断面"；④ 可做**多组不同速度**的过车。

执行口径（每条都写了边界，避免把宽松条件读成结论）：

**12.1 运行档案（放开重复跑的前提）**
每次运行落 `scratch/runs/<run_id>/`：`series.npz`（t / positions / velocities / 各接触法向力）、`meta.json`（速度、x_start、时长、输出步长、method、rtol/atol、七门、墙钟）、`manifest.json`（**case 文件 sha256 + 产物 sha256 + 代码 HEAD**）；全局 `index.jsonl` 一行一次运行。代理模型的训练/验证集**只能从 index 生成**，不许按结果好坏手工挑——否则代理模型学到的是挑选偏差。

**12.2 98 % 相对误差（G-REL 提高，G-ABS 保留）**
`|ŷ − y| / max(|y|, y_ref) ≤ 2 %`，`y_ref = 0.5 mm`。它**不替代** G-ABS：15 mm 处 2 % = 0.3 mm（比 22 µm 绝对门松 13 倍），0.5 mm 处 2 % = 10 µm（比绝对门紧 2 倍）。两者同时报，逐 2 mm 降低值分档必须给，**任何一个都不单独作结论**。

**12.3 PRR 断面作为参考面（证据分级要改一处）**
接受 PRR 断面作为"设计/无磨耗参考面"，但 §4.3 的 A/B/C 分级必须跟着改：正演几何就是用同一批断面建的，所以"反演面 vs PRR 面"验证的是**估计器**（A 级 + B 级），**不是**物理真值（C 级）。为降低同源自证，规定三条留出：**跨速度**（一档标定、另一档检验）、**跨里程**（标定站与检验站不重叠）、**跨表征**（反演给 z 曲线，不是直接读断面）。满足这三条才允许写"算法准确性已验证"。

**12.4 多速度**
预注册四档 **40 / 60 / 80 / 100 km/h**（运行前写死，不得事后挑档）；每档 ≥1 次运行；报逐速度结果与合并结果。速度间增益差异（40→80 km/h 已实测降 32 %）必须逐档标定，禁外推。
