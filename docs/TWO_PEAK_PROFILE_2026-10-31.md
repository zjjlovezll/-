# 两个峰：拟合第一次处理"剖面"而不是"一个鼓包"（2026-10-31，第 273 轮）

> 第 261–272 轮全部是**一个**高斯。波磨与随机不平顺是**多个**峰的叠加，所以 M8 的第一刀是：
> 给拟合**已知峰数（2）**、**不知道位置与幅值**，它还能不能同时把两个峰的值与位置都反演出来？
> 判据在跑之前写死，四个门都用既有的那三个加一个新的可分门。

## 一、预注册

```
z(s) = A1·exp(−0.5((s−s1)/W)²) + A2·exp(−0.5((s−s2)/W)²)     W = 0.35 m（声明先验）
真值：A = 50 µm @ 57.6 m  +  30 µm @ 59.4 m（相距 1.8 m ≈ 5W，合并就是拟合自己的失败）

G-ABS  p95(|z_hat − z|) ≤ 22 µm          （真值 ≥10 % 峰值的窗口）
G-LOC  每个峰 |s_i − 真值| ≤ 0.20 m
G-AMP  每个峰 |A_i − 真值| / max(真值, 500 µm) ≤ 2 %
G-SEP  两个拟合中心相距 ≥ 0.5 m（不许并成一个）
```

为什么宽度取 0.35 m：第 257/258 轮量过，`onset` 跟的是**坡道**而不是鼓包宽度，所以宽度不能靠拟合去求，只能当**声明先验**。本轮声明 0.35 m，比第 261 轮的单峰 1.2 m 窄，这样两个峰才可分。

## 二、做法

1. 规范算例 + blade 体站位叠双高斯（42 个站位非零、峰 49.91 µm / 谷 3.03 µm / 第二峰 30.0 µm）；
2. 0.6 s、80 km/h、**1201 帧、七门 7/7**（`one_set_twopeak-080.00kmh-0.6000s-500us-d7df6f37`）；
3. 零点 `u0(s)` 由**规范无凸起趟**反解（与第 261 轮同一套），四参数最小二乘（`A1, s1, A2, s2`），
   9 个起点（两个中心各 ±0.6/0 m）。

## 三、读数

| 峰 | 真值站位 | 拟合站位 | 站位误差 | 真值幅值 | 拟合幅值 | 相对 |
|---|---|---|---|---|---|---|
| 1 | 57.600 m | **57.611 m** | **0.011 m** | 50.0 µm | **52.2 µm** | **0.45 %** |
| 2 | 59.400 m | **59.404 m** | **0.004 m** | 30.0 µm | **32.0 µm** | **0.39 %** |

```
p95 = 2.63 µm（门 22）   最差 2 mm 分箱 = 0.54 %（门 2 %）   两峰间距 = 1.792 m（门 0.5）
G-ABS PASS / G-LOC PASS / G-AMP PASS / G-SEP PASS
VERDICT: both peaks are recovered and the profile clears the absolute gate
```

可用站位 304 个（份额落在 0.02–0.98 且位于 55.5–61.5 m 拟合窗内）。**这是本项目第一次反演一条含两个峰的剖面**，而且两个峰的幅值都偏 **+4.4 % / +6.7 %**（52.2 对 50、32.0 对 30）——与第 272 轮的单峰偏置（+5.5 % / +10.2 %）**同号同量级**，说明这个偏置是**算子级**的、不是单峰特有的。

## 四、能说 / 不能说

**能说**：在既有的一组模型上、已知峰数（2）与形状宽度（0.35 m）时，同一套正演拟合把 50 µm 与 30 µm
两个相距 1.8 m 的峰各自定位到 **11 mm / 4 mm**、幅值到 **0.45 % / 0.39 %**，剖面 p95 **2.63 µm**，
且没有并峰。

**不能说**：① 峰数是**给定的**，不是从数据里数出来的——真实波磨的峰数未知，那一步还没做；
② 只测 80 km/h、单侧、直向、一组形状与两档幅值；③ 幅值的系统性偏置仍在（+4.4/+6.7 %）；
④ 随机不平顺（宽谱、峰不可数）**没有**被这一轮覆盖，它需要非参数估计器，不是加两个高斯。
