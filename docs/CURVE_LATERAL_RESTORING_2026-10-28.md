# 横向回复刚度：模型不是「没有回复」，而是硬了 927 倍（2026-10-28，第 206 轮）

## 1 上一轮留下的那句话，这一轮去量它

第 205 轮（`docs/CURVE_TILTED_FRAME_2026-10-28.md`）把超高放进参考系之后，`cant = 0.060 m`
在工作点上第一次让八个轮在 0.60 s 内全部落在 [0.625, 1.6] 带内；但拉到 1.0 s 就出现
`axle1_left 1.99x`、载荷转移 `+152 849 N`。那轮的特征值扫描给出的读法是：

> 有摇头阻尼时最大实部是 **0.00 Hz** 的刚性模态，即整车横向在模型里没有静态回复项，
> 外力不平衡只能靠走位到接触非线性变陡的地方「刹住」。

这句话是一个**假设**，可以一行量出来。所以这一轮先把它变成判据，再量：

```
k_force = -d(sum Fy)/dy          接触模型给的横向回复力   [N/m]
k_yaw   = -d(sum M_yaw)/dy       接触模型给的摇头回复力矩 [N.m/m]
k_transfer = -d(N_left - N_right)/dy   横向走位换来的载荷转移 [N/m]
lam_eff = -1/2 d(r_L - r_R)/dy   型面自带的等效锥度
k_grav  = W/n * lam / r          Wickens 重力刚度（真实轮对靠它定位）[N/m]
```

**预注册判据（写在脚本 docstring 里，先于运行）**：

| 判据 | 含义 |
|---|---|
| `RESTORING PRESENT`：`k_force ∈ [0.5, 2.0]·k_grav` | 模型与真实轮对同量级，1.0 s 走位是阻尼/瞬态问题 |
| `RESTORING BLIND`：`0 ≤ k_force < 0.2·k_grav` | 模型没有静态回复，即上一轮的假设成立 |
| `RESTORING INVERTED`：`k_force < 0` | 符号错，优先级最高 |
| 其余（`> 2·k_grav`） | `RESTORING STIFF`：回复在，但机制不对 |

## 2 实测（R = 1100 m、80 km/h、`cant = 0.060 m`、`--curvature-force`，35 坐标）

座位残差 `1.02e-07 N`，八斑 `sum N = 477 444.4 N = 1.000×` 车重（每个偏移点都只解竖向行，

**判据落在 `RESTORING STIFF`：`k_force / k_grav = 927`。**

也就是说：**上一轮「没有回复项」的假设被否掉了**——回复不但有，而且比真实轮对硬三个数量级。
细扫（±0.6 mm、0.1 mm 步）复现同一结论（`k_force +4 926.5 kN/m`、`k_transfer +233 666 kN/m`），
转移随偏移**连续**变化（−0.6 → +0.6 mm 单调、无跳变），所以 240 kN/mm 不是接触分支跳变的假象。

## 3 它解释了两件此前分开记的事

**① 带内横向力上限 37.4 % 就是这个刚度造成的。** 八斑的 `n_y/n_z` 冻结在 0.0210，
横向力只能由**法向力差**给出：

```
ΣFy = 0.0210 · (N_right - N_left)  ≤  0.0210 · W = 10.03 kN
```

第 204 轮实测的带内上限是 **8 169.6 N**，是这条上限的 **81 %**——两个独立测量互相解释，
不是两组巧合。

**② 1.0 s 的 `1.99×` 只需要 0.64 mm 的走位。** 240 kN/mm ⇒ 第 205 轮那 `+152 849 N` 的转移量
对应横向位移 **0.64 mm**。也就是说车并没有「跑掉」，它是走了**不到一毫米**就把一侧卸空了。
这就是为什么 0.34 s、0.60 s 看着在带内、1.0 s 突然越界。

**③ 顺带一个正面结果**：需求（`cant 0.060` 下只剩 2 662 N）在 **−0.15 mm** 处就被满足
（−0.2 mm 给 2 979 N、转移 40.9 kN、份额约 1.09×），所以**带内稳态在这条路上是存在的**，
只是它的容许窗口只有 **±0.9 mm 左右**（−1.0 mm 时转移 259 kN，份额 1.54×/0.91×，已到边）。

## 4 缺陷登记 B047

> **横向定位由 65.47 µm 的 Hertz 压入深度配一个冻结的 1:48 接触角决定 ⇒ 240 kN/mm；
> 真实轮对由锥度 + 蠕滑定位（5.83 kN/m），软 927 倍。**

触发条件：任何带曲率、且要求 `ΣFy ≠ 0` 的工况。影响：带内窗口被压到亚毫米级，
任何 0.5–2 mm 的横向位置误差都直接把载荷推出 [0.625, 1.6]，所以「曲线能不能跑」被这个数主宰，
而不是被离心力或超高主宰。它同时是第 203 轮「`d(n_y/n_z)/dy ≈ 0`（倾角冻结）」的直接后果：
倾角不动 ⇒ 横向力只能借法向力差 ⇒ 刚度必然是 Hertz 量级。

修法方向（不在本轮）：横向力必须主要来自**蠕滑与摇头**（软），而不是法向力再分配（硬）；
这要求接触点能沿踏面移动、`n_y/n_z` 随横向位置演化——与 B045（`lever_y` 跑到轨头之外）
是同一个根。

## 5 能声称 / 不能声称

**能声称**（R = 1100 m、80 km/h、`cant = 0.060 m`、`--curvature-force`、35 坐标）：

- 横向回复在**模型里存在**且符号正确（`k_force > 0`），大小 **+5.40 MN/m**；
- 载荷转移刚度 **240 kN/mm**，横向走位 2 mm 即可搬走整个车重；
- 等效锥度 `λ = 0.0210`（1:48），型面本身不缺锥度；
- 带内上限 8.17 kN 与 `0.021·W = 10.03 kN` 一致（81 %），1.0 s 的越界对应 **0.64 mm** 走位；
- 需求 2 662 N 在 **−0.15 mm** 处满足，带内稳态存在，容许窗口约 **±0.9 mm**。

**不能声称**：

- 不能声称「曲线已稳态」：这只是静态扫掠的最优点，时间历程在 0.9 mm 之外仍会越界；
- 不能声称 `k_force` 是物理量：它是 `0.021·(dN/dy)` 的产物，`dN/dy` 是 Hertz 压入的非线性斜率；
- 不能声称 18 号道岔曲股可用：该算例站表 `cant = 0`，需求仍是 21.8 kN，落在 10.03 kN 上限之上；
- 只做了 `z` 行的重解（`y`/`roll`/`yaw` 固定在扫掠值），所以 `k_yaw` 是「摇头被夹住时」的力矩。
