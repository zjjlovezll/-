# Velch 0.4.18 发布说明

发布日：2026-10-23　｜　和 0.4.17 的差别：**状态栏常驻一行"这版跑过什么"**。

## 这一版改了什么

- 状态栏右侧显示最新证据：`证据：冒烟 ACCEPT · 8 步 ｜ 不变量 未移动`（绿）。
- 三项语气：全部通过=绿；有报告缺失=黄并写明"未找到"；有失败或漂移=红并写明数字。
- 冒烟里若有跳过，会显示 `跳过 N`——跳过不是通过。
- 新模块 `velch/ui/evidence.py`（纯函数，无 Tk 依赖，可单独测）。

## 为什么值得发

问"这版能不能用"时，答案不该依赖用户记得去翻 `reports/`。现在它一直在屏幕上，且**说得出缺什么**。

## 仍然没有的四项

1. Simpack 横向布置的双侧导入（需要两条轨都有断面表的模型）。
2. Simpack 侧轴重/刚度/阻尼只作对照。
3. 没有代码签名。
4. `physics_validation_status` 仍未标定。
