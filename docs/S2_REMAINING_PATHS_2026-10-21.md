### 1.3 "阻尼不是杠杆"这个负结果，从未在生产算例的阻尼量级上被检验过

`DAMPING_CALIBRATION_2026-10-21.md` 自己在 §结论里写"**阻尼不是杠杆**"，并说已把该判断写进
`SPEED_2026-10-20.md` 的后续计划（据此把精力转向接触的空间分布）。这条判断值得复核。
但 `calibrate_damping.py` 的源码显示：默认源是 `case_frog_N_strip05.json`，扫的四个点是
`2e4 / 5e4 / 1e5 / 2e5`——**比该算例自己文件里的 `1e6` 小 5–50 倍，比 BDF 生产算例的 `3e7` 小 150–1500 倍**。

把量级算出来（阻尼律 `c·√δ·approach`，取静平衡 `δ_ref = 65.5 µm`，`√δ = 8.09e-3`；
接触切线 `k = 1.5·C·√δ = 1.5 × 1.1267e11 × 8.09e-3 ≈ 1.37e9 N/m`；`m = 1780 kg` 轮对；
临界阻尼 `2√(km) ≈ 3.12e6 N·s/m`）：

| `normal_damping_n_s_m_1p5` | 有效阻尼 `c·√δ_ref` (N·s/m) | 阻尼比 ζ | 出处 |
|---|---|---|---|
| 2e4 | 162 | **5.2e-5** | 定标扫点（下界） |
| 5e4 | 405 | 1.3e-4 | 定标扫点 |
| 1e5 | 809 | 2.6e-4 | 定标扫点 |
| 2e5 | 1620 | **5.2e-4** | 定标扫点（上界） |
| 1e6 | 8090 | 2.6e-3 | 辙叉窗 / oracle 算例文件值 |
| 3e7 | 243 000 | **0.078** | BDF 生产算例 |

也就是说：那个"阻尼放大 10 倍只降 0.7% rms"的实验，全部落在 **ζ ≤ 5e-4** 的近似无阻尼区间里——
在这个区间里阻尼本来就没有作用，**结论是构造性成立的，不是发现**。153.85 Hz 这个振铃与
`√(k/m)/2π ≈ 139 Hz` 同量级，正是轮对压接触弹簧的共振；ζ=5e-4 时 Q≈1000，整个 3.4 m 窗口内不会衰减，
所以"主频一位不变"是可预期的。

**结论修订**：
- 这不能作为"路线 B 不必做"的依据；
- 反过来它也不能作为"路线 B 安全"的依据。**必须补 B0 实验**（§4）。
- 旧文档里"153.85 Hz 是几何起伏驱动的受迫响应"这句判断，若真是受迫响应，加阻尼确实不该改变主频——
  但在 ζ=5e-4 下自由振动同样不会衰减，**两种解释在该实验里无法区分**。要么补 B0，要么把这句话降级为"未定"。

### 1.4 路线 B 的 `c_floor ≈ 1.1e6` 有单位陷阱

旧交接 §5 写 `c_floor = 2ζ√(m_eff·k_eff) ≈ 1.1e6`。它的单位是 **N·s/m（有效阻尼）**，
但 `ContactParameters.normal_damping_n_s_m_1p5` 是**系数**，有效阻尼 = 系数 × √δ。
把 1.1e6 直接写进这个字段，在 δ_ref 处只得到 1.1e6 × 8.09e-3 = **8 900 N·s/m**，
比生产算例的 243 000 小 27 倍——**是做减法，不是加法**。

正确换算：`系数 = c_eff / √δ_ref`。若目标 `c_eff = 1.1e6`，则该字段应填 **≈ 1.36e8**。
（B2 现已取消；**若将来真出现"确有退化带"的算例而重启 B2，这条必须写进代码注释**，否则后人重犯。）

四条结论，直接改写了 §3.1 的验收门：

1. **`h=1e-6` 太粗，`h=1e-7` 才是可用基准。** 注意 1e-7 与 1e-8 相对 1e-6 基准"漂"了 1e-2，
   但它们彼此一致到 1e-7 —— 说明**漂的是粗的那一端**：接触 `N ∝ δ^1.5` 的二阶项让 `h=1e-6` 已经偏 ~1 %
   （估算 `(3/8)·h/δ`，取 `δ≈65 µm`、`h≈1e-6` 得 0.6 %，量级吻合）。**所以参照物取中心差分 `h=1e-7`。**
2. **FD 参照物自身的精度是相对 `max|J|` 的 1e-7 量级**（`h=1e-7` 时前向-中心差 4e-7；`h=1e-8` 时 1e-8）。
   这意味着"解析 vs FD 差 < 1e-6"这个门**是可达的**，但**必须相对 `max|J|` 归一**。
3. **不能逐元素判相对误差。** 实测 `max|J| ≈ 1.15–1.28e7 s⁻¹`，而 `min|J|>0 ≈ 1e-13`（纯属舍入噪声），
   跨度 1e19–1e20。逐元素相对误差对噪声元素毫无意义。**正确判据**：
   `max|J_a − J_fd| / max|J_fd| < 1e-6`，外加"在 `|J_fd| > 1e-6·max|J_fd|` 的元素上逐元素相对误差 < 1e-4"。
4. **四个状态都没有切换面**：把状态在 z 上推动 1e-9 m，没有一项导数变化超过 1 %（`entries moved >1%: 0`）。
   与 §4.1 的"active 翻转 0 次"互相印证——这条轨迹上"避面取样"是能满足的要求。

**顺带纠正一个量级口径**：最刚的那一项不是 1.37e9。`derivative` 返回的是 `f/m`，接触刚度落在**钢轨**
自由度上（质量 120 kg），所以 `max|J| ≈ 1.37e9/120 ≈ 1.14e7 s⁻¹`，对应 `ω_max ≈ 3.4e3 rad/s ≈ 537 Hz`。
真正卡步长的是这个 537 Hz 的模式，不是轮对的 139 Hz。这也是为什么 `max_step=1e-4`（DOP853 遗留）
对 BDF 未必必要——但**先别动它**，终局门要的是先跑通。

### 3.2 数学结构

状态 `state = (q, v)`，`derivative` 返回 `(v, f(q,v)/m)`（`vehicle_solver.py:365-369`），于是

```
J = [[ 0 ,  I  ],
     [ ∂f/∂q / m , ∂f/∂v / m ]]
```

`∂f/∂q` 与 `∂f/∂v` 由四块拼成：

| 块 | 是否常数 | 说明 |
|---|---|---|
| 悬挂/连接器 | ✅ 常数矩阵 | `Connector.force` 本就是 `k·Δ + c·Δv`，导数是常数，直接组装 |
| 轨道层（`layered` / `local_compliant`） | ✅ 常数矩阵 | 同为线性弹簧-阻尼链 |
| 接触法向 | ❌ 主战场 | `∂N/∂q = ∂N/∂δ · ∂δ/∂q`，再加上法向方向与力臂随 q 变化的项 |
| 接触切向 | ❌ | `∂T/∂q` 走蠕滑线性项 + 饱和函数导数 |

接触力的广义力映射用 `ContactGeometry`（`contact.py:154-170`）里的
`normal_y / normal_z / lever_y_m / lever_z_m` 组装到轮对 5 个自由度与钢轨 z 自由度上。

### 3.3 五个非光滑/不连续源——这是"解析导数数值上仍然不干净"的全部原因

| 编号 | 源 | 位置 | 处理 |
|---|---|---|---|
| a | `series_normal_force` 用固定 5 次 Newton 解 `δ=(N/C)^(2/3)+N·G`，迭代次数随 δ 分段常数 | `support_compliance.py:134-154` | **已完成（A2）**：新增 `series_normal_force_slope()`，`dN/dδ = 1 / ((2/3)(N/C)^(-1/3)/C + G)`；`G` 缺省时走 closed form `1.5·C·√δ`。测试 `tests/test_support_slope.py`（44 项，20 个 δ 点对中心差分相对误差 < 1e-8） |
| b | 阻尼项 `c·√δ·approach` 的 `∂/∂δ ~ 1/√δ` 在 δ→0 发散 | `contact.py:1012` | 必须给 δ 一个解析下限，**与路线 B 同一处收口**；A 会话只加下限不改物理（下限取 1e-12 级仅防溢出） |
| c | `saturate_creep_force` 在 `demand = 3μN` 处 C⁰ 但 C¹ 断裂 | `contact.py:951-968`（`if demand <= 3.0 * limit` 分支） | 饱和支内导数解析可写；跨越点用左/右导数之一（半光滑）。**注意 `limit` 本身依赖 N，所以 ∂T/∂q 里有 `∂N/∂q` 的项不能漏** |
| d | `normal = max(0, elastic + damping)` 与 `active` 布尔 | `contact.py:1019` | 半光滑：取 max 的活跃支；`active=False` 时整块为 0 |
| e | **接触点选择是 argmax**（`point_policy="argmax"`），`δ(q)` 分段光滑、切换点导数跳变 | `contact.py:275` 起 `_evaluate_patch` 一圈 | 这不是 bug，是模型本身的性质。解析雅可比在 piece 内部**是对的**；差分对照必须在同一 piece 内取点，否则会误判成"解析写错" |

另外注意 `stiffness_policy="local_circular"` 与 `normal_policy="strip_integral"` 下 `C` 本身随接触位置查表变化，
`∂N/∂q` 里还有一项 `∂C/∂q`。量级远小于 `∂N/∂δ·∂δ/∂q`，但**数值门要求 1e-6，这一项不能省**——
先用差分估一次量级再决定是解析求还是留作"已知残差"。

### 3.3b A2 落地时的实测附带结论：生产算例没有启用串联支承柔度

`series_normal_force_slope()` 写完顺手把 `G`（支承柔度）扫了一遍，`C = 1.1393e11`：

| G (m/N) | δ=5 µm | δ=30 µm | δ=65.5 µm | δ=200 µm |
|---|---|---|---|---|
| 无（纯 Hertz） | 1.27 kN / k=3.82e8 | 18.72 kN / 9.36e8 | **60.40 kN / 1.383e9** | 322.3 kN / 2.42e9 |
| 5e-9 | 0.48 kN / 1.16e8 | 3.89 kN / 1.47e8 | 9.33 kN / 1.58e8 | 31.5 kN / 1.70e8 |
| 2e-8 | 0.18 kN / 4.00e7 | 1.25 kN / 4.42e7 | 2.85 kN / 4.55e7 | 9.07 kN / 4.68e7 |

冻结 oracle 的静载是 **59 680 N @ 65.47 µm**，只与"无柔度"那一行吻合（60.40 kN），
任何大于 5e-9 的 `G` 都会把力砍到 1/6 以下。**所以生产算例的 `series_normal_force` 走的是纯 Hertz 分支**，
`G` 那一支只在 `layered` 轨下结构上会启用。这解释了两件事：
①A2 实际运行时用的是闭式 `1.5·C·√δ`；②`max|J| ≈ 1.14e7 s⁻¹` 精确等于 `1.383e9 / 120 kg`，
反证最刚路径确实经由 120 kg 的钢轨自由度（§3.0 的量级纠正由此得到独立验证）。

   把路线 B 彻底封死。

### 4.2 B2：实现阻尼下限 —— **已取消（B1 证明无退化带）；以下留作将来口径，现在不要做**

在 `ContactParameters` 新增 `damping_floor_n_s_m: float | None = None`（**有效阻尼，N·s/m**，默认 `None` = 现状，
保证所有既有算例逐位不变）。在 `contact.py:1007-1012` 两个分支之后统一收口：

```
c_eff = max(damping_floor_n_s_m, c_law(δ))     # 单位：N·s/m
```

`c_law(δ)` 由两个分支分别算出：`fixed_coefficient` 分支是 `c_coef·√δ`，`hunt_crossley` 分支是
`coefficient·δ^1.5`（注意后者量纲不同，**不能直接比大小**，要么换算成等效 `c_eff` 再比，要么在
`hunt_crossley` 下直接不支持 floor 并抛错）。§1.4 的换算关系写进 docstring。

注意现有 `damping_force_cap_ratio` 是**力上限**，防冲击；`damping_floor` 是**有效阻尼下限**，防退化。
两者正交，别混。

**B0 已经把这个参数的可行区间钉死了，实现前必须先读懂这三条（否则一定把基线拉坏）：**

1. **幅值上限**：生产生效阻尼是 `c_eff(δ_ref) = 3e7·√65.5µm ≈ 243 kN·s/m`（ζ=0.078）。
   上表 1e8 一档的等效值已给出 rms 20.07，比 Simpack 的 23.30 小 14%——**"比 Simpack 还小"不是更好，是过阻尼失真**。
   所以 `damping_floor_n_s_m` 必须 **≤ 243 kN·s/m**；旧交接 §5 提议的 `≈1.1e6` 是它的 4.5 倍，**禁止照抄**。
2. **作用域必须局部**：floor 的意义是兜住 `c_law(δ)=c_coef√δ` 在 δ→0 的退化，所以取值应恰好只在小 δ 段生效。
   按 `3e7·√δ = floor` 反解：`floor = 2e4` → 只影响 `δ < 0.44 µm`；`floor = 2e5` → `δ < 4.4 µm`；
   `floor = 1e6` → `δ < 1.1 mm`（等于全面改物理，属路线 B 的另一种方案，必须当物理改动另立验收）。
   **推荐从 `2e4` / `2e5` 两档做起**，跑 §4.3 全表，看哪一档能救数值又不挪基线。
3. **不要用 cap 来替代 floor**：§4.0 判读 4/5 已证明 cap 在此窗近乎无感（Δ<0.5%）且在过阻尼端有害（+24 kN 峰值），
   它是台阶冲击的专用阀，不是 δ→0 退化问题的解。
