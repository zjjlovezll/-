# S5f：双带同时激励测出的 2×2 —— 两个估计器互相矛盾，线性反演到此为止

日期：2026-10-24 凌晨（第 34 轮）。脚本 `scripts/s5_dual.py`。与 S5e 同一算例、同一幅值 0.10 mm、同一响应通道（`axle1_box_left_z_acc_m_per_s2`），区别只在**激励方式**：两个带同时驱动、各自独立随机相位，每轮给出两个方程，六轮解出完整复数 2×2（含耦合项）。

## 结果

| 项 | 单带 BLMA（S5e） | 双带 BLMA（本轮） |
|---|---|---|
| 条件数 | 2.85 | **2.65** |
| 标定误差 | 65.2 % | **71.8 %** |
| 闭环（复原谱回灌） | 8.39 % | **14.28 %**（>10 % 判据） |

双带测出的矩阵（每单位幅值，(1/s²)/m）：

```
| 17785.0 |   14.1 |
|   339.5 | 6718.1 |
```

复原 `+0.0764 / +0.0625 mm`，真值 `+0.0830 / +0.1030 mm` → 0.1 m 带 **−8 %**、2.0 m 带 **−39 %**。

## 为什么这条结果比 S5e 更重要

1. 单带 BLMA 只能测对角项，必须**假设**耦合为零。双带测出真实的非对角项确实很小（14.1 与 339.5，相对对角 0.08 % 与 4 %），**耦合假设本身成立**。
2. 但 2.0 m 带的对角增益从单带的 7 840 降到双带的 **6 718（−14 %）**，而反演出的幅值从 −23 % 恶化到 **−39 %**。同一带、同一幅值，**只因为另一个带同时在振，增益就变了 14 %** —— 这是**非线性相互作用**的直接证据，不是测量噪声。
3. 因此闭环从 8.39 % 退化到 14.28 %：**单带标定的 H 能闭环、双带标定的 H 不能**，两者不可能同时描述同一个物理系统。
4. 结论（可交付的判决）：**在这条传递链上，用线性常数矩阵 H 描述"轨面幅值 → 轴箱加速度"不成立**，误差量级 40 %–70 %，且随激励组合变化。继续在 H 上加 λ、加带、加平均都不会收敛到 30 % 以内。

## 对目标主张的最终影响

- S5 的四条判据：带限误差 **未过**（65 %–72 %）、分辨表 **有**、闭环 **单带版过/双带版不过**、盲测 **单带版过（87.1 % ≤ 1.5×97.7 %）**。
- 按任务书"不达标则显式降级"：**不能声称"用轴箱加速度可以在 30 % 精度内反演 0.1 m 与 2 m 的轨面幅值"**；能声称的是"两带可分辨、单带标定下闭环自洽（8.39 %）、盲测在标定误差 1.5 倍内"，以及"线性 Tikhonov 在此传递链上被判为不适用，原因是幅值—响应非线性"。
- 下一步若继续，唯一正路是**非线性辨识**（分幅值段建 H(A)，或直接训练"响应→幅值"的可微代理），而不是继续调 λ。
