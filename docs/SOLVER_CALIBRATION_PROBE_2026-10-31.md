# 把轴停在一站上：静态分配就是滚动分配吗？（2026-10-31，第 284 轮）

> 上一轮把闭式的路关掉了，剩下的只有"问求解器自己"。但在付 300 站的代价之前，必须先答一个
> 更便宜、也更致命的问题：**把轴停在该站、座椅一次，它给出的份额，和滚动经过该站时的份额是同一个数吗？**
> 如果不是，逐站座椅测的是另一个东西，整条路就是白跑。

## 一、预注册

```
探针    站位 52.0 / 54.0 / 56.0 / 57.0 / 58.0 / 58.5 / 59.0 / 60.0 / 61.0 / 62.0 m
        在 58.0 / 58.5 / 59.0 三站再叠 0 / 50 / 100 µm 抬升（测该站的灵敏度）
做法    每站把 run.x_start_m 与 seat_x_start_m 都设成 s − 前轴偏移（前轴停在该站），
        blade 站位最近的一站按抬升改 z_offset_m，然后座椅、读 body_contacts["axle1_right"]

R1  座椅必须收敛（残差 ≤1e-5 N 且至少一个接触活跃）
R2  |share_座椅 − share_滚动| ≤ 0.02（每站）
R3  逐站 d(share)/d(抬升) 非零且同号
```

`R1` 的口径本身在第一次运行里被我自己写错过：我原来要求"两个接触都活跃"，于是**抬升大到基本轨卸载**
（此时份额确实是 1.000，是物理分支，不是座椅失败）被判成失败。改成"求解收敛 + 至少一个活跃"，
并把单接触分支单独计数。

## 三、这一轮到底答了什么

**答了**：把轴停在一站上座椅一次，得到的份额就是滚动经过那一站的份额——中位数差 **0.0022**，
九站在 0.02 内，唯一超门的是 61.0 m 的 **0.0218**（超门 0.0018）。所以**逐站座椅是一个可用的正演**，
代价 4.5 s/站（300 站 ≈ 22 min）。

**没答**：这个"可用"是**零点对得上**，不是"抬升的响应也对得上"。R3 只证明该站份额随抬升单调增长
（0.0038 / 0.0041 / 0.0047 per µm），**没有证明它的斜率就是滚动时的斜率**。要证明那一步，
必须在同一站同时有"滚动 + 抬升"的读数——那就得对每个抬升跑一趟时程（0.6 s ≈ 250 s/趟），
代价从 22 min 变成数小时。

## 四、能说 / 不能说

**能说**：① 在 80 km/h、直向、规范算例上，逐站座椅的份额与滚动份额在 9/10 站相差 ≤0.02
（中位 0.0022，最差 0.0218@61 m）；② 尖轨在 52–58 m 完全不承力（六个单接触分支），这解释了为什么
"初始可观测带"从 58 m 才开始；③ 三站的灵敏度是 **+0.0038…+0.0047 share/µm**，同号。

**不能说**：① 不能说"逐站座椅能修好随机剖面的反演"——那是斜率的问题，本轮没测；
② 不能把 0.0218 当成"通过了 0.02 门"；③ 不给任何幅值。
