# Velch 0.4.20 发布说明

发布日：2026-10-23　｜　和 0.4.19 的差别：**页眉多了「发布证据」，两个整程序动作搬了家**。

## 这一版改了什么

- 页眉新增「发布证据」：只读窗口显示 `docs/EVIDENCE_MAP.md` 原文 + 文件时间 + 大小；
  找不到时列出查过的三个候选路径与重新生成命令。
- 「环境体检」同样搬到页眉（原来在 ① 屏右卡里）。
- ① 屏右卡导航回到三键——第 5 个按钮在那里会被父容器裁掉。

## 为什么值得发

"这版凭什么能发"以前要离开软件去读 markdown。现在它在页眉一眼可达，并且**显示的是文件原文**，
不经过任何再加工。

## 仍然没有的四项

1. Simpack 横向布置的双侧导入（需要两条轨都有断面表的模型）。
2. Simpack 侧轴重/刚度/阻尼只作对照。
3. 没有代码签名。
4. `physics_validation_status` 仍未标定。
