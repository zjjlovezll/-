# 直向过岔 + 随机速度：波磨反演的六段判定（第 6 门的直向半边）

日期 2026-10-28 · 脚本 `scripts/s35_straight_random_speed.py` · 数据 `../scratch/s35/inversion.json`

本文只做一件事：在**直向**、**随机抽出的速度**下，把"已知波磨 → 轴箱加速度 → 反演深度"这条链
跑完并按预注册判据判定。曲线那边已在 `docs/CURVE_YAW_BALANCE_2026-10-28.md` 按实测参数边界
显式降级，本文不重复。

## 1 为什么是直向、为什么速度只能从这个带里抽

- 直向路线实跑 **七门 7/7**，不碰任何冻结物理；
- 曲线路线被实测的接触律边界挡住（21 842 N 只能以"单边卸载 + 0.14 mm 压入轨头"换到），
  所以在它被授权标定之前，曲线上的深度数字没法引用。
- **速度带 70–90 km/h**：短波算子是按速度分键标定的（`docs/INVERSION_PIPELINE_2026-10-27.md`），
  70.8 km/h 是算子的参考速度、实测记录在 40–75 km/h。把它们之间以外的速度当作"随机速度"
  写进来，就是拿外推冒充现实。所以随机只能在这个带内抽。本轮种子 20261028 抽出 **70.32 km/h**
  （19.534 m/s），抽法与数值都打印在报告里，可复算。

## 2 协议（与 `s31b` 的曲线版逐字相同，未因结果改过）

- 四个对数分层波长落在 0.10–0.30 m：**0.1004 / 0.1379 / 0.2073 / 0.2293 m**
  （70.32 km/h 下 194.48 / 141.69 / 94.22 / 85.18 Hz），相位均匀、权重 0.5–0.9，
  混合后按**峰峰值**归一；
- 幅值水平 **0 / 0.1 / 0.2 / 0.3 mm 峰峰**；
- 补片 42.5–45.5 m、步长 2.5 mm、两端 50 mm 升余弦淡入淡出，**只加在左轨**；
- 观测 `axle1_z_acc_m_per_s2`；投影窗 = 前轴越过补片的那一段（0.1280–0.2816 s，308 帧）；
- 增益在**最小激励幅值**（0.1 mm）上标定，再去预测**未参与标定**的 0.2 与 0.3 mm；
- 判据：`|误差| ≤ 2 dB` 记该带命中（第 1 门规定的"带限幅值 ±2 dB 带命中率"）。

## 3 四个水平都算通了，七门全过

| 水平 (mm 峰峰) | 状态 | 门 | 最大侵入 |
|---|---|---|---|
| 0.0 | `numerically_checked` | 7/7 | 65.47 µm |
| 0.1 | `numerically_checked` | 7/7 | 138.26 µm |
| 0.2 | `numerically_checked` | 7/7 | 168.80 µm |
| 0.3 | `numerically_checked` | 7/7 | 236.33 µm |

**车窗内该轮离轨的帧比例：0.0 %（四个水平全部）** —— 这一条很重要，它把"轮子飞起来造成的
非线性"这个最顺手的解释**当场排除**了（用的是每帧 `contacts["axle1_left"].active` 与
`geometry is None` 的实测计数，不是推断）。

## 4 响应与幅值不成比例，而且**方向逐带不同**

| 波长 (m) | 施加 (µm) 0.1 / 0.2 / 0.3 | 响应 (m/s²) 0.1 / 0.2 / 0.3 | 增益(0.1) | 增益(0.3) |
|---|---|---|---|---|
| 0.1004 | 11.55 / 23.09 / 34.64 | 41.68 / 25.19 / 15.72 | **3.610** | **0.454** |
| 0.1379 | 11.67 / 23.35 / 35.02 | 13.27 / 32.79 / 33.57 | 1.136 | 0.959 |
| 0.2073 | 14.59 / 29.18 / 43.76 | 4.41 / 10.60 / 20.02 | **0.302** | **0.457** |
| 0.2293 | 16.64 / 33.28 / 49.93 | 3.84 / 8.04 / 18.09 | **0.231** | **0.362** |

三条读数：

1. **0.1004 m 的响应随幅值下降**（41.68 → 15.72，−62 %，增益掉 8 倍）——不是"略有非线性"，
   是**反方向**；
2. **0.2073 / 0.2293 m 的响应涨得比幅值快**（幅值 3 倍、响应 4.6 / 4.7 倍）；
3. 所以同一个"随幅值漂移"在不同带上**符号相反**，任何单调的 `H(A)` 分段都建不起来。

## 5 判定

| 判据 | 实测 | 结论 |
|---|---|---|
| 0.1 mm 标定 → 0.2 mm 预测 | **3/4 带 ≤ 2 dB** | — |
| 0.1 mm 标定 → 0.3 mm 预测 | **1/4 带 ≤ 2 dB** | — |
| 合计**带命中率** | **4/8 = 50 %** | **不达 ±2 dB 全部命中** |
| 内插检验（用 0.1 与 0.3 的增益对数内插，预测**未参与标定**的 0.2 mm） | **1/4 带 ≤ 2 dB** | 分段 `H(A)` 这条路也被否掉 |

因此**第 6 门的直向半边显式降级**：协议、门、观测都成立，但带限幅值的 ±2 dB 命中率是
**50 %（合 8 次预测 4 次）**，且内插检验只有 1/4。按第 1 门的口径，能说的话只有：

> 直向过岔、70.32 km/h 随机抽速下，0.10–0.23 m 的波磨**可以被检出并给出量级**，
> 但**不能报 ±2 dB 的带限幅值**；限制来自传递关系随幅值变化（0.38×–4.6×），
> 不是轮轨脱离（实测 0.0 %），也不是容差。

## 6 这一轮排除掉的解释（都可复算）

| 解释 | 检验 | 结果 |
|---|---|---|
| 轮子飞离轨面 | 窗内 `active=False` 或 `geometry is None` 的帧比例 | **0.0 %**（四个水平） |
| 只是"增益偏一个常数" | 逐带比较 0.1 与 0.3 的增益 | 0.1004 m 掉 8 倍、0.2293 m 涨 1.6 倍 —— 方向相反 |
| 线性 + 单点标定就够 | 4/8 带命中 | 不够 |
| 分段 `H(A)` 单调内插 | 0.2 mm 留出检验 | **1/4**，不够 |

## 7 下一步（未做，须先量）

候选机理是**接触点随幅值迁移**（波峰把接触斑推到踏面的另一段，杠杆臂与滚动半径随之变化），
它的判据是：逐分量单独激励、扫 5 个幅值，看 `lever_y` 与 `lever_z` 是否随幅值单调移动，
且移动量与 `0.1004 m` 那条 8 倍增益掉的起点对齐。逐分量（而不是像本轮四分量同时）是必要的，
因为本轮只证明了"混合激励下不可分"，没证明"单分量下也不可分"。
