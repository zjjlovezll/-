# 任务书：短波轨面反演（2026-10-23 拟定，待批准后执行）

> 一句话：**用轴箱加速度反演 0.05–3 m 波长范围内的轨面不平顺**，并在随机不平顺谱的正演数据上
> 给出"带限精度"的量化结论；长波不做承诺。

## 0. 为什么先限定"短波"

| 波段 | 轴箱加速度里的响应 | 能不能反演 |
|---|---|---|
| 0.05–1 m | 接触刚度直接驱动，信噪比最高 | **本文任务的目标** |
| 1–3 m | 经一系/构架滤波，仍可用但要正则化 | 作为上边界，报误差 |
| > 3 m | 近似准静态，加速度几乎不携带信息 | **不承诺**（需位移/IMU 辅助，另立任务） |

判据不是"逐点毫米级吻合"，而是**带限误差**：把真值与反演值都带通到同一波段再比。

## 2. 接入不平顺：Simpack 侧已查明的事实

**2.1 交换格式（由 `H:\不平顺\bps_sc.m` 决定，可复现）**

```
header.begin
  data.type   = 1            ! track related: lateral, vertical, roll, gauge
  data.par(1..5) = 1.0       ! s / Delta-y / Delta-z / Delta-phi / Delta-g 的单位系数
  data.par(6) = 1            ! 逐行读取
header.end
! s[m] Delta-y[m] Delta-z[m] Delta-phi[rad] Delta-g[m]
 0.0000000  4.2786753618e-04  -9.0855894446e-04  -1.1467208799e-04  2.3330816687e-05
…
```

实测 `H:\不平顺\tre.tre`：**4096 行、s = 0…1023.75 m、dx = 0.25 m**（Nyquist 波长 0.5 m，但谱只到 7.62 m）。

**2.2 Simpack 模型里它挂在哪**

* 三个子模型（`CRH380A_{M,T}_{Bogie,Carbody,Wheelset}.spck`）里没有 `.tre` 字符串，但
  `CRH380A_M_Wheelset.spck:22` 有 `glob.compat.track.excit = 1  ! Track Excitation rotation sequence`；
* 结果文件 `350.mat` 里有 **`ch_007 y_irreg`、`ch_008 z_irreg`** 两个通道（我们自己探针读到的）——
  说明**模型确实被一条轨道不平顺信号驱动**，并把激励本身记录成了通道。
* 结论：**轨道不平顺力元（读 `.tre`）在总装模型里**，而我们手上只有 6 个子模型（`G:\研究生\动力学`
  下共 12 个 `.spck`，全是子模型，没有总装的 `CRH380A_M.spck`）。
* 需要你补一样东西（任一即可）：①总装模型目录；②Simpack 里那个力元对话框的截图。
  有了它我才能把"Simpack 怎么参数化这条激励"写成对照表；没有也能做——因为我们按 `.tre` 语义实现。

**2.3 现有生成器的两个问题（这次必须解决）**

1. **没有短波**：`bc1 = 7.62 m` 是最短截止波长。短波反演要 `bc1 ≈ 0.15–0.3 m`，`dx ≤ 0.05–0.1 m`，
   `Nr` 相应加大（否则 `nf < Nr/2` 的断言会挡住）。
2. **幅值被乘了 0.1**：`bps_sc.m:20` 的 `output = [out(:,1), 0.1*out(:,4), …]`。按德国低干扰谱
   `Av = 4.032e-7` 在 7.62–304 m 带内算出的高低 rms ≈ **4.4 mm**，而 `tre.tre` 实测 rms = **0.375 mm**
   —— 正好差一个量级，**就是这个 0.1**。要么删掉它，要么在文档里写明"这条是按 10% 幅值算的"。

## 3. 分阶段任务与验收

每阶段都有"可复跑命令 + 判据"，不通过不进入下一阶段。

### S1 加速度通道（0.5 天）

* 在 `history.csv` 增加：`axleN_{y,z}_acc`、`bogieN_{y,z}_acc`、`carbody_{y,z}_acc`（后续加轴箱）。
  实现直接从 RHS 的力除以质量，**不用差分**。
* 验收：`tests/test_acceleration_channels.py`——加速度与 `d(v)/dt` 的中心差分相对误差 < 1e-6；
  旧算例 `history.csv` 逐位不变（新增列不算变化，用列子集比较）。

### S2 轴箱体车型（1 天）

* 用节点表建 `CRH380A_M_axlebox`：8 个轴箱体（48.2 kg）+ 转臂节点衬套（13.7e6 / 5.49e6 N/m）
  + 一系弹簧/减振器，参数全部来自已挖的 `CRH380A_M_Bogie.spck`。
* 验收：①`velch vehicle validate` 通过；②轴箱加速度谱在 30–500 Hz 出现可解释峰；
  ③旧车型结果逐位不变。

### S3 短波不平顺输入（1 天）

* 新模块 `velch/irregularity.py`：
  * `from_tre(path)` / `to_tre(path, samples)`（与 `H:\不平顺` 同一格式，双向）；
  * `spectrum(kind, band, rms)`：德国低/高干扰、美国五/六级（复刻现有公式）+ **TB/T 3352-2014**（新增）；
  * `synthesise(psd, dx, length, seed)`：逆 FFT、单边谱归一化、固定种子；
  * 算例侧新增块：`"irregularity": {"tre": "...", "band": [0.2, 30], "seed": 1}`。
* 施加方式：Δy/Δz/Δφ/Δg 按里程叠加到轨面采样上（与求解器读型面同一条曲线）。
* 验收：①`tre.tre` 读入再写出**逐字节等价**；②合成样本的 FFT 反算 PSD 与解析谱在 ±1.5 dB 内（多实现均值）；
  ③`band = [0.2, 3]` 的短波样本能被求解器吃进（零不平顺时与基线逐位相同）。

### S4 灵敏度矩阵与"可反演波段表"（1 天，决定性）

* 用解析雅可比逐列求 `∂(轴箱加速度)/∂r_i`（r 网格 0.05 m），拼矩阵 H；
* 算 `HᵀH` 的奇异值谱 → 输出**每个 1/3 倍频程空间波长的可反演性**（条件数、噪声放大倍数）。
* 验收：输出 `docs/SHORTWAVE_OBSERVABILITY.md` 一张表 + 一句结论（哪些波长能做、精度上限）。

### S5 反演与验证（2 天）

* 基线：`min ‖H r − a_meas‖² + λ‖Dr‖²`（Tikhonov，λ 由 L 曲线或 GCV 定），输出 `r̂(x)` + 不确定度带；
* 学习对照：ResNet-1D/GP 在 log 带功率上回归（只作对照，不作主结论）；
* 验证协议（必须全做）：
  1. **带限误差**：`r̂` 与真值都带通到 0.05–3 m，比 rms 误差、相关系数、峰值误差；
  2. **波长分辨表**：按 1/3 倍频程报误差；
  3. **闭环一致性**：把 `r̂` 再正演，加速度谱回到原处（偏差 < 2 dB）；
  4. **盲测**：谱型/速度/幅值三组留出，分别报。
* 验收：`scripts/shortwave_inversion_check.py` 打印一张表 + `VERDICT: ACCEPT|REJECT`，写 `reports/`。

## 4. 明确不做（写进文档，避免被误读）

* 不承诺 > 3 m 的高低保真度（加速度信息不足）；
* 不在没有实测标定的情况下宣称"能反演真实线路"；
* 不把"学习模型在训练分布内很准"当作能力——必须过盲测与闭环。

## 5. 依赖与风险

| 风险 | 应对 |
|---|---|
| 轴箱体参数（转臂位置/刚度）不齐 | 已有 Simpack 挖出的全套数字；缺的标"未验证" |
