# 残差是静态的：准静态这一族没选错（2026-10-31，第 282 轮）

> 第 281 轮否掉“无拟合点接触”后，还有一个在此之前从未检验的候选：**测量本身就是动态的**。
> 0.35 m 的特征在 80 km/h 下只走 **16 ms**，比轮对的竖向周期还短；如果份额带动态成分，
> 任何“间隙 → 份额”的准静态律都不可能复现它。这一轮用已归档数据直接量。

## 一、做法（零新仿真）

```
预测份额 = 律(u0(s) + 真值(s))，逐帧按该帧里程取        （第 277 轮的正演）
残差 r   = 预测 − 实测，逐帧
谱       = r 在可观测窗内的能量谱，分 <20 Hz 与 >20 Hz
滞后     = 预测与实测的互相关峰值对应里程（mm）
```

预注册读法：**>30 % 的残差能量在 20 Hz 以上、或滞后超过 5 mm ⇒ 动态**；否则 ⇒ 静态建模误差，
准静态这一族是对的，下一个候选仍是逐站接触模型。

## 二、读数

```
run                         usable     rms   >20Hz  peak Hz  lag mm
one_set_twopeak                469  0.0155   0.824      4.3    0.00
one_set_threepeak_obs          469  0.0441   0.381      4.3    0.00
one_set_random                 381  0.1317   0.110      5.2    0.00
hold-out dynamic: NO
VERDICT: the residual is static: its energy sits below 20 Hz and the peak lag is within a few mm, so the
         quasi-static family is right and the next candidate stays a per-station contact model
```

三条读数：

1. **留出集（六分量）的残差 89 % 在 20 Hz 以下**、主峰 **5.2 Hz**、滞后 **0.00 mm** ⇒ **动态被排除**；
2. 而两峰那趟 **82.4 % 在 20 Hz 以上**（主峰 4.3 Hz 但能量分散）——**说明“静态”是对留出集说的，不是对所有运行**；
   两峰的 rms 只有 **0.0155**，那点高频是“已复现的剖面在细节上的抖动”，与六分量的 **0.1317** 不是一回事；
3. 滞后全为 **0.00 mm**：预测与实测在对齐里程上相关最好 ⇒ 没有“轮子过冲/滞后”的迹象。

## 三、这意味着什么

- **准静态族（间隙 → 份额）没有被证伪**：留出集的残差是**低频、无滞后**的成形误差；
- 因此第 281 轮的失败**不是**“静态律不可能”，而是那个具体的**点接触尺寸律**不对；
- 下一个候选保持原判：**逐站等效刚度**（用真实断面、线/共形接触），而不是“把动力学加进来”。

## 四、能说 / 不能说

**能说**：在六分量留出集上，准静态律的残差 **89 % 能量在 20 Hz 以下、主峰 5.2 Hz、互相关滞后 0.00 mm**，
所以该残差**不是**轮对竖向动力学造成的；两峰那趟高频占比虽高（0.824），但 rms 仅 0.0155，
不能与六分量的 0.1317 混为一谈。

**不能说**：① 不能说“所有工况都静态”（只测四条运行、单速度、单侧、直向）；
② 不能说“残差一定是接触尺寸律”——只排除了动力学这一条；
③ 不给任何幅值数字。
