# Velch 0.4.33 发布说明

日期：2026-10-25。这一版是**柔性轮对**从"有模态文件"走到"能算、能量、能反演"的一版：
31 阶 CAD 有限元模态真正接进了求解器，辙叉窗拉到 0.45 s 之后弹性带第一次能被数出来，
长波反演在柔性模型上重跑了一遍。

## 本轮结论

**1. 柔性轮对已经嵌入求解器。** 4 根轴各 33 阶模态 = 132 个模态坐标，状态向量
`[刚体 q | 轨道 q | 模态 q]`（整车 218 坐标）。模态块的质量是单位阵（模态质量归一化的结果，
不是 132 kg 的物理质量），`K = diag(ω²) + Ω²·G·G`、`C = diag(2ζω) + 2Ω·G`，接触力经 Φᵀ 进入模态坐标。

**2. 接触搜在变形的踏面上。** 把模态位移加到**车轮型面本身**（`ProfileSeries.z_m`）再交给接触搜索，
位置、法向、侵入三者由同一条曲线给出，不再事后修正；法向随踏面斜率转 `−atan(slope)`。
零模态坐标时返回原对象，`history.csv` 逐位不变。

**3. 刚柔对比必须先坐稳。** 第一次对比得到 23 %（直线）/ 87 %（辙叉），追下去是**起振瞬态**：
模态坐标从零起步 = 踏面未受力。加了模态静平衡（不动点迭代 12 轮，收缩比 ≈0.5）并与之字交替 2 轮后，
直线窗降到 **1.21 %**，辙叉窗 78.66 % —— 后者是**真物理**：辙叉冲击把模态打到 2.5 mm，
是 200 kN 静柔度（70 µm）的 36 倍。

**4. 弹性带存在，但很小。** 0.05 s 辙叉窗回答不了这个问题（101 样本 / 19.8 Hz 分辨率，
且刚性 5 坐标轮对在该带读出 10.6 m/s² 的冲击泄漏）。拉到 0.45 s 后：300–400 Hz 柔性比刚性
**高 3.89 倍**（0.09076 vs 0.02332），但比该窗总 rms 小 **19.3 倍（−25.7 dB）**。
柔性轮对贡献的是高频细节，不是量级。

**5. 长波反演在柔性模型上仍然成立。** 20/40 m 带，0.10 mm 探测：单通道轴箱加速度
标定 **3.8 %**、闭环 **1.20 %**，逐带 +1.2 % / −4.8 %。任务书 §4 的"≤3 % 标定"门**没有过**（差 0.8 点，
刚性车是 0.7 %），"≤10 % 闭环"门过。柔性把 20→40 m 的交叉项削掉 34 %，对角项只动 1 %。

## 验证

- 全仓 `pytest` **792 passed, 1 skipped**（skip 是"未设 `VELCH_SIMPACK_MODEL` 时不跑真模型"）。
- 冻结物理未动：静载门 59 680.5769 N / 65.47 µm、八接触峰值 89.68 / 170.61 kN、七项门、DOP853 路径。
- 提交前闸门 `scripts/auto_accept.py --skip-run` → `verdict: ACCEPT`。
- 安装包 `smoke_test.py --readonly-acl` 8 步全过。

## 仍然没有的

1. **没有复现论文的 345 / 378 Hz 特征**：CAD 轮盘的对应族在 347.10 Hz，幅值比论文小 5.6 倍
   （§17.1）；频率整体低 5–39 %，说明两套轮对不是同一个结构。
2. **只有单滚动圆**：模态只作用在踏面那一圈节点上，没有把轮缘/轮背的变形带进接触搜索，
   也没有从变形节点重建侧滚/摇头角。
3. **0.05 s 辙叉窗不能引用**：它在起振瞬态之内。
4. **标定门差 0.8 个点**：要分辨是协议差还是模型差，需把 V 档重跑成 8 相位（约 88 分钟）。
5. **物理仍未标定**：`physics_validation_status` 仍是 unvalidated，与实测没有对照。
6. O010 仍开放：节点表车型在柔性轨道上的静平衡解不出来（每条轨行恒差一个接触斑 ≈ 59 662 N）。
