# 运行模态识别（SSI-FCM）接到实测：算法通过，实测上不收敛

日期：2026-10-27 · 目标 `goal-4b49c9f5-b591-4025-8f66-81b646b08697`（第 65 轮）

## 1. 为什么要做这件事

实测数据链**没有激励记录、没有轨面真值**，所以模型没法直接拟合。但实测里带着**系统自己的模态签名**：不管激励是什么，轴箱响应的频率与阻尼是悬挂的属性。论文（Lv, Hua, Yu, Dong, Gong, *Automatic identification of operational modal parameters for train suspension systems based on an improved SSI-FCM*）给的正是这条路线，并且在一个 7 自由度仿真、一个 DMU 台架、一个五层框架上达到频率 ≥95.22 %、阻尼 ≥91.76 %。

如果模型的轴箱共振不在实测频点上，那么**模型的垂向刚度就是错的**——这是一次不依赖真值的可反驳检查，也是"模型如何标定"的第一锤。

## 2. 算法（`src/velch/inverse/oma.py`）

| 环节 | 实现 | 论文依据 |
|---|---|---|
| 非平稳处理 | `average_correlation(y, segments)`：分段去均值、逐段归一化后平均 | §2.1.1 的平均相关信号 |
| 协方差 | `covariance(y, max_lag)` → `R_τ` | 式 (2) |
| Toeplitz | `toeplitz_block(lags, block_rows, start)`，负滞后取转置 `R_{-k}=R_kᵀ` | `T_{1|i}` / `T_{2|i+1}` |
| 阶次 | `singular_entropy_increment(singular, tolerance)` | 奇异熵增量（论文用 SEI，不用"数非零奇异值"） |
| 极点 | `A = Σ^{-1/2}Uᵀ·T_{2|i+1}·VΣ^{-1/2}` 的特征值 | 标准 Cov-SSI |
| 稳定判据 | 与前一个阶次的极点比 `f`（2 %）与 `ζ`（10 %） | 硬验证 |
| 伪模态剔除 | 对 (f, ζ, MAC) 做模糊 C 均值；再要求**簇内自洽**（f 散度 ≤2 %、ζ 散度 ≤25 %）且 `|ζ| ≤ 0.5` | FCM 聚类 + 工程边界 |

**两处判据是物理的，不是调出来的**：簇内不自洽的极点（合成算例里出现过 63 Hz、散度 5.17 Hz = 8 %）是数值极点碰巧重复；`|ζ| > 0.5` 在本应用的悬挂里不存在（空簧相关模态 1–20 %）。

## 3. 合成算例：通过

`tests/test_oma.py`（6 项，全绿）用解析可算的 2 自由度链（`m=2 kg`、`k=1e5 N/m`，模态 **22.0 / 57.6 Hz**，ζ=0.02），1000 Hz、40 s、−10 dB 量级噪声：

- 两个模态频率都恢复到 **3 % 以内**，阻尼落在 0–6 %（论文报 91.76 %，取 40 % 的相对界更诚实）；
- 单音 37 Hz 能识别且阻尼≈0；
- SEI 给出的阶次落在 2–20 之间（真值 4）；
- 归一化、四种拒绝消息、证据字段（poles / spread）都有断言。

## 4. 实测：不收敛（这是本轮的结论）

记录 `Run_75kmh_E1toE2.mat`（579 740 点 @ 4 kHz = 145 s，两列轴箱垂向），5–200 Hz 带通，`block_rows=12`：

| 区段 | 样本 | 平均速度 | 稳定极点 | 识别出的模态 |
|---|---|---|---|---|
| S2 4718–4805 m | 16 164 | 77.5 km/h | 24 / 137 | 134.4 / 135.0 / 150.7 / 189.0 Hz（ζ 0.31/0.31/0.26/0.18，各 2 极点） |
| S3 4855–4927 m | 13 686 | 75.8 km/h | — | 69.7 / 100.2 Hz |
| S5 5438–5577 m | 26 121 | 76.7 km/h | — | 65.9 / 165.0 Hz |
| **整程** 3798–6303 m | 579 740 | 62.2 km/h | **12 / 154** | **67.4 / 166.8 Hz**（MAC 代理 0.06 / 0.07） |

**没有一处在区段之间重复**（S2 的 134 Hz 在 S3/S5 都不出现；S3 的 69.7 与整程的 67.4 相差 3 %），**SEI 阶次只有 5**（Toeplitz 是 24×24，真实自由度远不止 5），整程的 MAC 代理掉到 0.06——说明聚类出来的"模态"在两根通道上的参与比例对不上。

对照模型：只有 S2 的 **134.43 Hz** 与模型轮盘对 133.34 Hz 吻合（+0.8 %），其余全部 DISAGREES。**但这一条不能当证据**——同一批数据在三个区段给出三套互不相容的答案，其中任何一个吻合都可能是巧合。

判读：**两通道轴箱记录、5–200 Hz、4 s 级区段，在当前配置下不足以支撑稳定模态识别。** 与我们自己早前测到的事实一致——轴箱通道在 `f_n` 以上是 `(2πf_n)²·A` 的宽带响应，冲击主导、模态振铃很弱，这正好压低相关矩阵的有效秩（SEI 只给 5）。

## 6. 下一步（按代价排）

1. **FDD/EFDD**（频域分解，对谱矩阵做 SVD）：对冲击主导、非平稳记录比 Cov-SSI 稳，且只需 2 通道也能给出一致的峰值集；判据同前——**跨区段重复**才算识别到。
2. **把 `Vi_Lat`（司机室横向）作为第三通道**：形状估计从 2 维升到 3 维，MAC 才有意义（现在两通道的"MAC"只是幅值比）。
3. **只在不含缺陷的区段做识别**（S1–S6 之外的平顺段），避免波磨冲击把相关矩阵压成低秩。
4. 若三条都不成，**如实登记"该数据集不支持 OMA 标定"**，标定只能走"按速度比消掉轨面谱"那条（L2/L3 已完成）。

## 8. 补做 FDD（频域分解）：峰值能重复，但还不属于车辆

Cov-SSI 不收敛之后按上一节的第 1 条做 FDD（`src/velch/inverse/spectral.py`，Brincker 等的
frequency domain decomposition）：在共振处谱矩阵秩一，于是第一奇异值出峰、对应奇异向量就是振型。
它**不拟合模型**，所以不会凭噪声造出一个模态——正好配合本节要用的判据。

实现与判据：

- `spectral_matrix(y, sample_rate_hz, segment_seconds, band)` 用 Welch 互谱拼出 `S(f)`，逐频点做
  `eigh`，输出**未归一化**的第一奇异值谱（归一化会把峰值对比抹平：实测两通道记录在每个频点第一
  奇异值都接近 0.9，任何阈值的显著性都过不去）；
- `find_peaks(prominence_db, separation_hz)` 以**下四分位**为底、并忽略低于 `max·1e-9` 的数值零线
  （否则纯音算例里 1e-13 的零线会用“零除零”赢下显著性）；
- 判据不是“有没有峰”，而是**跨区段重复**：车辆模态是车辆的属性，换一段轨道必须还在。

实测（2 s 分段、5–200 Hz、显著性 6 dB、重复容差 3 %）：

| 重复次数 | 频率（Hz） |
|---|---|
| 6/6 | 57.5、59.0、89.0、91.5 |
| 5/6 | 58.0、59.5、88.5、90.5 |
| 4/6 | 40.0、40.5、50.5、57.0、89.5、91.0 |
| 3/6 | 72.5、73.5、74.5、76.0、84.0、86.5、87.5 |
| ≤2/6 | 其余（19、20、23、29–32.5、34.5、38.5、44–50、55、61–63.5、68、79、81–83、99.5、108.5、149） |

三条判读：

1. **FDD 确实给出可重复的谱脊**（57–60 Hz、88–92 Hz 两组各在 4–6 个区段出现），说明这套方法在这个
   记录上比 Cov-SSI 稳——这是本节唯一的正面结论。
2. **但它们与模型的轴箱模态一个都不重合**：模型是 12.0/12.2/12.6 Hz（受约束轴箱）、24.9 Hz（轴箱在
   一系上）、133.3 Hz（轮盘对）；实测重复脊在 40–92 Hz。
3. **还分不清它们是车辆的、还是轨道的**：0.6 m 枕距在 75 km/h（20.8 m/s）下给出枕木通过频率
   **34.7 Hz** 及其谐波 69.4/104 Hz；而本记录只有**一个速度**，无法用“换速度后频率是否随速度平移”
   来把轨道周期性与车辆模态分开。3 % 容差在 0.5 Hz 分辨率下也只有 2–3 根谱线宽，判“重复”本身偏宽松。

因此本节的结论是：**FDD 可继续用，但要用它标定模型，必须先有一段速度不同的数据**（同一缺陷在不同
车速下频率平移、枕木谐波也平移，但车辆模态不动——这正是判据）。在此之前，`measurement_validation_status`
仍是 `not_evaluated`。

复算：`python -X utf8 scripts\s22_fdd_measured.py`，产物 `F:\velch_tmp\fdd\fdd_sections.json`。
