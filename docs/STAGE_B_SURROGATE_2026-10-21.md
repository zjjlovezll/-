# B 阶段：可微代理与保险丝 2026-10-21

**结论先说**：代理层做成了，精度达标（亚微米）且保险丝有效，但**在成本上打不过已有的三线性查表**
（单次 173 µs vs 8.46 µs），因此**不作为默认快速路径**，只作为"需要 C¹ 光滑 + 带界"的选项保留。

## B1 方法与选型

- 选 **高斯过程**（Matérn 5/2，numpy 手写，无 sklearn——本机 sklearn 与 numpy ABI 不兼容，
  `ValueError: numpy.dtype size changed ... Expected 96 ... got 88`，未动环境）。
- 不选神经算子（LNO）的理由：输入只有 2 维（横向偏移、竖向压入）、样本 O(100)、
  且求解器要的是**逐次可用的误差界**；LNO 需 1e3–1e4 样本与 GPU，边界还得另拟合。
- 长度尺度由 5 点边缘似然栅格选择，不做完整优化（O(100) 样本下收益不抵不确定性）。
- 数据来自"几何层 + 本构层"的精确解：`build_dataset()` 用抖动网格采样，`fit()` 拟合
  （压入量、接触点横坐标）两个输出。

## 实测（两圆弧解析几何，225 训练 / 400 验证）

| 项 | 值 |
|---|---|
| 压入误差 \|Δδ\| | p50 **0.013 µm** / p95 **0.255 µm** / max **4.451 µm** |
| 界的覆盖（q=0.999） | **99.8 %**，界的中位数 0.422 µm |
| 容差 1 µm | 回退率 **7.0 %**，回退后最坏误差 **0.713 µm**（≤ 容差，保险丝成立） |
| 容差 5 µm | 回退率 0 %，最坏误差 4.451 µm（由界保证） |
| 单次预测 | **172.7 µs** |
| 批量 1000 次 | 12.86 µs/次 |
| 对照：三线性查表 | **8.46 µs/次**，误差 1.023 µm |
| 对照：直算 | 154.2 µs/次 |

## B2 保险丝

`FusedEvaluator(fit, exact, tolerance_m)`：每次预测同时取界，`bound ≤ tolerance` 才用代理，
否则回退精确解，并统计 `fallback_rate`。上表两个容差档就是它的实测行为——
**代理只能费时间，不能损精度**，这一点由构造保证。

## B3 判定（关键）

1. 代理精度确实优于查表（0.013/0.255 µm 对 1.023 µm），但那是抽样误差口径；
   两者都在微米级，对 0.5 mm 量级的侵入而言都是 0.1 % 以下。
2. 成本上代理**输给查表近 20 倍**（单次 172.7 vs 8.46 µs）。原因是 GP 每次要算 n=225 的核向量。
3. 因此批量/反演场景的快速路径仍是**查表**（18× 直算）；代理的价值在
   "需要导数连续（C¹）且要一个可核验误差界"的场合，例如反演里的梯度传播、或
   论文中论证"几何层的可微替代"。

## 复现

```
python -X utf8 -m velch.surrogate          # 自测：拟合→标定→覆盖→回退率→计时
```

模块：`src\velch\surrogate.py`（`build_dataset` / `fit` / `calibrate` / `SurrogateFit.predict`
/ `bound` / `FusedEvaluator` / `FusedResult`）。不在默认求解路径上，需显式调用。

## 已知限制

- 只在"始终接触"的压入区间标定；跨 `δ = 0` 折点时误差尾部会爆到 80 µm（第一版实测），
  接触判定仍须交给精确解。
- 只覆盖一个断面配对；换断面要重采样重拟合（单次 0.2 s），不能跨站位复用。
